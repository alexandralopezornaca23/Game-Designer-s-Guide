# Properties > Tool


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔧 | **Opciones de la herramienta activa** | *Panel Properties > pestaña Tool (icono de llave/destornillador)* | Basic | El contenido cambia por completo según la herramienta seleccionada en la barra T (p. ej. Bevel muestra segmentos y perfil). |
| - | **Tool es dinámica** | *Panel Properties > pestaña Tool (icono de llave/destornillador)* | Basic | A diferencia del resto de pestañas del panel de Properties (que muestran datos fijos del objeto/escena), Tool siempre muestra las opciones de la herramienta actualmente activa en la Barra T (Select Box, Move, Extrude Region, Brush...); su contenido cambia según la herramienta (ver fila 'Opciones de la herramienta activa' más arriba). A continuación, el detalle de Select Box y del subpanel fijo 'Workspace' que aparece bajo cualquier herramienta. |
| - | **Select Box > Affect Only: Origins** | *Panel Properties > Tool > Options > Affect Only > Origins* | Intermediate | Con Select Box (u otra herramienta de transformar) activa: al marcarlo, cualquier Move/Rotate/Scale que hagas solo mueve el punto de origen del objeto, sin mover su geometría/malla; útil para recolocar el origen sin desplazar el modelo. |
| - | **Select Box > Affect Only: Locations** | *Panel Properties > Tool > Options > Affect Only > Locations* | Intermediate | Restringe la transformación para que solo afecte a la posición (Location) del objeto, ignorando cambios de rotación o escala aunque la herramienta o el gizmo los permita. |
| - | **Select Box > Affect Only: Parents** | *Panel Properties > Tool > Options > Affect Only > Parents* | Advanced | Si mueves un objeto que tiene hijos (Parent/Child), al marcarlo la transformación solo afecta al padre; normalmente mover un padre arrastra también a sus hijos, así que esta opción sirve para reposicionar solo el padre sin desplazar a los hijos. |
| 📌 | **Workspace > Pin Scene** | *Panel Properties > Tool > Workspace > Pin Scene* | Advanced | Fija una escena concreta a este Workspace: si lo activas, esta pestaña siempre muestra/usa esa escena aunque cambies la 'escena activa' global desde el selector de arriba (útil si, por ejemplo, quieres que la pestaña Shading trabaje siempre sobre una escena de pruebas distinta de la principal). |
| - | **Workspace > Mode** | *Panel Properties > Tool > Workspace > Mode* | Basic | El mismo desplegable de Modo del header del Viewport (Object Mode, Edit Mode, Sculpt Mode...), repetido aquí; cambiarlo desde este panel equivale a cambiarlo desde arriba. |
| - | **Workspace > Sequencer Scene** | *Panel Properties > Tool > Workspace > Sequencer Scene* | Advanced | Si este Workspace contiene un Video Sequencer, elige aquí qué escena muestra ese Sequencer, de forma independiente a la escena 3D activa de este mismo Workspace. |
| - | **Workspace > Sync Scene Time** | *Panel Properties > Tool > Workspace > Sync Scene Time* | Advanced | Sincroniza el fotograma actual de reproducción entre la escena de este Workspace y la del Sequencer Scene, para que avancen a la vez al darle a Play. |
| 🧩 | **Workspace > Filter Add-ons** | *Panel Properties > Tool > Workspace > Filter Add-ons* | Advanced | Al activar la casilla, puedes marcar qué add-ons concretos (de los que ya tienes instalados/activados en Preferences > Add-ons) muestran su interfaz SOLO en este Workspace, para no saturar la UI con botones de add-ons que no usas en esta pestaña; la lista desplegada muestra los add-ons disponibles con una casilla cada uno (en tu caso: Import-Export: glTF 2.0 format, Render: Cycles Render Engine, Animation: Pose Library). |
| - | **Workspace > Custom Properties** | *Panel Properties > Tool > Workspace > Custom Properties > New* | Advanced | Añade propiedades personalizadas (clave/valor) al propio Workspace (no al objeto ni a la escena), pensado para exponer datos a scripts de Python que necesiten guardar configuración ligada a esa pestaña de Workspace. |
