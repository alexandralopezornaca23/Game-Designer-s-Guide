# Modifier: Boolean


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Operation (Union/Difference/Intersect)** | *Dentro del modificador* | Basic | Union junta los dos objetos, Difference resta el segundo objeto del primero, Intersect deja solo la parte donde se solapan. |
| - | **Solver (Exact/Fast)** | *Dentro del modificador* | Intermediate | Exact es más preciso pero más lento; Fast es más rápido pero puede fallar con geometría compleja o no-manifold. |
| - | **Object** | *Dentro del modificador* | Basic | El segundo objeto con el que se hace la operación; suele ocultarse en el viewport/render tras aplicar el resultado. |
