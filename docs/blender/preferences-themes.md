# Preferences > Themes


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎨 | **Presets (desplegable + botones +/-/guardar)** | *Edit > Preferences > Themes* | Basic | Guarda, carga o borra combinaciones completas de colores como preset propio; por defecto Blender trae 'Blender Dark' y 'Blender Light'. Solo esta pestaña tiene esta barra de Presets arriba del todo, a diferencia del resto de pestañas de Preferences. |
| 🎨 | **Install...** | *Edit > Preferences > Themes* | Advanced | Instala un archivo de tema (.xml) descargado o compartido por otra persona, para aplicarlo directamente. |
| - | **Reset** | *Edit > Preferences > Themes* | Basic | Descarta todos los cambios de color hechos a mano en el tema actual y vuelve a su estado original. |
| 🎨 | **Estructura general (categorías)** | *Edit > Preferences > Themes* | Intermediate | Es la pestaña más larga de Preferences: la lista de categorías (User Interface, Color Sets, Regions, Common, y luego una por cada editor: 3D Viewport, Dope Sheet/Timeline, Node Editor...) permite personalizar el color de cada elemento visual de Blender por separado, editor a editor. |
