# File Menu: Recover


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📄 | **Last Session** | *File > Recover > Last Session* | Intermediate | Recupera exactamente el estado en que estaba Blender al cerrarse (ventanas y archivos abiertos); ideal tras un cierre inesperado. |
| 💾 | **Auto Save...** | *File > Recover > Auto Save* | Intermediate | Abre el explorador de archivos con los autoguardados periódicos (frecuencia configurable en Preferences > Save & Load); útil si Last Session no tiene lo que buscas. |
