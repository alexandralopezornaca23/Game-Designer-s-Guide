# Edit Menu


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ↩️ | **Undo** | *Edit > Undo (Ctrl+Z)* | Basic | Deshace el último paso. En Blender el historial de Undo es global (afecta a todo lo que has tocado, no solo a un objeto); su profundidad se ajusta en Preferences > Editing > Undo Steps. |
| ↪️ | **Redo** | *Edit > Redo (Mayús+Ctrl+Z)* | Basic | Rehace el paso que acabas de deshacer; se pierde en cuanto haces una acción nueva distinta. |
| 🕘 | **Undo History** | *Edit > Undo History* | Intermediate | Despliega una lista visual de todos los pasos recientes para saltar directamente a uno concreto, en vez de deshacer de uno en uno. |
| 🔧 | **Adjust Last Operation...** | *Edit > Adjust Last Operation (F9)* | Intermediate | Abre un panel flotante con los parámetros de la ÚLTIMA operación (por ejemplo, tras un Bevel, aquí cambias el número de segmentos); solo funciona justo después de la acción, antes de hacer clic en otra cosa. |
| 🔁 | **Repeat Last** | *Edit > Repeat Last (Mayús+R)* | Intermediate | Repite la última acción realizada, tantas veces como pulses el atajo; muy usado para replicar rápido una misma operación. |
| 🕘 | **Repeat History...** | *Edit > Repeat History* | Advanced | Muestra una lista de acciones anteriores (no solo la última) para elegir cuál repetir. |
| 🔍 | **Menu Search...** | *Edit > Menu Search (F3)* | Basic | Busca cualquier comando/operador de Blender por nombre y lo ejecuta directamente, sin necesidad de saber en qué menú vive; muy útil cuando no recuerdas dónde está una función. |
| 🏷️ | **Rename Active Item...** | *Edit > Rename Active Item (F2)* | Basic | Renombra el objeto/dato activo sin tener que ir al Outliner y hacer doble clic. |
| 🏷️ | **Batch Rename...** | *Edit > Batch Rename (Ctrl+F2)* | Intermediate | Abre un panel para renombrar varios objetos/datos a la vez con reglas: buscar y reemplazar, añadir prefijo/sufijo, numeración automática... |
| 🔒 | **Lock Object Modes** | *Edit > Lock Object Modes* | Advanced | Activado (por defecto), impide cambiar el modo (Object/Edit/Sculpt...) de un objeto mientras otro objeto distinto esté en un modo especial; evita cambios de modo accidentales al hacer clic entre objetos. |
