# Top Menu > File


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📄 | **New / Open / Open Recent** | *Barra superior > File* | Basic | Nuevo archivo, abrir uno existente o ver los últimos abiertos. |
| 📄 | **Revert / Recover Last Session** | *Barra superior > File* | Intermediate | Revert descarta cambios y recarga el último guardado; Recover recupera tras un cierre inesperado (autosave). |
| 💾 | **Save / Save As / Save Copy** | *Barra superior > File / Ctrl+S (Save) / Ctrl+Mayús+S (Save As)* | Basic | Save Copy guarda una copia sin que el archivo activo pase a ser esa copia (útil para exportar variantes). |
| 💾 | **Save Incremental** | *Barra superior > File* | Intermediate | Guarda una nueva versión numerada (archivo_v01, v02...) sin sobrescribir la actual, con un clic. |
| 🔗 | **Link / Append** | *Barra superior > File* | Advanced | Append copia datos de otro .blend a este; Link los referencia en vivo desde el otro archivo (cambian si cambia el original). |
| 📤 | **Import / Export** | *Barra superior > File* | Basic | Trae o saca modelos en formatos como FBX, OBJ, glTF, Alembic... la puerta de salida hacia Unity/Unreal/Maya. |
| 📁 | **External Data** | *Barra superior > File* | Advanced | Gestiona rutas de texturas externas: empaquetarlas dentro del .blend o volver a buscarlas si se movieron. |
| ⚙️ | **Defaults (Load/Save Startup File)** | *Barra superior > File* | Advanced | Guarda la escena actual como plantilla de inicio cada vez que abres Blender. |
