# Viewport 3D > Object


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🧊 | **Object: menú general** | *Barra superior del Viewport 3D > Object* | Basic | El menú con más comandos de gestión de objetos: transformar, organizar en Collections, vincular datos entre objetos, animación rápida, física y limpieza. Estructurado en bloques separados por líneas: Transform/Set Origin/Mirror/Clear/Apply/Snap (todo lo relativo a mover y fijar transformaciones), Duplicate/Join/Copy/Paste, Asset/Collection, Library Override/Relations/Parent/Modifiers/Constraints/Track (relaciones entre objetos), Shade Smooth/Flat, Animation/Rigid Body, y por último Quick Effects/Convert/Show-Hide/Clean Up/Delete (pendientes de documentar con sus propias capturas). |
| ✛ | **Object > Transform: Move / Rotate / Scale / To Sphere / Shear / Bend / Push-Pull** | *Barra superior > Object > Transform* | Basic | Move/Rotate/Scale (G/R/S): las 3 transformaciones básicas, como comandos de menú además de sus atajos. To Sphere deforma gradualmente la selección hacia una esfera perfecta (con un factor de 0 a 1). Shear la inclina como un paralelogramo. Bend la curva a lo largo de un eje, como si la doblaras. Push/Pull la acerca o aleja de un punto central, engordando o encogiendo la forma. |
| - | **Object > Transform: Move/Scale Texture Space / Align to Transform Orientation / Randomize Transform / Align Objects** | *Barra superior > Object > Transform* | Advanced | Move/Scale Texture Space mueven o escalan la Texture Space del objeto (la caja de referencia para coordenadas Generated, ver Properties > Object Data) sin tocar la geometría real. Align to Transform Orientation rota el objeto para que sus ejes locales coincidan con la orientación de transformación activa (Global/Local/Normal...). Randomize Transform aplica una variación aleatoria de posición/rotación/escala a los objetos seleccionados, útil para dispersar props de forma natural. Align Objects alinea la selección sobre un eje concreto (por ejemplo, todos a la misma altura Z). |
| ⊕ | **Object > Set Origin: Geometry to Origin / Origin to Geometry / Origin to 3D Cursor / Origin to Center of Mass (Surface/Volume)** | *Barra superior > Object > Set Origin* | Intermediate | Geometry to Origin mueve la MALLA para que coincida con el punto de origen actual (el origen se queda quieto). Origin to Geometry hace lo contrario: mueve el ORIGEN al centro geométrico de la malla, dejándola quieta. Origin to 3D Cursor manda el origen a la posición actual del 3D Cursor. Origin to Center of Mass (Surface/Volume) calcula el centro de masa según el área de la superficie o según el volumen sólido, útil antes de simulaciones de Rigid Body o Physics para que giren de forma realista. |
| 🪞 | **Object > Mirror: Interactive Mirror / X-Y-Z Global / X-Y-Z Local** | *Barra superior > Object > Mirror* | Intermediate | Interactive Mirror (Ctrl+M) deja elegir el eje moviendo el ratón antes de confirmar con clic. Las 6 opciones fijas (X/Y/Z Global o Local) espejan instantáneamente la selección sobre ese eje concreto, sin necesidad de mover el ratón; Global usa los ejes de la escena, Local los ejes propios del objeto. |
| 🧹 | **Object > Clear: Location / Rotation / Scale / Origin** | *Barra superior > Object > Clear* | Basic | Location (Alt+G) devuelve la posición a 0,0,0. Rotation (Alt+R) devuelve la rotación a 0° en los 3 ejes. Scale (Alt+S) devuelve la escala a 1,1,1. Origin devuelve el punto de origen del objeto a la posición del origen de la escena, sin mover la geometría. Los 3 primeros NO borran la animación existente, solo reinician el valor actual del frame. |
| ✅ | **Object > Apply: Location / Rotation / Scale / All Transforms / Rotation & Scale** | *Barra superior > Object > Apply (Ctrl+A)* | Intermediate | 'Aplica' la transformación actual como si fuera el estado 'de fábrica' del objeto, y resetea esos valores a 0/0/1: por ejemplo, Apply Scale hace que la escala vuelva a mostrar 1.0 en Properties > Object aunque el tamaño visual del objeto no cambie. Imprescindible antes de muchos modifiers y simulaciones que asumen escala 1 (Rigid Body, Cloth, Bevel con tamaño real...). All Transforms aplica los 3 a la vez; Rotation & Scale solo esos dos. |
| - | **Object > Apply: Location/Rotation/Scale/All Transforms/Animated Transforms to Deltas** | *Barra superior > Object > Apply* | Advanced | Variante de los mismos Apply pero en vez de resetear a 0/0/1, mueve ese valor a las propiedades Delta (Object > Transform, unos valores extra que se suman a la transformación normal); útil para aplicar una transformación sin 'perder de vista' el valor aplicado, muy usado en instancias de partículas o Duplicate Linked donde no se puede aplicar la transformación normal sin romper el enlace. |
| - | **Object > Apply: Visual Transform / Visual Geometry to Mesh / Visual Geometry to Objects / Make Instances Real / Parent Inverse** | *Barra superior > Object > Apply* | Advanced | Visual Transform aplica como transformación real el resultado visual actual (incluyendo el efecto de Constraints/Physics), quitando esos efectos pero dejando el objeto donde se veía. Visual Geometry to Mesh convierte en malla real el resultado visual de Modifiers/Shape Keys. Visual Geometry to Objects hace lo mismo pero para instancias (Geometry Nodes/partículas), creando objetos de verdad. Make Instances Real convierte todas las instancias de una Collection en objetos independientes y editables. Parent Inverse aplica la matriz inversa del parentesco, útil tras cambiar de padre sin querer heredar su transformación previa. |
| 🧲 | **Object > Snap: Selection to Grid / to Cursor / to Cursor (Keep Offset) / to Active** | *Barra superior > Object > Snap* | Intermediate | Mueven la selección: Selection to Grid la ajusta al punto de rejilla más cercano. Selection to Cursor la manda a la posición del 3D Cursor (todos los objetos se apilan en el mismo punto). Selection to Cursor (Keep Offset) los manda ahí pero conservando las distancias relativas entre ellos. Selection to Active manda el resto de la selección a la posición del objeto activo. |
| 🧲 | **Object > Snap: Cursor to Selected / to World Origin / to Grid / to Active** | *Barra superior > Object > Snap* | Intermediate | Mueven el 3D CURSOR en vez de los objetos: Cursor to Selected lo manda al centro de la selección. Cursor to World Origin lo devuelve a 0,0,0. Cursor to Grid lo ajusta al punto de rejilla más cercano. Cursor to Active lo manda a la posición exacta del objeto activo. |
| 📑 | **Object: Duplicate Objects / Duplicate Linked / Join** | *Barra superior del Viewport 3D > Object* | Basic | Duplicate Objects (Mayús+D) crea una copia independiente con su propia malla/datos. Duplicate Linked (Alt+D) crea una copia que COMPARTE el mismo dato de malla/curva (editar una en Edit Mode edita todas las copias a la vez), muy usado para repetir props idénticos ahorrando memoria. Join (Ctrl+J) fusiona todos los objetos seleccionados en uno solo, con la malla del objeto activo como base (los demás pierden su identidad como objetos independientes). |
| 📋 | **Object: Copy Objects / Paste Objects** | *Barra superior del Viewport 3D > Object* | Basic | Copy Objects (Ctrl+C) copia la selección al portapapeles del sistema. Paste Objects (Ctrl+V) la pega, incluso en OTRA instancia de Blender abierta o en otro archivo, a diferencia de Duplicate que solo funciona dentro del mismo archivo. |
| 🏷️ | **Object > Asset: Mark as Asset / Clear Asset / Clear Asset (Set Fake User)** | *Barra superior > Object > Asset* | Advanced | Mark as Asset convierte el objeto en un Asset reutilizable visible desde el Asset Browser de cualquier archivo que tenga esta librería enlazada, con su propia miniatura de vista previa. Clear Asset le quita esa marca. Clear Asset (Set Fake User) le quita la marca pero le activa Fake User para que no se borre igualmente al guardar aunque no lo use nada en la escena. |
| 📦 | **Object > Collection: Move to Collection / Link to Collection** | *Barra superior > Object > Collection* | Intermediate | Move to Collection (M) saca al objeto de su Collection actual y lo mete en otra (elegida de una lista o creando una nueva). Link to Collection (Mayús+M) lo añade también a otra Collection sin sacarlo de la actual, quedando en ambas a la vez. |
| 📦 | **Object > Collection: Create New Collection / Remove from Collection / Remove from All Collections** | *Barra superior > Object > Collection* | Intermediate | Create New Collection (Ctrl+G) mete la selección en una Collection nueva recién creada. Remove from Collection (Ctrl+Alt+G) la saca de la Collection activa. Remove from All Collections (Mayús+Ctrl+Alt+G) la saca de TODAS las Collections a la vez, dejándola solo en la Collection raíz de la escena. |
| 📦 | **Object > Collection: Add Selected to Active Object's Collection / Remove Selected from Active Collection** | *Barra superior > Object > Collection* | Advanced | Add Selected to Active Object's Collection (Mayús+Ctrl+G) mete al resto de la selección en la misma Collection en la que ya está el objeto activo. Remove Selected from Active Collection (Mayús+Alt+G) saca a la selección de esa Collection en concreto (pudiendo seguir perteneciendo a otras). |
| 🔗 | **Object > Library Override: Make / Reset / Clear** | *Barra superior > Object > Library Override* | Advanced | Sistema para poder editar, dentro del archivo actual, ciertas propiedades de un objeto enlazado (Link) desde otro .blend sin romper el enlace ni tener que editar el archivo original. Make crea ese 'permiso de edición local'. Reset descarta los cambios locales hechos y vuelve al estado del archivo original. Clear elimina el Library Override, dejando el objeto de nuevo totalmente bloqueado como un Link normal. |
| 🔗 | **Object > Relations: Make Instance Face** | *Barra superior > Object > Relations* | Advanced | Convierte cada cara de la malla activa en una instancia del objeto seleccionado, repartiéndolo por toda la superficie orientado según la normal de cada cara; una forma alternativa y más antigua de dispersar objetos frente a Geometry Nodes o Particles. |
| 🔗 | **Object > Relations > Make Local: Selected Objects / Selected Objects and Data / Selected Objects, Data and Materials / All** | *Barra superior > Object > Relations > Make Local* | Advanced | Rompe el enlace (Link) con la librería/archivo externo del que provienen los objetos seleccionados, convirtiéndolos en datos 100% locales y editables de este archivo. Las variantes controlan hasta qué profundidad se copia: solo el Object, también su Object Data (malla/curva...), también los Materials, o All (todo lo enlazado del archivo, sin necesidad de tener nada seleccionado). |
| 🔗 | **Object > Relations > Make Single User: Object / Object & Data / Object & Data & Materials / Materials / Object Animation / Object Data Animation** | *Barra superior > Object > Relations > Make Single User* | Advanced | Cuando varios objetos COMPARTEN el mismo dato (por ejemplo, tras un Duplicate Linked), separa esa selección para que cada uno tenga su propia copia independiente en vez de compartirla, sin afectar a los objetos NO seleccionados que sigan compartiendo el original. Las variantes controlan qué se independiza: solo el Object, también su Data (malla), también los Materials, solo los Materials, o solo la Action de animación del Object o de su Object Data. |
| 🔗 | **Object > Parent: Object / Bone / Bone Relative / Curve Deform / Follow Path / Path Constraint / Lattice Deform / Vertex / Vertex (Triangle)** | *Barra superior > Object > Parent (Ctrl+P)* | Intermediate | Formas de emparentar el objeto activo como padre de la selección (el más usado es Object, un parentesco normal). Bone/Bone Relative emparentan a un hueso concreto de un Armature. Curve Deform hace que el hijo se deforme siguiendo una curva (equivale al modifier Curve). Follow Path/Path Constraint hacen que el hijo recorra una curva (equivale a la Path Animation o al constraint Follow Path). Lattice Deform aplica el modifier Lattice automáticamente. Vertex/Vertex (Triangle) emparentan a uno o tres vértices concretos de una malla, para que el hijo siga esa parte exacta de la geometría aunque se deforme. |
| 🔗 | **Object > Parent: Armature Deform (With Empty Groups / With Automatic Weights / With Envelope Weights)** | *Barra superior > Object > Parent > Armature Deform* | Intermediate | Emparenta la malla seleccionada a un Armature Y le añade automáticamente un modifier Armature, la forma estándar de riggear un personaje. With Empty Groups crea los Vertex Groups vacíos (para pintar los pesos a mano después). With Automatic Weights calcula los pesos de deformación en automático según la cercanía de cada hueso. With Envelope Weights usa el radio de Envelope de cada hueso (ver Properties > Bone > Deform) para calcular los pesos, en vez de Vertex Groups pintados. |
| 🔗 | **Object > Parent: Make Parent without Inverse / Make Parent without Inverse (Keep Transform)** | *Barra superior > Object > Parent* | Advanced | Emparenta sin guardar la matriz inversa del padre (lo normal SÍ la guarda, para que el hijo no salte de sitio al emparentar). Sin ella, el hijo puede saltar visualmente a heredar de golpe toda la transformación del padre. Keep Transform intenta compensar ese salto ajustando los valores del hijo para que se quede donde estaba visualmente. |
| 🔗 | **Object > Parent: Clear Parent / Clear and Keep Transformation / Clear Parent Inverse** | *Barra superior > Object > Parent (Alt+P)* | Intermediate | Clear Parent quita el parentesco; el hijo puede saltar de sitio al perder la herencia de transformación del padre. Clear and Keep Transformation lo quita pero ajusta los valores para que el objeto se quede exactamente donde estaba visualmente. Clear Parent Inverse resetea solo la matriz inversa guardada al emparentar, sin quitar el parentesco en sí. |
| 🔧 | **Object > Modifiers: Copy Modifiers to Selected Objects / Clear Object Modifiers** | *Barra superior > Object > Modifiers* | Intermediate | Copy Modifiers to Selected Objects copia TODA la pila de modifiers del objeto activo al resto de la selección, sustituyendo la que tuvieran. Clear Object Modifiers borra todos los modifiers de los objetos seleccionados de golpe. |
| ⛓️ | **Object > Constraints: Add Constraint (with Targets) / Copy Constraints to Selected Objects / Clear Object Constraints** | *Barra superior > Object > Constraints* | Intermediate | Add Constraint (with Targets) añade un constraint nuevo al objeto activo usando el resto de la selección como Target automáticamente, sin tener que abrir Properties > Object Constraints y elegirlo a mano. Copy Constraints to Selected Objects copia todos los constraints del activo al resto de la selección. Clear Object Constraints los borra todos de golpe. |
| ⛓️ | **Object > Track: Damped Track / Track to / Lock Track Constraint** | *Barra superior > Object > Track* | Intermediate | Atajo rápido para añadir alguno de estos 3 constraints de orientación (ya documentados a fondo en Properties > Object Constraints) usando el objeto activo como Target de la selección, sin pasar por el panel de Properties: Damped Track, Track To y Lock Track. |
| ⛓️ | **Object > Track: Clear Track / Clear and Keep Transformation (Clear Track)** | *Barra superior > Object > Track* | Intermediate | Clear Track quita cualquiera de esos 3 constraints de tracking de la selección. Clear and Keep Transformation los quita pero ajusta la transformación para que el objeto se quede donde se veía justo antes de quitarlos. |
| 🌓 | **Object: Shade Smooth / Shade Flat** | *Barra superior del Viewport 3D > Object* | Basic | Shade Smooth suaviza visualmente el sombreado entre caras adyacentes (sin cambiar la geometría real, solo cómo se calculan las normales al iluminar). Shade Flat vuelve a mostrar cada cara con su sombreado plano/facetado normal. Ninguno de los dos añade ni quita geometría, es puramente visual/de render. |
| 🔗 | **Object > Link/Transfer Data: Link Objects to Scene / Link Object Data / Materials / Animation Data / Collections / Instance Collection / Fonts to Text** | *Barra superior > Object > Link/Transfer Data* | Advanced | Link Objects to Scene añade también los objetos seleccionados a OTRA Scene del mismo archivo (aparecen en las dos escenas a la vez). El resto copia, del objeto activo al resto de la selección, un tipo de dato ENLAZADO en vez de copiado: Object Data (comparten la misma malla/curva), Materials, Animation Data (la misma Action), Collections (pertenecen a las mismas Collections), Instance Collection (la misma Collection instanciada), Fonts to Text (la misma fuente tipográfica, entre objetos Text). |
| 🔗 | **Object > Link/Transfer Data: Copy Modifiers / Constraints / Grease Pencil Effects / Light Linking / Shadow Linking / UV Maps** | *Barra superior > Object > Link/Transfer Data (Ctrl+L)* | Advanced | Copian (no enlazan, crean una copia independiente) del objeto activo al resto de la selección: Modifiers, Constraints, Grease Pencil Effects, Light Linking (qué luces afectan a qué objetos), Shadow Linking (qué objetos proyectan sombra sobre cuáles) y UV Maps. Transfer Mesh Data y Transfer Mesh Data Layout (en gris en la captura, deshabilitados sin el contexto adecuado) transfieren datos de malla más complejos (Vertex Groups, Shape Keys...) entre mallas con topología distinta. |
| 🔗 | **Object > Link/Transfer Data: Link Receivers to Emitter / Link Blockers to Emitter (Include / Exclude)** | *Barra superior > Object > Link/Transfer Data* | Advanced | Exclusivo de sistemas de Light Linking/Shadow Linking: vincula la selección como Receivers (objetos que SÍ reciben la luz/sombra de un emisor) o como Blockers (objetos que bloquean/proyectan la sombra) del objeto activo (que actúa como emisor/luz). Include los añade a esa lista, Exclude los añade pero marcados para excluirlos explícitamente en vez de incluirlos. |
| 🔑 | **Object > Animation: In-Betweens (Blend Pose with Rest Pose / Push Pose from Breakdown / Relax Pose to Breakdown / Pose Breakdowner / Blend to Neighbor)** | *Barra superior > Object > Animation > In-Betweens* | Advanced | Herramientas de Pose Mode para crear poses intermedias entre keyframes (mismo concepto que la herramienta Breakdowner de la Barra T, ver 'Barra T: Object Mode'): Blend Pose with Rest Pose mezcla la pose actual con la pose de reposo del Armature. Push/Relax Pose from/to Breakdown exageran o suavizan la pose respecto a sus vecinas. Pose Breakdowner (arrastrando el ratón) es la versión interactiva, idéntica a la herramienta de la Barra T. Blend to Neighbor mezcla la pose con la del keyframe más cercano. |
| 🔑 | **Object > Animation: Insert Keyframe / Insert Keyframe with Keying Set / Delete Keyframes / Clear Keyframes / Change Keying Set** | *Barra superior > Object > Animation* | Intermediate | Insert Keyframe (I) crea un keyframe en el frame actual para las propiedades por defecto (normalmente Location/Rotation/Scale). Insert Keyframe with Keying Set (K) usa un Keying Set concreto (un conjunto de propiedades predefinido) en vez del set por defecto. Delete Keyframes (Alt+I) borra los keyframes del frame actual. Clear Keyframes borra TODOS los keyframes de esa propiedad en toda la línea de tiempo. Change Keying Set (Mayús+K) cambia qué Keying Set está activo. |
| 🔑 | **Object > Animation: Bake Action / Bake Object Transform to Grease Pencil / Replace Action / Replace with New Action** | *Barra superior > Object > Animation* | Advanced | Bake Action convierte cualquier animación calculada (Constraints, Drivers, Physics...) en keyframes reales frame a frame, 'horneando' el resultado para poder editarlo o exportarlo sin depender de esos sistemas. Bake Object Transform to Grease Pencil convierte el movimiento del objeto en trazos de animación 2D de Grease Pencil. Replace Action sustituye la Action activa por otra elegida. Replace with New Action crea y asigna una Action completamente nueva y vacía. |
| 🪨 | **Object > Rigid Body: Add Active / Add Passive / Remove** | *Barra superior > Object > Rigid Body* | Intermediate | Add Active convierte la selección en Rigid Body Active (se ve afectada por la gravedad y las colisiones, cae y rebota). Add Passive la convierte en Rigid Body Passive (sirve de suelo/obstáculo fijo para las demás, no se mueve ella misma). Remove le quita la física de Rigid Body por completo. Atajos de menú para lo mismo que Properties > Physics > Rigid Body, sin tener que activar el panel a mano en cada objeto. |
| 🪨 | **Object > Rigid Body: Change Shape / Calculate Mass / Copy from Active / Apply Transformation / Bake to Keyframes / Connect** | *Barra superior > Object > Rigid Body* | Advanced | Change Shape cambia de golpe la Collision Shape (ver Properties > Physics) de todos los Rigid Body seleccionados. Calculate Mass calcula la masa automáticamente según el volumen y el material elegido (madera, metal...). Copy from Active copia toda la configuración de Rigid Body del objeto activo al resto de la selección. Apply Transformation aplica la transformación actual como el nuevo estado base de la simulación. Bake to Keyframes convierte el resultado de la simulación física en keyframes reales, editables como cualquier animación. Connect añade un Rigid Body Constraint entre los objetos seleccionados y el activo, uniéndolos físicamente (bisagras, uniones fijas...). |
| ⚛️ | **Object > Quick Effects: Quick Fur / Quick Explode / Quick Smoke / Quick Liquid** | *Barra superior > Object > Quick Effects* | Advanced | Atajos que configuran de golpe varios pasos manuales de Particles/Physics a la vez. Quick Fur (en gris en la captura, no disponible con el objeto/selección activos) añade un sistema de partículas Hair ya configurado como pelo básico. Quick Explode añade partículas + textura de explosión para que el objeto se rompa en fragmentos con física. Quick Smoke convierte el objeto en emisor de humo (Domain + Flow ya enlazados). Quick Liquid lo configura como emisor de un fluido líquido (Domain + Flow tipo Liquid). |
| ♻️ | **Object > Convert: Mesh / Curve / Curves / Point Cloud / Grease Pencil** | *Barra superior > Object > Convert* | Intermediate | Convierte el objeto activo (y la selección) a otro tipo de dato, generando geometría real en el tipo elegido. Mesh convierte Curve/Surface/Metaball/Text en malla real editable. Curve convierte Mesh/Text en curva Bézier. Curves convierte al sistema nuevo de Hair Curves. Point Cloud convierte a nube de puntos. Grease Pencil convierte Mesh/Curve en trazos de Grease Pencil (por ejemplo, para sacar un line art editable a mano). Solo aparecen aquí los tipos a los que el objeto activo puede convertirse realmente, no todos los tipos son intercambiables entre sí. |
| 👁️ | **Object > Show/Hide: Show Hidden Objects / Hide Selected / Hide Unselected** | *Barra superior > Object > Show/Hide* | Basic | Show Hidden Objects (Alt+H) vuelve a mostrar todo lo oculto con H. Hide Selected (H) oculta del Viewport los objetos seleccionados sin borrarlos (siguen existiendo en la escena). Hide Unselected (Mayús+H) oculta todo MENOS la selección actual, para aislar visualmente en qué se está trabajando (alternativa rápida a Local View). |
| 🎯 | **Object > Clean Up: Clean Vertex Group Weights / Limit Total Vertex Groups** | *Barra superior > Object > Clean Up* | Advanced | Clean Vertex Group Weights elimina asignaciones de peso de Vertex Group con valor 0 o insignificante, aligerando el archivo. | 🎨 | **Object > Clean Up: Remove Unused Material Slots / Remove All Materials** | *Barra superior > Object > Clean Up* | Intermediate | Remove Unused Material Slots borra los slots de material vacíos o que ninguna cara de la malla usa realmente.
