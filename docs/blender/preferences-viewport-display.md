# Preferences > Viewport: Display


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Object Info** | *Edit > Preferences > Viewport > Display* | Basic | Muestra en la esquina del viewport el nombre del objeto activo, su tipo de dato y otra info básica; útil para saber qué tienes seleccionado sin abrir el Outliner. |
| - | **View Name** | *Edit > Preferences > Viewport > Display* | Basic | Muestra en el viewport el nombre de la vista actual (Front, Top, User Perspective...). |
| - | **Playback Frame Rate (FPS)** | *Edit > Preferences > Viewport > Display* | Intermediate | Muestra los FPS reales de reproducción en el viewport mientras se reproduce la animación; útil para detectar si la escena va lenta antes de exportar/renderizar. |
| - | **Samples (junto a Playback Frame Rate)** | *Edit > Preferences > Viewport > Display* | Advanced | Número de fotogramas usados para calcular la media de FPS mostrada; con 0, Blender lo calcula automáticamente haciendo que el número de samples coincida con el FPS objetivo de la escena. |
| - | **Gizmo Size** | *Edit > Preferences > Viewport > Display* | Basic | Tamaño en píxeles del gizmo de mover/rotar/escalar que aparece sobre el objeto seleccionado. |
| - | **Reference Sphere Size** | *Edit > Preferences > Viewport > Display* | Advanced | Tamaño de la esfera de referencia usada al previsualizar materiales/iluminación de estudio. |
| 🧭 | **3D Viewport Axes (Interactive Navigation)** | *Edit > Preferences > Viewport > Display* | Basic | Tipo de gizmo de ejes en la esquina del viewport; en modo 'Interactive Navigation' puedes clicar los ejes para cambiar de vista al instante. |
| - | **Fresnel (Edit Mode)** | *Edit > Preferences > Viewport > Display* | Advanced | Activa un efecto Fresnel (más brillo en los bordes) en el sombreado de la malla durante el modo edición. |
