# Preferences > File Paths: Render


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖼️ | **Texture Cache** | *Edit > Preferences > File Paths* | Advanced | Carpeta donde se guarda la caché de texturas de render, por ejemplo texturas de gran tamaño ya procesadas. |
| 🎬 | **Render Output** | *Edit > Preferences > File Paths* | Basic | Carpeta por defecto donde se guardan las imágenes/animaciones al renderizar, si no se especifica otra ruta en Properties > Output. |
| 🎬 | **Render Cache** | *Edit > Preferences > File Paths* | Advanced | Carpeta donde se guarda la caché intermedia del render. |
