# Properties > Modifiers


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔧 | **Pila de modificadores (stack)** | *Panel Properties > pestaña Modifiers (icono de llave inglesa)* | Basic | Los modificadores se aplican de arriba a abajo y son no destructivos hasta que pulsas Apply. |
| 🔧 | **Cabecera común de cualquier modifier: iconos de la fila** | *Panel Properties > Modifiers, cabecera de cada modifier ya añadido* | Basic | Iconos que se repiten en la cabecera de (casi) cualquier modifier, de izquierda a derecha tras el nombre: icono de tipo (identifica de qué modifier se trata, coloreado según su categoría del menú Add Modifier), 'Edit Mode Display' (aplica el efecto también mientras estás en Edit Mode, no solo verlo en Object Mode), 'Realtime' (icono de pantalla: muestra el efecto en el Viewport) y 'Render' (icono de cámara: lo incluye en el render final) — estos 3 se pueden apagar por separado para aligerar el trabajo sin perder el resultado final. La flecha desplegable abre opciones extra (Copy to Selected, Apply, Duplicate...), la X lo borra, y los puntos ':::' de la derecha del todo permiten arrastrar el modifier para reordenarlo en la pila. |
| 🔳 | **Subdivision Surface** | *Panel Properties > Modifiers > Add Modifier* | Basic | Suaviza la malla añadiendo geometría; base del flujo de trabajo "subdivision modeling". |
| 🪞 | **Mirror** | *Panel Properties > Modifiers > Add Modifier* | Basic | Duplica la malla en espejo respecto a un eje; muy usado modelando personajes simétricos. |
| ▦ | **Array** | *Panel Properties > Modifiers > Add Modifier* | Intermediate | Repite la malla N veces en una dirección (vallas, escaleras, raíles...). |
| 🔷 | **Bevel** | *Panel Properties > Modifiers > Add Modifier* | Intermediate | Achaflana aristas automáticamente; muy usado para que los modelos no se vean "perfectamente afilados". |
| 🧱 | **Solidify** | *Panel Properties > Modifiers > Add Modifier* | Intermediate | Da espesor a una superficie plana (como una tela sin grosor) convirtiéndola en un sólido. |
| ∩ | **Boolean** | *Panel Properties > Modifiers > Add Modifier* | Intermediate | Combina, resta o intersecta dos mallas (por ejemplo, para hacer un agujero con otro objeto). |
| 🦴 | **Armature** | *Panel Properties > Modifiers > Add Modifier* | Intermediate | Hace que la malla se deforme siguiendo un esqueleto (armature); imprescindible para animar personajes. |
| ✂️ | **Decimate** | *Panel Properties > Modifiers > Add Modifier* | Intermediate | Reduce el número de polígonos automáticamente; útil para generar LODs para el motor de videojuegos. |
| 🔺 | **Weighted Normal** | *Panel Properties > Modifiers > Add Modifier* | Advanced | Corrige el sombreado en modelos low-poly con biseles; muy recomendado antes de exportar a Unity/Unreal. |
| 🎞️ | **Data Transfer** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Copia datos (normales, vertex colors, UVs, vertex groups...) de otro objeto a este; útil para transferir detalle de una malla high-poly a una low-poly. |
| 🎞️ | **Mesh Cache** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Reproduce una animación de malla importada desde un archivo externo (formatos como MDD o PC2), típico al traer simulaciones de otros programas. |
| 🗺️ | **Mesh Sequence Cache** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Igual que Mesh Cache pero para secuencias Alembic (.abc), muy usado para importar simulaciones o animaciones de otros DCC manteniendo el cambio de topología frame a frame. |
| 🗺️ | **UV Project** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Proyecta las UV de la malla desde la perspectiva de una o varias cámaras/proyectores, útil para proyectar texturas tipo 'decal' sobre una superficie. |
| 🎯 | **UV Warp** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Deforma las coordenadas UV siguiendo la transformación de dos objetos (From/To), permitiendo animar una textura moviendo un Empty en vez de editar UVs a mano. |
| 🎯 | **Vertex Weight Edit** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Modifica los pesos de un Vertex Group ya existente aplicándoles una curva/remapeo, sin tener que repintar el Weight Paint a mano. |
| 🎯 | **Vertex Weight Mix** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Combina (suma, resta, multiplica...) los pesos de dos Vertex Groups distintos en uno solo. |
| ▦ | **Vertex Weight Proximity** | *Panel Properties > Modifiers > Add Modifier > Edit* | Advanced | Genera automáticamente los pesos de un Vertex Group según la distancia de cada vértice a otro objeto (más cerca = más peso). |
| 🏗️ | **Array (Legacy)** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Versión antigua del modificador Array, mantenida por compatibilidad con archivos viejos; para proyectos nuevos se recomienda el Array normal. |
| ➰ | **Build** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Hace aparecer o desaparecer progresivamente las caras de la malla a lo largo de los frames, como si se construyera o se desintegrara; efecto puramente de animación. |
| ✂️ | **Curve to Tube** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Convierte una curva en un tubo con geometría real (malla), generando un cilindro que sigue su trayectoria. |
| 🎭 | **Edge Split** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Separa la malla por las aristas marcadas como Sharp o que superen un ángulo límite, para que el sombreado suave no las redondee; control clásico de sombreado plano/duro. |
| 🔳 | **Mask** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Oculta o muestra partes de la malla según un Vertex Group o un Armature, sin borrar geometría de verdad; útil para previsualizar partes de un personaje. |
| 🔁 | **Multiresolution** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Genera niveles de subdivisión independientes para viewport/render/esculpido, guardando el detalle esculpido en cada nivel; es la base técnica para esculpir con muchísimo detalle en Sculpt Mode. |
| 🌱 | **Remesh** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Genera una malla nueva con topología regular a partir de la forma actual; muy usado tras un sculpt intensivo para limpiar la malla antes de retopologizar a mano. |
| ⚙️ | **Scatter on Surface** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Esparce copias de otro objeto o colección sobre la superficie de la malla (vegetación, rocas, decoración), como alternativa más directa a montarlo con Geometry Nodes. |
| 🧍 | **Screw** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Genera una malla girando un perfil 2D alrededor de un eje, como un torno; ideal para tornillos, roscas y objetos de revolución. |
| 🔺 | **Skin** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Genera automáticamente una malla sólida con volumen a partir de un esqueleto simple de vértices y aristas; útil para bocetar formas orgánicas muy rápido. |
| ☁️ | **Triangulate** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Convierte todas las caras (cuads/n-gons) en triángulos; se suele añadir justo antes de exportar a motores de videojuegos que requieren mallas trianguladas. |
| 🔗 | **Volume to Mesh** | *Panel Properties > Modifiers > Add Modifier > Generate* | Advanced | Convierte un objeto de tipo Volume (VDB, como el humo de una simulación Fluid) en una malla poligonal que se puede renderizar como sólido. |
| 🕸️ | **Weld** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Fusiona automáticamente los vértices que estén a una distancia mínima entre sí, eliminando duplicados sin tener que seleccionarlos a mano (equivalente a Merge by Distance pero no destructivo). |
| 🎱 | **Wireframe** | *Panel Properties > Modifiers > Add Modifier > Generate* | Intermediate | Convierte las aristas de la malla en geometría sólida con grosor, generando una versión 'de alambre' tridimensional del modelo. |
| ➰ | **Cast** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Deforma la malla proyectándola hacia una forma geométrica simple (esfera, cilindro, caja), mezclando la forma original con esa forma según un Factor. |
| 🗻 | **Curve** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Deforma la malla siguiendo la forma de un objeto Curve; muy usado para doblar texto o geometría a lo largo de un camino. |
| 🪝 | **Displace** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Desplaza los vértices según los valores de una textura (blanco/negro = alto/bajo); se usa para generar relieve o terrenos de forma procedural. |
| 〰️ | **Hook** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Vincula un grupo de vértices a un objeto 'gancho' (normalmente un Empty) para poder moverlos arrastrando ese objeto, sin tener que entrar en Edit Mode. |
| 🕸️ | **Laplacian Deform** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Deforma la malla preservando el volumen y los detalles de superficie al mover solo unos pocos vértices de control; útil para posar sin perder detalle esculpido. |
| 🕸️ | **Lattice** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Deforma la malla a través de una jaula (objeto Lattice) que la envuelve: mover los puntos de esa jaula deforma todo lo que hay dentro, sin tocar la malla original. |
| 🎁 | **Mesh Deform** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Igual que Lattice pero usando otra malla más compleja como jaula de deformación en vez de una rejilla regular. |
| 〰️ | **Shrinkwrap** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Pega o ajusta la malla a la superficie de otro objeto (proyectar, envolver, cercanía); muy usado para poner ropa sobre un personaje o generar un LOD que siga la forma original. |
| 🌀 | **Simple Deform** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Aplica deformaciones paramétricas simples a lo largo de un eje: Twist (retorcer), Bend (doblar), Taper (ahusar) o Stretch (estirar). |
| 🌀 | **Smooth** | *Panel Properties > Modifiers > Add Modifier > Deform* | Basic | Suaviza la posición de los vértices promediándolos con sus vecinos, sin añadir geometría nueva; reduce ruido o asperezas de la malla. |
| 🌀 | **Smooth Corrective** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Como Smooth pero intenta preservar el volumen original, evitando el efecto de 'encogimiento' típico del suavizado normal; muy usado en rigging para corregir deformaciones de piel en articulaciones. |
| 📎 | **Smooth Laplacian** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Variante de suavizado que preserva mejor la forma general del objeto mientras elimina ruido de alta frecuencia en la superficie. |
| 〰️ | **Surface Deform** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Vincula (Bind) la malla a otra malla base para que la siga al deformarse, transfiriendo su animación; típico para ropa o accesorios que deben seguir a un personaje animado. |
| 🌊 | **Warp** | *Panel Properties > Modifiers > Add Modifier > Deform* | Advanced | Deforma el espacio entre dos objetos (From/To), moviendo los vértices como si el espacio entre ambos se estirara o comprimiera. |
| 🧭 | **Wave** | *Panel Properties > Modifiers > Add Modifier > Deform* | Intermediate | Genera una onda que se propaga por la malla a lo largo del tiempo, como ondas en la superficie del agua. |
| 📐 | **Normal Edit** | *Panel Properties > Modifiers > Add Modifier > Normals* | Advanced | Permite editar manualmente la dirección de las normales de la malla, útil para forzar un sombreado concreto sin cambiar la geometría real. |
| 🧵 | **Smooth by Angle** | *Panel Properties > Modifiers > Add Modifier > Normals* | Basic | Sustituye al antiguo botón 'Shade Auto Smooth': suaviza el sombreado automáticamente según un ángulo límite entre caras, marcando como duras (Sharp) las aristas que lo superen. |
| 💥 | **Cloth** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Simulación de tela con física real (peso, rigidez, viento, colisiones); usado para ropa, banderas, cortinas o cualquier superficie flexible. |
| 🖌️ | **Collision** | *Panel Properties > Modifiers > Add Modifier > Physics* | Intermediate | Hace que el objeto actúe como obstáculo sólido para telas, partículas o cuerpos blandos de otros objetos de la escena. |
| 🧨 | **Dynamic Paint** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Permite que un objeto 'pinte' sobre otro al tocarlo: huellas, charcos que se mojan o texturas que reaccionan al contacto, generadas en tiempo real. |
| 💧 | **Explode** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Fragmenta la malla en trozos, apoyándose en un sistema de partículas, para simular una explosión o desintegración. |
| 💧 | **Fluid** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Simulación de líquidos, humo y fuego; requiere configurar al menos un objeto Domain, uno o varios Flow (emisores) y opcionalmente Effector (obstáculos). |
| ✨ | **Ocean** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Genera y anima procedimentalmente una superficie de océano realista con oleaje, sin necesidad de simulación de fluidos completa. |
| ✨ | **Particle Instance** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Muestra copias de esta malla en la posición de cada partícula de OTRO sistema de partículas del mismo objeto. |
| 🫧 | **Particle System** | *Panel Properties > Modifiers > Add Modifier > Physics* | Intermediate | Añade un sistema de partículas (Emitter o Hair) a la malla; es el mismo sistema configurable desde la pestaña Properties > Particles. |
| 🧬 | **Soft Body** | *Panel Properties > Modifiers > Add Modifier > Physics* | Advanced | Simulación de cuerpo blando/gelatinoso: la malla se deforma por gravedad, colisiones y su propia física interna, como si fuera goma o gel. |
| 🪮 | **Geometry Input / Capture Rest Geometry** | *Panel Properties > Modifiers > Add Modifier > Geometry* | Advanced | Geometry Input y Write > Capture Rest Geometry son utilidades pensadas para combinarse con Geometry Nodes: la primera trae geometría externa a la pila de modificadores, la segunda guarda un snapshot de la geometría en su estado sin deformar para usarlo de referencia más adelante en la pila. |
| 🪮 | **Hair Curves > Deformation: Blend / Displace / Frizz / Noise / Roll / Rotate / Shrinkwrap / Smooth / Straighten / Trim** | *Panel Properties > Modifiers > Add Modifier > Hair > Deformation* | Advanced | Modificadores del sistema moderno de Hair Curves (distinto del Hair clásico de partículas) que alteran la forma de curvas de pelo ya generadas: mezclarlas, desplazarlas, encresparlas, añadirles ruido, enrollarlas, rotarlas, ajustarlas a una superficie, suavizarlas, enderezarlas o recortar su longitud. |
| 🪮 | **Hair Curves > Generation: Duplicate / Generate / Interpolate** | *Panel Properties > Modifiers > Add Modifier > Hair > Generation* | Advanced | Crean nuevas curvas de pelo: duplicando las existentes, generándolas desde cero sobre una superficie, o interpolando curvas intermedias entre las guías para aumentar la densidad de pelo. |
| 🪮 | **Hair Curves > Guides: Braid / Clump / Create Guide Index Map / Curl** | *Panel Properties > Modifiers > Add Modifier > Hair > Guides* | Advanced | Trabajan con las curvas 'guía' del pelo: trenzarlas, agruparlas en mechones (Clump), generar un mapa de qué guía controla a cada curva, o rizarlas. |
| 🪮 | **Hair Curves > Utility: Attach to Surface / Redistribute Curve Points / Restore Curve Segment Length** | *Panel Properties > Modifiers > Add Modifier > Hair > Utility* | Advanced | Mantenimiento de curvas de pelo: fijarlas a la superficie del objeto, redistribuir sus puntos de control de forma más uniforme, o restaurar la longitud original de cada segmento tras deformarlas. |
| 🧬 | **Hair Curves > Write: Set Hair Curve Profile** | *Panel Properties > Modifiers > Add Modifier > Hair > Write* | Advanced | Define el perfil (grosor y forma de la sección transversal) con el que se renderizan las curvas de pelo. |
| 🎲 | **Instance on Elements** | *Panel Properties > Modifiers > Add Modifier > Instances* | Advanced | Genera una instancia (copia enlazada) de un objeto o colección en cada elemento (vértice/cara) de la malla; similar a la opción Instancing de Properties > Object pero con más control como modificador propio. |
| 🧵 | **Randomize Transforms** | *Panel Properties > Modifiers > Add Modifier > Instances* | Advanced | Aleatoriza la posición, rotación y/o escala de instancias ya generadas, para que no se vean todas idénticas. |
| 💥 | **Cloth Dynamics (Experimental)** | *Panel Properties > Modifiers > Add Modifier > Simulation* | Advanced | Versión experimental/nueva del sistema de simulación de tela, con un motor de físicas distinto al modificador Cloth clásico. |
| 🪮 | **Collider** | *Panel Properties > Modifiers > Add Modifier > Simulation* | Advanced | Marca el objeto como colisionador para el nuevo sistema de Simulation Nodes (física dentro de Geometry Nodes); equivalente moderno al modificador Collision clásico. |
| 🧬 | **Hair Dynamics** | *Panel Properties > Modifiers > Add Modifier > Simulation* | Advanced | Añade simulación física real (gravedad, viento, colisiones) a las curvas de pelo Hair Curves, para que se muevan de forma natural. |
| - | **Geometry Nodes** | *Panel Properties > Modifiers > Add Modifier* | Advanced | Añade un modificador de Geometry Nodes vacío para construir efectos procedurales propios con nodos (generación, dispersión, deformación...); ver también la categoría 'Workspaces' para el Workspace Geometry Nodes. |
