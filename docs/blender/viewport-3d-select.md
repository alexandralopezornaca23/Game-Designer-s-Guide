# Viewport 3D > Select


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖱️ | **Select: All / None / Invert** | *Barra superior del Viewport 3D > Select* | Basic | All (A) selecciona todos los objetos de la escena. None (Alt+A) deselecciona todo. Invert (Ctrl+I) invierte la selección actual: lo seleccionado pasa a no estarlo y viceversa. |
| 🖱️ | **Select: Box Select / Circle Select / Lasso Select** | *Barra superior > Select* | Basic | Las mismas 3 formas de seleccionar ya documentadas como variantes de la primera herramienta de la Barra T (ver 'Select Box (Tweak)'), aquí accesibles también como comandos de menú con sus propios atajos directos de una sola pulsación: Box Select (B), Circle Select (C), Lasso Select (sin atajo de una tecla, con submenú propio detallado en la fila siguiente). |
| - | **Select > Lasso Select: Set / Extend / Subtract / Difference / Intersect** | *Barra superior > Select > Lasso Select* | Intermediate | Controlan cómo se combina una nueva selección por Lasso (o Box/Circle) con la que ya había: Set sustituye la selección anterior por la nueva. Extend (Ctrl+arrastrar con botón derecho) añade la nueva selección a la existente. Subtract (Mayús+Ctrl+arrastrar con botón derecho) quita de la selección lo que toque el nuevo lazo. Difference selecciona solo lo que esté en una de las dos selecciones pero no en ambas. Intersect selecciona solo lo que esté en las dos selecciones a la vez. |
| 🖱️ | **Select: Select Active Camera / Select Mirror / Select Random** | *Barra superior del Viewport 3D > Select* | Intermediate | Select Active Camera selecciona directamente la cámara activa de la escena, esté donde esté. Select Mirror selecciona el equivalente simétrico (según el eje) de la selección actual, muy usado en objetos con nombres L/R para seleccionar su pareja. Select Random selecciona un porcentaje aleatorio de la selección actual o de toda la escena, útil por ejemplo para dispersar variaciones en un conjunto de props. |
| 🖱️ | **Select > More/Less: More / Less** | *Barra superior > Select > More/Less* | Intermediate | More (Ctrl+Numpad +) y Less (Ctrl+Numpad -) amplían o reducen la selección actual añadiendo o quitando un 'anillo' más de elementos conectados a los ya seleccionados (en Object Mode, según relaciones de Parent/Child; en Edit Mode, según la topología de la malla). |
| 🖱️ | **Select > More/Less: Parent / Child / Extend Parent / Extend Child** | *Barra superior > Select > More/Less* | Intermediate | Parent ([) selecciona (sustituyendo la selección) al objeto padre del activo. Child (]) selecciona a su hijo. Extend Parent (Mayús+[) y Extend Child (Mayús+]) hacen lo mismo pero AÑADIENDO a la selección actual en vez de sustituirla, permitiendo subir o bajar varios niveles de la jerarquía sin perder lo ya seleccionado. |
| 🖱️ | **Select > Select All by Type** | *Barra superior > Select > Select All by Type* | Intermediate | Misma lista de tipos de objeto que en Add (Mesh, Curve, Surface, Metaball, Text, Hair Curves, Point Cloud, Volume, Grease Pencil, Armature, Lattice, Empty, Light, Light Probe, Camera, Speaker): selecciona de golpe TODOS los objetos de la escena que sean de ese tipo, sin importar dónde estén ni cómo se llamen; muy útil para, por ejemplo, seleccionar todas las luces o todas las cámaras a la vez. Aquí aparece 'Hair Curves' como tipo independiente (curvas de pelo ya creadas en la escena), a diferencia del menú Add donde Empty Hair/Fur estaban dentro del submenú Curve. |
| 🖱️ | **Select > Select Grouped: Children / Immediate Children / Parent / Siblings / Type / Collection / Hook / Pass / Color / Keying Set / Light Type** | *Barra superior > Select > Select Grouped (Mayús+G)* | Advanced | Amplía la selección a partir del objeto ACTIVO según distintos criterios: Children (todos los descendientes) / Immediate Children (solo un nivel) / Parent / Siblings (otros hijos del mismo padre) / Type (mismo tipo de objeto) / Collection (misma Collection) / Hook (objetos usados como Hook del activo) / Pass (mismo Pass Index) / Color (mismo color de Viewport en Object > Viewport Display) / Keying Set (incluidos en el mismo Keying Set de animación) / Light Type (mismo tipo de luz, si el activo es una Luz). |
| 🖱️ | **Select > Select Linked: Object Data / Material / Instanced Collection / Particle System / Library / Library (Object Data)** | *Barra superior > Select > Select Linked (Mayús+L)* | Advanced | Amplía la selección a otros objetos que comparten el mismo dato ENLAZADO (Linked, no solo parecido) que el objeto activo: Object Data (misma malla/curva/etc. enlazada, típico tras duplicar con Alt+D en vez de Mayús+D), Material (mismo material asignado), Instanced Collection (misma Collection instanciada), Particle System (mismo sistema de partículas), Library / Library (Object Data) (mismo archivo .blend externo enlazado, en flujos de Link entre archivos). |
| 🖱️ | **Select: Select Pattern...** | *Barra superior del Viewport 3D > Select* | Intermediate | Abre un cuadro para escribir un patrón de texto (admite comodines * y ?) y seleccionar de golpe todos los objetos cuyo nombre coincida; por ejemplo 'Rock*' selecciona Rock01, Rock02, RockBig, etc. de una vez. |
| ⌨️ | **Select All** | <kbd>A</kbd> | Basic | Select All |
| ⌨️ | **Deselect All** | <kbd>Alt</kbd> + <kbd>A</kbd> | Basic | Deselect All |
| ⌨️ | **Box Select** | <kbd>B</kbd> | Basic | Box Select |
| ⌨️ | **Circle Select** | <kbd>C</kbd> | Basic | Circle Select |
| ⌨️ | **Invert Selection** | <kbd>Ctrl</kbd> + <kbd>I</kbd> | Intermediate | Invert Selection |
| ⌨️ | **Select More** | *Ctrl+Numpad +* | Intermediate | Select More |
| ⌨️ | **Select Less** | *Ctrl+Numpad -* | Intermediate | Select Less |
| ⌨️ | **Select Grouped** | <kbd>Mayús</kbd> + <kbd>G</kbd> | Advanced | Select Grouped |
| ⌨️ | **Select Linked** | <kbd>Mayús</kbd> + <kbd>L</kbd> | Advanced | Select Linked |
