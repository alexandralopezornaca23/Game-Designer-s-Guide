# Preferences > Save & Load: Blend Files


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💾 | **Save Prompt** | *Edit > Preferences > Save & Load* | Basic | Muestra un aviso de confirmación al cerrar Blender si hay cambios sin guardar. |
| 💾 | **Save Modified Images** | *Edit > Preferences > Save & Load* | Intermediate | Qué hacer con las imágenes/texturas editadas dentro de Blender al guardar; aquí 'Ask Every Time' pregunta cada vez. |
| 💾 | **Save Versions** | *Edit > Preferences > Save & Load* | Intermediate | Cuántas copias de seguridad numeradas (.blend1, .blend2...) guarda Blender de las versiones anteriores del archivo cada vez que guardas. |
| 📄 | **Recent Files** | *Edit > Preferences > Save & Load* | Basic | Cuántos archivos recuerda Blender en la lista de 'Open Recent'. |
| 💾 | **Auto-Save (Timer en minutos)** | *Edit > Preferences > Save & Load* | Basic | Guarda automáticamente una copia temporal cada X minutos (aquí 2), para poder recuperarla con Recover Auto Save si Blender se cierra mal. |
| 📄 | **File Preview Type** | *Edit > Preferences > Save & Load* | Advanced | Cómo se genera la miniatura de vista previa del archivo .blend en el explorador de archivos. |
| - | **Relative Paths** | *Edit > Preferences > Save & Load* | Intermediate | Al guardar, las rutas a texturas/archivos externos se guardan relativas a la ubicación del .blend en vez de absolutas; muy recomendable para poder mover la carpeta del proyecto sin romper enlaces. |
| 💾 | **Compress File** | *Edit > Preferences > Save & Load* | Intermediate | Comprime el .blend al guardarlo, reduciendo su tamaño en disco a cambio de un poco más de tiempo al guardar/abrir. |
| - | **Load UI** | *Edit > Preferences > Save & Load* | Intermediate | Al abrir un archivo, carga también la disposición de paneles/pantallas que tenía guardada, no solo la escena. |
| - | **Tabs as Spaces** | *Edit > Preferences > Save & Load* | Advanced | En el editor de texto/scripting, convierte las tabulaciones en espacios automáticamente (buena práctica en Python). |
| 🐍 | **Auto Run Python Scripts** | *Edit > Preferences > Save & Load* | Advanced | Permite que los scripts Python guardados dentro de un .blend se ejecuten automáticamente al abrirlo; desactivado por defecto por seguridad, ya que un .blend de origen desconocido podría traer código malicioso. |
