# File Browser > View


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Source List** | *Barra superior del File Browser > View* | Intermediate | Muestra/oculta el panel lateral izquierdo con accesos rápidos, dividido en 4 bloques plegables: Bookmarks (vacío por defecto; botón Add Bookmark para fijar aquí cualquier carpeta que uses a menudo), System (atajos a carpetas estándar del sistema operativo — Home, Desktop, Documents, Downloads, Music, Pictures, Videos, Fonts, OneDrive — más cualquier carpeta que el propio sistema tenga anclada, como 'Proyectos Unity' en la captura), Volumes (discos/unidades disponibles, ej. Disco local (C:), Nuevo vol (D:), Alex (E:)) y Recent (últimas carpetas abiertas; vacío en la captura enviada). |
| ⌨️ | **Source List** | <kbd>T</kbd> | Intermediate | Source List |
| - | **File Path** | *Barra superior del File Browser > View* | Basic | Activado por defecto: muestra el campo de ruta editable en la cabecera del editor. Si se desactiva, ese campo desaparece. |
| 🔍 | **Display Size: Tiny / Small / Medium / Big / Large** | *Barra superior del File Browser > View > Display Size* | Basic | Tamaño de icono/miniatura preestablecido para la lista de archivos; Small es el valor activo en la captura enviada. |
| 🧭 | **Recursion: None / One Level / Two Levels / Three Levels** | *Barra superior del File Browser > View > Recursion* | Intermediate | Cuántos niveles de subcarpetas se muestran mezclados en la lista además de la carpeta actual; None (por defecto) solo muestra el contenido directo de la carpeta abierta. |
