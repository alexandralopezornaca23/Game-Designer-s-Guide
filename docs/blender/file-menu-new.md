# File Menu: New


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📄 | **General** | *File > New* | Basic | Plantilla en blanco estándar: cámara, luz y un cubo. El punto de partida más habitual. |
| ✏️ | **2D Animation** | *File > New* | Intermediate | Arranca con el workspace de Grease Pencil ya configurado para animar en 2D dentro de Blender. |
| 🖌️ | **Sculpting** | *File > New* | Intermediate | Arranca con una malla base y el workspace de Sculpting activo, listo para esculpir sin configurar nada. |
| 🎞️ | **VFX** | *File > New* | Advanced | Layout orientado a compositing y tracking, con los editores de Movie Clip y Compositor ya a mano. |
| 🎞️ | **Video Editing** | *File > New* | Intermediate | Abre directamente el Video Sequence Editor, pensado para montar vídeo en vez de modelar/animar en 3D. |
