# Top Menu > Edit


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ↩️ | **Undo / Redo / Undo History** | *Barra superior > Edit / Ctrl+Z (Undo) / Ctrl+Mayús+Z (Redo)* | Basic | Undo History muestra una lista visual de pasos para saltar a uno concreto, no solo el anterior. |
| 🔁 | **Repeat Last / Repeat History** | *Barra superior > Edit* | Intermediate | Repite la última acción (equivalente a Mayús+R) o elige una acción anterior de la lista para repetirla. |
| ⚙️ | **Preferences...** | *Barra superior > Edit* | Basic | Abre las preferencias generales del programa: tema, atajos, add-ons, rutas de archivos, rendimiento. |
