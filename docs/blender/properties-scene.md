# Properties > Scene


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎥 | **Scene > Camera / Background Scene / Active Clip** | *Panel Properties > pestaña Scene* | Basic | Camera: qué cámara usa la escena para renderizar. Background Scene: muestra otra escena de Blender como fondo compuesto (útil para combinar dos escenas sin fusionarlas). Active Clip: clip de vídeo activo para Motion Tracking, vinculado al Movie Clip Editor. |
| 📏 | **Units (unidades)** | *Panel Properties > Scene > Units* | Intermediate | Sistema métrico/imperial y escala de la unidad. Revísalo siempre antes de exportar a Unity/Unreal para que las medidas cuadren. |
| - | **Units > Unit System / Unit Scale / Separate Units** | *Panel Properties > Scene > Units* | Intermediate | Unit System: None (unidades genéricas de Blender), Metric o Imperial. Unit Scale: factor de escala global de la unidad (p. ej. 0.01 si trabajas en cm en vez de metros). Separate Units: muestra medidas compuestas (p. ej. '1m 20cm' en vez de '1.2m'). |
| - | **Units > Rotation / Length / Mass / Time / Temperature** | *Panel Properties > Scene > Units* | Intermediate | Unidad mostrada en la interfaz para cada tipo de valor: Rotation (Degrees/Radians), Length (Meters/Kilometers/...), Mass (Kilograms/Grams/...), Time (Seconds/Frames), Temperature (Kelvin/Celsius/Fahrenheit) — solo cambia cómo se MUESTRAN los valores, no el resultado del render. |
| ⬇️ | **Gravity** | *Panel Properties > Scene > Gravity* | Intermediate | Fuerza de gravedad usada por las simulaciones físicas de la escena (activable/desactivable con el check junto al título del panel). |
| - | **Gravity > Gravity X / Y / Z** | *Panel Properties > Scene > Gravity* | Intermediate | Vector de gravedad en cada eje, en m/s². Por defecto solo Z tiene valor (-9.8 m/s², como la gravedad terrestre); cambiar X/Y inclina la dirección de caída, y poner Z en positivo invierte la gravedad. |
| - | **Simulation > Simulation Range / Start / End** | *Panel Properties > Scene > Simulation* | Advanced | Simulation Range: si está activado, fuerza a que TODAS las simulaciones de la escena (física, partículas, fluidos...) usen este rango de Start/End en vez de calcularlo cada una a su manera; útil para sincronizar varias simulaciones distintas al mismo tramo de tiempo. |
| 🔑 | **Keying Sets** | *Panel Properties > Scene > Keying Sets* | Advanced | Listas guardadas de propiedades concretas (posición, un material, un hueso...) que se insertan como keyframe TODAS A LA VEZ con un solo atajo, en vez de tener que animar cada propiedad por separado. |
| 🔊 | **Audio > Volume / Distance Model / Doppler Speed / Doppler Factor** | *Panel Properties > Scene > Audio* | Advanced | Volume: volumen global de toda la escena. Distance Model: cómo se atenúa el sonido con la distancia al oyente (Inverse Clamped por defecto). Doppler Speed/Factor: velocidad del sonido y cuánto se exagera el efecto Doppler (cambio de tono por movimiento) en la reproducción. |
| - | **Audio > Update Animation Cache** | *Panel Properties > Scene > Audio* | Advanced | Botón para forzar el recálculo de la caché de sonido/animación si el audio se ha desincronizado del vídeo tras editar. |
| 🪨 | **Rigid Body World** | *Panel Properties > Scene > Rigid Body World* | Advanced | Configura la caché y los fotogramas de las simulaciones de cuerpo rígido; se activa con el botón 'Add Rigid Body World' (antes de añadirlo no hay ninguna simulación de físicas rígidas corriendo en la escena, aunque los objetos tengan Rigid Body Constraints). |
| 🔮 | **Light Probes > Spheres Resolution / Bake All Light Probe Volumes** | *Panel Properties > Scene > Light Probes* | Advanced | Configuración global para el horneado (bake) de Light Probes de tipo esfera usados por EEVEE Next para iluminación indirecta; Spheres Resolution fija la resolución de textura de cada sonda, y el botón hornea de golpe todos los Light Probe Volumes de la escena. |
| 🔑 | **Animation (Scene) / Custom Properties** | *Panel Properties > Scene > Animation / Custom Properties* | Advanced | Animation: permite crear (New) una acción de animación asociada directamente a la propia escena (no a un objeto), para animar valores globales como el mundo o el compositor. Custom Properties: añade atributos propios a la escena, útiles para pipelines/scripts en Python. |
