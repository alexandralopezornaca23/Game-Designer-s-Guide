# Editor Type Selector: Data


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🗂️ | **Outliner** | *Icono de tipo de editor > Outliner (Mayús+F9)* | Basic | Convierte el panel activo en el árbol jerárquico de todos los objetos, colecciones y datos de la escena (ya documentado en detalle en su propia sección de la guía). |
| 📋 | **Properties** | *Icono de tipo de editor > Properties (Mayús+F7)* | Basic | Convierte el panel activo en el panel de Properties (Render, Output, Modifiers, Physics, Object Data...), ya documentado a fondo en esta guía. |
| 📁 | **File Browser** | *Icono de tipo de editor > File Browser (Mayús+F1)* | Basic | Convierte el panel activo en un explorador de archivos del sistema integrado en Blender, para navegar carpetas al importar/exportar/abrir archivos. |
| 🗃️ | **Asset Browser** | *Icono de tipo de editor > Asset Browser (Mayús+F1)* | Intermediate | Convierte el panel activo en el explorador de Asset Libraries (bibliotecas de materiales, pinceles, objetos, poses... marcados como Asset), para arrastrarlos directamente a la escena. |
| 📊 | **Spreadsheet** | *Icono de tipo de editor > Spreadsheet* | Advanced | Convierte el panel activo en una tabla de datos que muestra los atributos (Attributes) de la geometría activa vértice a vértice/cara a cara; muy usado para depurar Geometry Nodes. |
| ⚙️ | **Preferences** | *Icono de tipo de editor > Preferences* | Intermediate | Convierte el panel activo en las Preferences de Blender embebidas como un panel más (la misma ventana ya documentada a fondo en la sección Preferences de esta guía), en vez de abrirlas en su propia ventana. |
