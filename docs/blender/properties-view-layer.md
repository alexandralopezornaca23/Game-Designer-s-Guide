# Properties > View Layer


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📑 | **Lista de View Layers** | *Panel Properties > pestaña View Layer (arriba)* | Intermediate | Permite tener varias configuraciones de render de la misma escena (p. ej. una capa solo de personajes); cada View Layer de la lista tiene su propia combinación de Passes/Filter/Override de esta pestaña. |
| - | **View Layer > Use for Rendering / Render Single Layer** | *Panel Properties > View Layer* | Intermediate | Use for Rendering: si esta capa se incluye al renderizar toda la escena (desactívala para 'apagar' una capa sin borrarla). Render Single Layer: al renderizar, ignora todas las demás capas y solo procesa esta, útil para probar rápido una sola capa sin esperar a las demás. |
| 🧾 | **Passes (pasadas de render)** | *Panel Properties > View Layer > Passes* | Advanced | Genera capas separadas (profundidad, normales, difusa, especular...) que se pueden recombinar en el Compositor para retocar el render por partes en vez de sobre la imagen final ya mezclada. |
| - | **Passes > Data: Combined / Depth / Mist / Normal / Position / Vector / Grease Pencil** | *Panel Properties > View Layer > Passes > Data* | Advanced | Combined es la imagen final normal (activada por defecto). Depth: distancia de cada píxel a la cámara (para niebla/profundidad de campo en compositing). Mist: pasada de niebla independiente. Normal: dirección de la normal de cada superficie (para retocar iluminación). Position: posición 3D de cada píxel en el mundo. Vector: vector de movimiento de cada píxel (para motion blur en compositing). Grease Pencil: pasada separada solo con los trazos de Grease Pencil. |
| - | **Passes > Light: Diffuse / Specular / Volume / Other** | *Panel Properties > View Layer > Passes > Light* | Advanced | Diffuse y Specular (con sub-opciones Light y Color) separan la luz difusa y especular en su componente de luz pura y de color, para poder re-colorear o re-iluminar en compositing sin re-renderizar. Volume > Light: pasada solo de la luz que atraviesa volúmenes. Other agrupa: Emission (luz emitida por materiales emisivos), Environment (luz del World/HDRI), Shadow (sombras), Ambient Occlusion, Transparent (zonas transparentes). |
| - | **Passes > Light > Occlusion Distance** | *Panel Properties > View Layer > Passes > Light* | Advanced | Distancia máxima que se considera para calcular la pasada de Ambient Occlusion de esta View Layer (por defecto 10 m). |
| 🎭 | **Cryptomatte** | *Panel Properties > View Layer > Passes > Cryptomatte* | Advanced | Genera máscaras de selección automáticas y con anti-aliasing correcto, útiles para aislar objetos/materiales concretos en compositing sin tener que crearlas a mano. |
| - | **Cryptomatte > Object / Material / Asset / Levels** | *Panel Properties > View Layer > Passes > Cryptomatte* | Advanced | Object, Material y Asset generan una máscara Cryptomatte distinta según se quiera aislar por objeto individual, por material asignado o por Asset/colección. Levels controla la precisión: cuántos objetos/materiales superpuestos como máximo puede diferenciar Cryptomatte en un mismo píxel (más Levels = más precisión pero más peso). |
| 🧾 | **Shader AOV** | *Panel Properties > View Layer > Passes > Shader AOV* | Advanced | Lista de 'Arbitrary Output Variables' definidas por el usuario (con el botón +): permite sacar como pasada extra de render cualquier valor personalizado que se genere dentro de un Shader Editor (por ejemplo, una máscara o un ID creado a mano con nodos), para usarlo luego en compositing. |
| - | **Filter > Include: Environment / Surfaces / Curves / Volumes / Grease Pencil** | *Panel Properties > View Layer > Filter* | Intermediate | Qué tipos de contenido de la escena renderiza esta View Layer en concreto; desactivar alguno hace que esa View Layer ignore ese tipo de dato aunque exista en la escena (por ejemplo, una capa que solo quiera Surfaces sin Grease Pencil). |
| - | **Filter > Use: Motion Blur** | *Panel Properties > View Layer > Filter* | Intermediate | Si esta View Layer concreta aplica el Motion Blur configurado en Properties > Render (permite tener una capa con motion blur y otra sin él en la misma escena). |
| - | **Override: Material Override / World Override / Samples** | *Panel Properties > View Layer > Override* | Advanced | Material Override fuerza a que TODOS los objetos de esta View Layer se rendericen con un único material, ignorando el suyo propio (típico para pasadas de AO o de clay render). World Override sustituye el World/HDRI de la escena solo para esta capa. Samples, si es distinto de 0, sobreescribe el número de Samples de Render > Sampling únicamente para esta View Layer. |
| 🔖 | **Custom Properties** | *Panel Properties > View Layer > Custom Properties* | Advanced | Permite añadir (botón New) propiedades personalizadas propias a esta View Layer, útiles para pipelines/scripts en Python que necesiten guardar datos extra junto a la capa. |
