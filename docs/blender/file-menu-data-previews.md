# File Menu: Data Previews


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖼️ | **Refresh Data-Block Previews** | *File > Data Previews* | Advanced | Regenera las miniaturas (previews) de materiales, objetos, etc. que estén desactualizadas. |
| 🖼️ | **Batch-Generate Previews...** | *File > Data Previews* | Advanced | Genera en bloque las miniaturas que falten, sin tener que abrir cada dato uno a uno. |
| 🖼️ | **Clear Data-Block Previews...** | *File > Data Previews* | Advanced | Borra las miniaturas generadas, para forzar que se regeneren desde cero si se ven corruptas o desactualizadas. |
| 🖼️ | **Batch-Clear Previews...** | *File > Data Previews* | Advanced | Borra en bloque las miniaturas de varios tipos de datos a la vez. |
