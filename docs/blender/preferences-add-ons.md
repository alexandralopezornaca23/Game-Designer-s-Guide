# Preferences > Add-ons


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Enabled Only** | *Edit > Preferences > Add-ons* | Basic | Filtra la lista para mostrar solo los add-ons que ya tienes activados, en vez de todos los instalados. |
| 🧩 | **Casilla de activación (por add-on)** | *Edit > Preferences > Add-ons* | Basic | Activa o desactiva ese add-on concreto. Blender 5.2 LTS trae ya instalados varios de uso muy común (Cycles Render Engine, glTF 2.0 format, Node Wrangler, Rigify, Pose Library...), listos para activar sin descargar nada. |
| - | **Preferences del add-on (por add-on)** | *Edit > Preferences > Add-ons* | Intermediate | Cada add-on puede desplegar sus propias opciones; por ejemplo glTF 2.0 format permite elegir la ruta a gltfpack o activar Material Variants, y Cycles Render Engine permite elegir el dispositivo de cálculo (None/CPU, CUDA, OptiX, HIP, oneAPI). |
| 🧩 | **Node Wrangler** | *Edit > Preferences > Add-ons* | Intermediate | Add-on integrado muy recomendado para trabajar con nodos (Shading/Compositor): añade atajos para conectar, previsualizar y organizar nodos mucho más rápido. |
| 🦴 | **Rigify** | *Edit > Preferences > Add-ons* | Advanced | Add-on integrado para generar rigs (esqueletos con controles) automáticos a partir de plantillas de huesos; muy usado para personajes. |
| 🕺 | **Pose Library** | *Edit > Preferences > Add-ons* | Intermediate | Add-on integrado para guardar y reutilizar poses de un personaje como assets, dentro del sistema de Asset Browser. |
| 🥽 | **VR Scene Inspection** | *Edit > Preferences > Add-ons* | Advanced | Add-on integrado para ver el viewport con gafas de realidad virtual (head-mounted displays). |
| 🎬 | **Hydra Storm render engine** | *Edit > Preferences > Add-ons* | Advanced | Add-on integrado que añade Storm, un motor de renderizado rápido basado en USD, como alternativa a Cycles/EEVEE. |
| 🌐 | **Manage UI translations** | *Edit > Preferences > Add-ons* | Advanced | Add-on pensado para quienes colaboran traduciendo el interfaz de Blender a otros idiomas (gestiona los archivos .po). |
