# Modifier: Decimate


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Ratio (modo Collapse)** | *Dentro del modificador* | Basic | Porcentaje de los polígonos originales que se conservan; 0.5 = la mitad de los polígonos, aproximadamente. |
| - | **Modo Un-Subdivide** | *Dentro del modificador* | Advanced | Deshace subdivisiones en mallas con topología regular, dando un resultado más "limpio" que Collapse. |
| - | **Modo Planar** | *Dentro del modificador* | Advanced | Elimina vértices solo en zonas totalmente planas, sin cambiar la silueta general del modelo. |
