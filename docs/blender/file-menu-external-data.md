# File Menu: External Data


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📦 | **Automatically Pack Resources** | *File > External Data* | Intermediate | Empaqueta automáticamente texturas y demás datos externos dentro del .blend cada vez que guardas; cómodo, pero aumenta bastante el peso del archivo. |
| 📦 | **Pack Resources** | *File > External Data* | Intermediate | Empaqueta de una vez todas las texturas y datos externos dentro del .blend; útil antes de enviar el archivo a otra persona. |
| 📦 | **Unpack Resources** | *File > External Data* | Intermediate | Extrae de vuelta a archivos externos en disco las texturas y demás datos que estaban empaquetados dentro del .blend. |
| 📦 | **Pack Linked Libraries** | *File > External Data* | Advanced | Empaqueta dentro del .blend los datos que vienen enlazados (Link) desde otros archivos .blend, para que el archivo sea autónomo. |
| 📦 | **Unpack Linked Libraries** | *File > External Data* | Advanced | Extrae de vuelta a archivos externos los datos de librerías enlazadas que se habían empaquetado. |
| 🔗 | **Make Paths Relative** | *File > External Data* | Advanced | Convierte las rutas de las texturas externas a relativas respecto a la ubicación del .blend; esencial si vas a mover o compartir la carpeta del proyecto. |
| 🔗 | **Make Paths Absolute** | *File > External Data* | Advanced | Convierte las rutas relativas de vuelta a absolutas (ruta completa del sistema); útil si el archivo se va a quedar fijo en un disco. |
| 🔍 | **Find Missing Files** | *File > External Data* | Advanced | Busca en una carpeta que indiques las texturas que Blender no encuentra (por ejemplo tras mover el proyecto) y reconecta las rutas. |
| 📋 | **Report Missing Files** | *File > External Data* | Intermediate | Lista en la consola de Blender qué archivos externos no se están encontrando, sin intentar arreglarlo automáticamente. |
