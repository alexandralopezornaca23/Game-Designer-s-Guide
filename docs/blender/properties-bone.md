# Properties > Bone


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🦴 | **Bone: qué es esta pestaña y cuándo aparece** | *Panel Properties > Bone (icono de hueso)* | Intermediate | Pestaña EXTRA que solo aparece en la barra vertical de Properties cuando hay un Armature en Edit Mode o Pose Mode con un hueso activo/seleccionado (no existe en Object Mode). Contiene los datos propios de ESE hueso en concreto (forma Bendy Bone, parentesco, en qué Bone Collections está, cómo deforma la malla, cómo se dibuja), distintos de los datos generales de todo el Armature vistos en Properties > Object Data. |
| 〰️ | **Bone > Bendy Bones: Segments / Display Size X-Z / Vertex Mapping** | *Panel Properties > Bone > Bendy Bones* | Advanced | Convierte un hueso rígido en un hueso curvable tipo B-Bone. Segments (1 por defecto = hueso recto sin subdivisiones internas; más segmentos = curva más suave a lo largo del hueso). Display Size X/Z (0.10000/0.10000): grosor visual del hueso en el Viewport en cada eje. Vertex Mapping (desplegable, Straight verificado): cómo se reparte la influencia de deformación entre los distintos segmentos del B-Bone. |
| - | **Bone > Bendy Bones: Curve In-Out / Roll In-Out / Inherit End Roll** | *Panel Properties > Bone > Bendy Bones* | Advanced | Curve In/Out X y Z (0.00000): curvan la entrada y la salida del B-Bone en esos ejes, como los tiradores de una curva Bézier. Roll In/Out (0° cada uno): giran el hueso sobre su propio eje en el punto de entrada/salida. Inherit End Roll (desactivado): hace que el Roll Out herede automáticamente el Roll In del siguiente hueso conectado. |
| - | **Bone > Bendy Bones: Scale In-Out / Ease In-Out / Scale Easing** | *Panel Properties > Bone > Bendy Bones* | Advanced | Scale In/Out X/Y/Z (1.000 todos): escala el grosor del hueso en el punto de entrada y salida, para B-Bones más gruesos o finos en las puntas. Ease In/Out (0.000): suaviza esa curvatura cerca de las puntas. Scale Easing (desactivado): aplica ese mismo suavizado también a los valores de Scale In/Out. |
| - | **Bone > Bendy Bones: Start/End Handle (Automatic / Custom / Scale)** | *Panel Properties > Bone > Bendy Bones* | Advanced | Start Handle y End Handle (desplegable, Automatic verificado en ambos): de dónde saca el B-Bone la dirección para curvarse en cada punta, calculada sola según los huesos conectados. Custom permite fijar a mano otro hueso como referencia de esa curva. Los botones X/Y/Z/Ease bajo cada Handle activan qué componentes del hueso Custom afectan a la forma final. |
| - | **Bone > Relations: Parent / Relative Parenting / Connected / Local Location / Inherit Rotation / Inherit Scale** | *Panel Properties > Bone > Relations* | Intermediate | Parent: qué otro hueso es el padre de este dentro del esqueleto (vacío = hueso raíz). Relative Parenting (desactivado): calcula la posición relativa al padre al posar, no solo al crear el rig. Connected (deshabilitado aquí por no haber Parent asignado): si está activo, la base de este hueso queda fija a la punta del padre, sin poder separarse. Local Location (activado): se mueve en el espacio local del padre en vez del global. Inherit Rotation (activado): gira junto con su padre. Inherit Scale (desplegable, Full verificado): cuánto de la escala del padre hereda este hueso. |
| 📦 | **Bone > Bone Collections: asignación del hueso activo** | *Panel Properties > Bone > Bone Collections* | Intermediate | Muestra en qué Bone Collections está metido el hueso seleccionado (aquí "Bones", con sus iconos de ojo/estrella/X para mostrarla, marcarla como favorita o quitar a este hueso de esa colección); es la misma lista de colecciones de Properties > Object Data > Armature, pero filtrada a la asignación de este hueso en concreto. |
| - | **Bone > Deform: Envelope Distance / Weight / Multiply / Radius Head-Tail** | *Panel Properties > Bone > Deform* | Advanced | Deform (activado): si este hueso deforma o no la malla vinculada al mover el rig (se desactiva en huesos auxiliares que no deben afectar a la piel, como controladores de IK). Envelope Distance (0.25m) y Envelope Weight (1.000): alcance y fuerza de influencia cuando se deforma por Envelope en vez de por Vertex Groups pintados a mano. Envelope Multiply (desactivado): multiplica esa influencia por los pesos ya pintados en vez de sustituirlos. Radius Head/Tail (0.1m/0.05m): grosor de esa influencia (envelope) en la base y en la punta del hueso. |
| - | **Bone > Viewport Display: Selectable / Hide / Display As / Bone Color / Pose Bone Color** | *Panel Properties > Bone > Viewport Display* | Intermediate | Selectable (activado): permite o bloquea seleccionar este hueso haciendo clic en el Viewport. Hide (desactivado): lo oculta por completo. Display As (desplegable, Armature Defined verificado): con qué forma se dibuja este hueso en concreto, o que use la forma general definida en todo el Armature. Bone Color / Pose Bone Color (Default Colors en ambos): color de este hueso en Edit Mode y en Pose Mode respectivamente, independiente del color de su Bone Collection. |
| - | **Bone > Viewport Display > Custom Shape: Custom Object / Translation / Rotation / Scale** | *Panel Properties > Bone > Viewport Display > Custom Shape* | Advanced | Sustituye el dibujo por defecto del hueso (un octaedro) por la malla de cualquier otro objeto (Custom Object), la técnica estándar para poner controladores con forma de flecha, círculo, etc. en un rig de personaje. Translation/Rotation/Scale X/Y/Z: ajustan a mano la posición, giro y tamaño de esa forma personalizada respecto al hueso. |
| - | **Bone > Viewport Display > Custom Shape: Override Transform / Affect Gizmo / Use As Pivot / Scale to Bone Length / Wireframe / Wire Width** | *Panel Properties > Bone > Viewport Display > Custom Shape* | Advanced | Override Transform: usa la transformación de otro hueso (Pose Bone) para dibujar la forma personalizada, en vez de la de este hueso. Affect Gizmo (desactivado): si la forma personalizada también cambia el tamaño del gizmo de mover/rotar/escalar. Use As Pivot (desactivado): usa el centro de esa forma como punto de pivote. Scale to Bone Length (activado): la forma se estira sola para ajustarse a la longitud real del hueso. Wireframe (desactivado): la dibuja solo en líneas, sin rellenar. Wire Width (1.00): grosor de esas líneas si Wireframe está activo. |
| - | **Bone: Custom Properties** | *Panel Properties > Bone > Custom Properties* | Advanced | Añade (New) metadatos propios a este hueso en concreto, distintos de los del Object o de los datos generales del Armature. |
