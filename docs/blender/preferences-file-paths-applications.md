# Preferences > File Paths: Applications


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖼️ | **Image Editor** | *Edit > Preferences > File Paths* | Intermediate | Programa externo (Photoshop, GIMP...) que se abre al usar 'Edit Externally' sobre una imagen desde Blender. |
| 🎬 | **Animation Player** | *Edit > Preferences > File Paths* | Advanced | Reproductor usado para 'View Animation'; 'Internal' usa el propio visor de Blender en vez de un reproductor externo. |
