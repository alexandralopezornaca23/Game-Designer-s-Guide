# Properties > Object Data


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🧱 | **Malla: iconos +/- / lista desplegable / candado** | *Panel Properties > pestaña Object Data (icono de triángulo verde, en malla)* | Basic | Esta pestaña cambia por completo según el TIPO de objeto (malla, cámara, luz, curva, armature...); en una malla siempre aparecen Vertex Groups, Shape Keys, UV Maps, Color Attributes, Attributes, Texture Space, Remesh, Geometry Data, Animation y Custom Properties. Los datos concretos (cuántos UV Maps, qué Attributes...) dependen de la malla, pero estas herramientas y su estructura son EXACTAMENTE las mismas en un Cube que en una Sphere, un mono Suzanne o cualquier otra malla. |
| 👥 | **Vertex Groups** | *Panel Properties > pestaña Object Data > Vertex Groups* | Intermediate | Guarda qué vértices pertenecen a cada hueso y con qué peso; la base del Skinning/Weight Paint. Los botones +/- de la derecha añaden o quitan grupos, y la flecha despliega un menú de operaciones extra (Sort, Copy to Selected...). |
| 🗝️ | **Shape Keys: Add Rest Position** | *Panel Properties > Object Data > Shape Keys* | Intermediate | Guarda variaciones de la forma de la malla (por ejemplo, expresiones faciales) para mezclarlas por animación; el primer Shape Key es siempre 'Basis' (la forma de referencia). Add Rest Position añade un atributo con la posición de los vértices ANTES de aplicar Shape Keys, útil para que ciertos shaders/nodos lean la forma original sin deformar. |
| 🗺️ | **UV Maps** | *Panel Properties > Object Data > UV Maps* | Basic | Lista los mapas UV del objeto (puede tener más de uno, útil para lightmaps en motores de videojuego); el icono de cámara junto al nombre marca cuál se usa por defecto para previsualizar texturas. |
| 🌈 | **Color Attributes (vertex colors)** | *Panel Properties > Object Data > Color Attributes* | Intermediate | Color pintado directamente sobre los vértices o caras de la malla, sin necesidad de textura; cada entrada puede vivir en dominio Point (vértice) o Face Corner, y en formato Byte Color o Color (más precisión). |
| 📋 | **Attributes: nombre / dominio / tipo de dato** | *Panel Properties > Object Data > Attributes* | Advanced | Lista TODOS los atributos de la malla (geométricos, de UV, de color, personalizados...) con su Dominio (Vertex/Face/Face Corner/Edge) y tipo de dato (Vector, Boolean, 2D Vector...); por ejemplo 'position' (Vertex - Vector) son las coordenadas de cada vértice, 'sharp_face' (Face - Boolean) marca qué caras son duras para Shade Auto Smooth, y cada UV Map también aparece aquí como atributo (Face Corner - 2D Vector). Es la vista técnica/unificada de todos los datos que lleva la malla, útil sobre todo con Geometry Nodes. |
| 🖼️ | **Texture Space: Texture Mesh / Auto Texture Space / Location / Size** | *Panel Properties > Object Data > Texture Space* | Advanced | Define la caja invisible usada como referencia para coordenadas de textura tipo Generated (proyección automática sin UV Map). Texture Mesh permite tomar prestada la Texture Space de otra malla (para que dos objetos compartan el mismo patrón). Auto Texture Space la recalcula sola según el tamaño del objeto; si se desactiva, Location/Size se pueden ajustar a mano. |
| 🔁 | **Remesh: Mode Voxel/Quad / Voxel Size / Adaptivity / Fix Poles / Preserve Volume-Attributes** | *Panel Properties > Object Data > Remesh* | Advanced | Genera una topología nueva y limpia a partir de la malla actual (muy usado tras Sculpt). Mode Voxel crea una malla uniforme basada en un tamaño de vóxel (Voxel Size = resolución, Adaptivity simplifica zonas planas). Mode Quad genera quads siguiendo el flujo de la superficie. Fix Poles limpia polos problemáticos. Preserve Volume evita que el remesh encoja la forma; Preserve Attributes conserva Vertex Groups/Attributes tras el proceso. El botón Voxel Remesh ejecuta la operación. |
| 🧹 | **Geometry Data: Clear Sculpt Mask/Face Sets/Skin Data / Reorder Mesh Spatially / Add Custom Normals Data** | *Panel Properties > Object Data > Geometry Data* | Advanced | Operaciones de mantenimiento sobre datos internos de la malla: los tres Clear borran máscaras de Sculpt, Face Sets o datos del modifier Skin si ya no se necesitan (aparecen deshabilitados si la malla no tiene esos datos). Reorder Mesh Spatially reordena internamente vértices/caras según su posición en el espacio, mejorando el rendimiento de caché en mallas muy densas. Add Custom Normals Data añade un atributo para poder editar normales personalizadas a mano. |
| 🔑 | **Animation: Mesh (New)** | *Panel Properties > Object Data > Animation* | Intermediate | Crea (botón New) o gestiona la Action de animación asociada a los DATOS de la malla en sí (Shape Keys, Attributes...), distinta de la animación del OBJETO (posición/rotación/escala), que se gestiona en Properties > Object > Animation. |
| 🏷️ | **Custom Properties (Object Data)** | *Panel Properties > Object Data > Custom Properties* | Advanced | Añade propiedades personalizadas a los datos de la malla (Mesh), distintas de las Custom Properties del Object (que van ligadas al objeto, no a su malla); útil para guardar metadatos que deben viajar con los datos aunque se enlacen (Link) a otro objeto. |
| 🦴 | **Armature: Pose Position / Rest Position** | *Panel Properties > Object Data (icono de "palito") > Pose* | Intermediate | Pose Position (activo por defecto) muestra la pose animada/posada actual del esqueleto. Rest Position fuerza temporalmente a ver el Armature en su pose de reposo/bind (la T-pose original del rigging), sin animación ni ajustes de Pose Mode, útil para comparar o para hacer ciertos ajustes de modelado del mesh vinculado. |
| 🦴 | **Armature > Bone Collections: lista +/- / arriba-abajo** | *Panel Properties > Object Data > Bone Collections* | Intermediate | Sustituye a los antiguos "Bone Layers": agrupa huesos en colecciones con nombre (aquí "Bones") para organizar esqueletos con muchos huesos y mostrar/ocultar u operar solo sobre ciertos grupos. Cada fila de la lista tiene un icono de punto, un icono de ojo (mostrar/ocultar esa colección en el Viewport) y un icono de estrella (marcarla como favorita, para acceso rápido en otros menús). Los botones +/- añaden o quitan colecciones; las flechas arriba/abajo las reordenan. |
| 🏷️ | **Armature: Custom Properties (tras Bone Collections)** | *Panel Properties > Object Data > Custom Properties* | Intermediate | Botón New para añadir metadatos propios a los datos del Armature. Nota: en la captura este mismo panel "Custom Properties" vuelve a aparecer al final de la pestaña, tras Animation (ver más abajo); ambos son funcionalmente el mismo tipo de sección. |
| 🛤️ | **Motion Paths: Paths Type / Calculation Range / Frame Range Start-End / Step** | *Panel Properties > Object Data > Motion Paths* | Advanced | Dibuja en el Viewport la trayectoria del movimiento de los huesos a lo largo de los frames, para depurar o pulir una animación. Paths Type (desplegable, In Range verificado): calcula la trayectoria para un rango de frames. Calculation Range (desplegable, Scene Frame Range verificado): de dónde saca ese rango. Frame Range Start/End (1/250 por defecto, heredados del rango de la escena) y Step (cada cuántos frames se marca un punto de la trayectoria, 1 = cada frame). Bake to Active Camera aplana la trayectoria dibujada respecto a la cámara activa. "Nothing to show yet..." indica que aún no se ha calculado ninguna trayectoria; el botón Calculate... la genera y Update All Paths recalcula las ya existentes. |
| - | **Motion Paths > Display: Frame Numbers / Keyframes / +Non-Group / Keyframe Numbers** | *Panel Properties > Object Data > Motion Paths > Display* | Advanced | Checkboxes que controlan qué información extra se dibuja sobre la trayectoria calculada: Frame Numbers (número de frame en cada punto), Keyframes (resalta los frames que son keyframes, activado por defecto), +Non-Group Keyframes (incluye también keyframes de acciones sin agrupar), Keyframe Numbers (número de frame concreto en cada keyframe, activado por defecto). |
| 👁️ | **Armature > Viewport Display: Display As / Show Names-Shapes-Bone Colors-In Front / Axes / Relations** | *Panel Properties > Object Data > Viewport Display* | Intermediate | Display As (desplegable, Octahedral verificado por defecto): forma con la que se dibujan los huesos en el Viewport. Show Names/Shapes/Bone Colors/In Front: casillas para mostrar el nombre de cada hueso, sus formas personalizadas (Custom Shape) si tienen, el color asignado por Bone Collection, y dibujarlos siempre por delante de la malla (X-ray solo para huesos). Axes (Position 0.0): añade un pequeño indicador de ejes en cada hueso, desplazable a lo largo de él. Relations (Tail/Head): define si las líneas de parentesco entre huesos se dibujan conectando con la punta (Tail) o la base (Head) del hueso padre. |
| 🦾 | **Armature: Inverse Kinematics — IK Solver** | *Panel Properties > Object Data > Inverse Kinematics* | Advanced | IK Solver (desplegable, Standard verificado por defecto): algoritmo usado por todo el Armature para resolver las cadenas de Inverse Kinematics (IK) definidas en Pose Mode con los constraints de hueso IK. |
| 🖱️ | **Armature > Selection Sets: lista +/- / Assign / Remove / Select / Deselect** | *Panel Properties > Object Data > Selection Sets* | Advanced | Guarda grupos de huesos con nombre para seleccionarlos rápidamente en Pose Mode, independientemente de a qué Bone Collection pertenezcan (útil, por ejemplo, para guardar "toda la mano izquierda" como un set). Con huesos seleccionados en Pose Mode: + crea un Selection Set nuevo con esa selección, Assign añade la selección actual al set activo, Remove la quita del set, Select selecciona los huesos del set activo, Deselect los deselecciona. |
| 🔑 | **Armature: Animation / Custom Properties (final del panel)** | *Panel Properties > Object Data > Animation / Custom Properties* | Intermediate | Animation crea (New) una Action para los propios datos del Armature (Bone Collections, etc.), distinta de la animación del Object o de la Pose. Custom Properties (New) añade metadatos propios a los datos del Armature; es la segunda aparición de esta misma sección dentro de la pestaña, ver nota más arriba tras Bone Collections. |
| ➰ | **Curve: qué pestañas de Properties tiene (a diferencia de Cámara/Luz)** | *Panel Properties (varias pestañas)* | Intermediate | A diferencia de Cámara/Luz/Empty/Armature/Speaker, un objeto Curve SÍ conserva las pestañas Modifiers (admite modifiers como Array, Bevel, Mirror, Solidify...) y Material (se le puede aplicar color/textura, sobre todo cuando Fill Mode la convierte en superficie renderizable), porque sí tiene geometría real editable. La única que no tiene es Particles (los sistemas de partículas necesitan una superficie de malla). Physics y Object Constraints se mantienen igual que en cualquier objeto. |
| - | **Curve > Shape: 2D / 3D** | *Panel Properties > Object Data (icono de curva) > Shape* | Intermediate | 2D limita todos los puntos de control de la curva a su propio plano local (Z siempre a 0), pensado para logos/texto a extruir o rellenar. 3D (verificado, activo aquí) permite que los puntos tengan profundidad en cualquier eje, imprescindible por ejemplo para un camino de cámara o de animación con Follow Path que suba y baje. |
| - | **Curve > Shape: Resolution Preview U / Render U** | *Panel Properties > Object Data > Shape* | Intermediate | Cuántos segmentos rectos se dibujan entre cada dos puntos de control para aproximar la curva. Resolution Preview U (12 por defecto) afecta al Viewport. Render U (0 = usar el mismo valor que Preview U) permite forzar una resolución distinta solo para el render final, sin sobrecargar el Viewport. |
| - | **Curve > Shape: Twist Method / Smooth** | *Panel Properties > Object Data > Shape* | Advanced | Twist Method (desplegable, Minimum verificado): algoritmo con el que Blender calcula la orientación/giro a lo largo de la curva, usado al aplicar un Bevel con perfil no circular o al orientar objetos con Follow Path. Smooth (0.00): suaviza la transición de ese giro entre un punto de control y el siguiente. |
| - | **Curve > Shape: Fill Mode / Fill Solver / Fill Rule** | *Panel Properties > Object Data > Shape* | Advanced | Fill Mode (desplegable, Full verificado): cómo se rellena la sección transversal de la curva al extruirla o convertirla en superficie. Fill Solver (desplegable, Sweep Line verificado): algoritmo interno usado para calcular ese relleno. Fill Rule (Even-Odd, aparece deshabilitado en la captura porque no aplica con la configuración actual): regla para decidir qué zonas quedan dentro o fuera del relleno cuando el contorno se autointerseca. |
| - | **Curve > Shape: Curve Deform (Radius / Stretch / Bounds Clamp)** | *Panel Properties > Object Data > Shape > Curve Deform* | Advanced | Cómo afecta esta curva a otros objetos que la usan mediante un modifier Curve. Radius (activado por defecto): el grosor de cada punto de control también escala al objeto deformado. Stretch: estira el objeto para que ocupe toda la longitud de la curva. Bounds Clamp: limita la deformación a los límites (bounding box) del objeto original. |
| 🖼️ | **Curve > Texture Space: Auto Texture Space / Location / Size** | *Panel Properties > Object Data > Texture Space* | Advanced | Igual que en Mesh: define la caja invisible de referencia para coordenadas de textura tipo Generated. Auto Texture Space (activado) la calcula sola según el tamaño de la curva (por eso Location 0m/0m/0m y Size 2.000/1.000/1.000 aparecen en gris, de solo lectura). Match Texture Space la recalcula manualmente a partir de la geometría actual. |
| - | **Curve > Geometry: Offset / Extrude / Taper Object / Taper Radius / Map Taper** | *Panel Properties > Object Data > Geometry* | Intermediate | Offset (0m): desplaza hacia fuera/dentro el contorno ya biselado de la curva. Extrude (0m): añade grosor recto (sin redondear) a ambos lados de la curva a lo largo de su normal, la forma más simple de darle volumen. Taper Object: otro objeto Curve usado como perfil de grosor variable a lo largo de esta curva (por ejemplo, para que una serpiente se vaya estrechando hacia la cola). Taper Radius (desplegable, Override verificado): cómo se combina ese grosor del Taper con el Bevel propio. Map Taper (desactivado, en gris): remapea en qué punto de la curva se aplica cada parte del Taper. |
| 🔷 | **Curve > Geometry > Bevel: Round / Object / Profile** | *Panel Properties > Object Data > Geometry > Bevel* | Intermediate | 3 formas de dar sección transversal/grosor a la curva. Round (activo, verificado): usa un círculo simple, con Depth (0m, el radio del círculo) y Resolution (4, segmentos del círculo) como parámetros, más Fill Caps para tapar los extremos de la curva (desactivado). Object: usa otra curva 2D cualquiera como perfil de sección. Profile: usa una curva de perfil personalizada dibujada a mano dentro de este mismo panel. |
| - | **Curve > Geometry > Start & End Mapping: Factor Start-End / Mapping Start-End** | *Panel Properties > Object Data > Geometry > Start & End Mapping* | Advanced | Recorta qué tramo de la curva se dibuja realmente. Factor Start/End (0.000/1.000 por defecto, o sea la curva completa): define el tramo visible en una escala de 0 a 1. Mapping Start/End (desplegable, Resolution verificado en ambos): en qué unidad se mide ese recorte (por puntos de resolución; existen otras unidades típicas en Blender como Length, no verificadas en esta captura). |
| 🔑 | **Curve > Geometry > Path Animation: Frames / Evaluation Time / Clamp / Follow** | *Panel Properties > Object Data > Geometry > Path Animation* | Intermediate | Activa (checkbox marcado) que otro objeto pueda recorrer esta curva con un constraint Follow Path. Frames (100): número de frames que tarda en recorrer la curva entera. Evaluation Time (0.000): fija/anima manualmente en qué punto exacto de la curva está el objeto, en vez de depender directamente del frame actual. Clamp evita que el objeto se salga del recorrido si el frame supera el valor de Frames. Follow gira automáticamente el objeto para que su eje apunte en la dirección de avance sobre la curva. |
| 🗝️ | **Curve > Shape Keys: lista +/-** | *Panel Properties > Object Data > Shape Keys* | Advanced | Igual que en Mesh: permite crear formas alternativas (morph targets) de los mismos puntos de control de la curva e interpolar entre ellas con un valor de 0 a 1 (lista vacía en la captura, sin Shape Keys creadas todavía). |
| 🔑 | **Curve: Animation / Custom Properties** | *Panel Properties > Object Data > Animation / Custom Properties* | Intermediate | Animation crea (New) una Action para los propios datos de la curva (puntos de control, Shape Keys...), distinta de la animación del Object (posición/rotación/escala). Custom Properties (New) añade metadatos propios a los datos de la curva. |
| 🔤 | **Text: qué pestañas de Properties tiene (comparado con Curve)** | *Panel Properties (varias pestañas)* | Intermediate | Confirmado por captura de la barra vertical de Properties: igual que Curve, Text SÍ conserva Modifiers y Material (tiene geometría real de contornos extruibles/biselables), y le falta Particles (no verificado en captura si Physics/Object Constraints muestran alguna limitación extra respecto a Curve, se asume igual por tener el mismo tipo de geometría vectorial). |
| - | **Text > Shape: Resolution Preview U / Render U / Fast Editing** | *Panel Properties > Object Data > Shape* | Intermediate | Resolution Preview U/Render U funcionan igual que en Curve (segmentos con los que se dibuja el contorno de cada letra). Fast Editing (exclusivo de Text, no visto en Curve): al activarlo, muestra el texto con una fuente simplificada/monoespaciada mientras se escribe en Edit Mode, para que escribir vaya fluido incluso con tipografías complejas o mucho texto, y solo calcula el contorno real al salir de Edit Mode. |
| - | **Text > Shape: Fill Mode / Fill Solver / Fill Rule** | *Panel Properties > Object Data > Shape* | Advanced | Mismos campos que Curve > Shape, aquí con sus propios valores verificados para texto: Fill Mode Both (rellena el interior de cada letra). Fill Solver Delaunay (algoritmo distinto al Sweep Line de Curve, mejor adaptado a las formas complejas de una tipografía). Fill Rule Non-Zero (distinta a la Even-Odd de Curve; con Non-Zero los huecos de letras como la O o la A se recortan correctamente incluso con contornos complejos o solapados). |
| 🖼️ | **Text > Texture Space / Geometry: misma estructura que Curve** | *Panel Properties > Object Data > Texture Space / Geometry* | Intermediate | Confirmado por captura: comparte exactamente los mismos campos ya documentados en Curve > Texture Space (Auto Texture Space/Location/Size) y Curve > Geometry (Offset/Extrude/Taper Object/Taper Radius/Map Taper, más el sub-panel Bevel con Round/Object/Profile, Depth, Resolution, Fill Caps), con los mismos valores por defecto (Extrude 0m, Bevel Round con Depth 0m/Resolution 4). |
| 🅰️ | **Text > Font: Regular / Bold / Italic / Bold & Italic** | *Panel Properties > Object Data > Font* | Basic | 4 slots de tipografía, uno por estilo (aquí los 4 con la fuente por defecto Bfont Regular asignada). Cada slot admite un archivo de fuente distinto (botón de carpeta para cargar uno propio); Blender aplica el estilo correcto automáticamente al marcar una porción de texto como negrita/cursiva en Edit Mode. |
| - | **Text > Font > Transform: Size / Shear / Object Font / Text on Curve / Underline Position-Thickness / Small Caps Scale** | *Panel Properties > Object Data > Font > Transform* | Intermediate | Size: tamaño general del texto. Shear: inclina las letras tipo cursiva forzada, sin depender de que la fuente tenga un estilo Italic real. Object Font: usa la malla de otro objeto como 'fuente' personalizada letra a letra (técnica avanzada para tipografías 3D hechas a mano). Text on Curve: hace que el texto siga la forma de un objeto Curve indicado aquí, para texto curvado. Underline Position/Thickness: ajustan el grosor y la altura del subrayado (con Underline activado sobre el texto en Edit Mode). Small Caps Scale: tamaño relativo de las mayúsculas pequeñas al usar el estilo Small Caps. |
| - | **Text > Paragraph > Alignment: Horizontal / Vertical** | *Panel Properties > Object Data > Paragraph > Alignment* | Intermediate | Horizontal (desplegable, Left verificado; existen también Center/Right/Justify/Flush no verificados aquí): alineación del texto dentro de su caja. Vertical (Top Baseline verificado): desde qué línea de referencia arranca el texto verticalmente. |
| - | **Text > Paragraph > Spacing: Character / Word / Line Spacing / Offset X-Y** | *Panel Properties > Object Data > Paragraph > Spacing* | Intermediate | Character/Word/Line Spacing (1.000 = espaciado normal): multiplicadores del espacio entre letras, palabras y líneas respectivamente. Offset X/Y (0m/0m): desplaza en bloque todo el texto sin mover el punto de origen del objeto. |
| 🔲 | **Text > Text Boxes: Add Text Box / Overflow / Size X-Y / Offset X-Y** | *Panel Properties > Object Data > Text Boxes* | Advanced | Add Text Box crea una o varias cajas de texto encadenadas: si el texto no cabe en la primera, continúa automáticamente en la siguiente, como en maquetación editorial. Overflow (desplegable, Overflow verificado: deja que el texto sobresalga de la caja si no cabe; existen otras opciones no verificadas aquí como recortarlo o escalarlo para que quepa). Cada caja tiene su propio Size X/Y (0m = sin límite) y Offset X/Y para posicionarla; la X roja la elimina. |
| 🔑 | **Text: Animation (Text Curve) / Custom Properties** | *Panel Properties > Object Data > Animation / Custom Properties* | Intermediate | Animation crea (New) una Action para los propios datos de Text Curve (contenido, tamaño, spacing...), distinta de la animación del Object. Custom Properties (New) añade metadatos propios a los datos de texto. |
| 🫧 | **Metaball: qué es** | — | Basic | Un tipo de objeto que genera su superficie de forma procedural fusionándose suavemente con otras Metaballs cercanas, como gotas de metal líquido o mercurio (de ahí el nombre) — sin necesidad de modelar la unión a mano. Varias Metaballs que compartan el mismo nombre base (Mball, Mball.001, Mball.002...) se tratan como una única 'familia' y se fusionan entre sí en el Viewport/render; Metaballs con nombre base distinto no se fusionan. Muy usadas para bocetar rápido formas orgánicas (blobs, criaturas, gotas de líquido) antes de convertirlas en malla real con Object > Convert > Mesh. |
| 🫧 | **Metaball: qué pestañas de Properties tiene (a diferencia de Curve/Text)** | *Panel Properties (varias pestañas)* | Intermediate | Confirmado por la barra vertical de Properties: a diferencia de Curve y Text (que sí conservan Modifiers), Metaball NO tiene ni Modifiers ni Particles — probablemente porque su geometría ya se calcula de forma 100% procedural fusionándose con otras Metaballs, sin una malla real sobre la que aplicar un stack de modifiers tradicional. SÍ conserva Physics, Object Constraints, Material y Texture, igual que Curve/Text. |
| - | **Metaball > Metaball: Resolution Viewport / Render** | *Panel Properties > Object Data > Metaball* | Intermediate | Tamaño de la rejilla (vóxel) usada para calcular la superficie fusionada: Resolution Viewport (0.4m verificado) afecta a cómo se ve en tiempo real en el Viewport. Render (0.2m verificado, más fino que Viewport) se usa solo para el render final, para tener buen rendimiento al trabajar sin perder calidad en el resultado. |
| - | **Metaball > Metaball: Influence Threshold / Update on Edit** | *Panel Properties > Object Data > Metaball* | Advanced | Influence Threshold (0.600 verificado): a partir de qué 'densidad' combinada de las Metaballs cercanas se considera que ahí hay superficie sólida; subirlo encoge la forma resultante, bajarlo la infla/hincha. Update on Edit (desplegable, Always verificado): cuándo se recalcula la superficie fusionada mientras se edita (Always = en tiempo real; existen otras opciones pensadas para aligerar el Viewport en escenas con muchas Metaballs, no verificadas en esta captura). |
| 🖼️ | **Metaball > Texture Space** | *Panel Properties > Object Data > Texture Space* | Advanced | Misma estructura ya documentada en Mesh/Curve/Text: Auto Texture Space (activado) calcula sola la caja de referencia para coordenadas Generated según el tamaño de la Metaball, dejando Location (0m/0m/0m) y Size (1.000/1.000/1.000) de solo lectura. |
| 🔑 | **Metaball: Animation / Custom Properties** | *Panel Properties > Object Data > Animation / Custom Properties* | Intermediate | Animation crea (New) una Action para los propios datos de la Metaball. Custom Properties (New) añade metadatos propios a esos datos. |
| ✏️ | **Grease Pencil: qué es y por qué cambia según el sub-tipo** | — | Basic | Tipo de objeto para dibujar trazos 2D (stroke-based, no malla) directamente en el espacio 3D, usado tanto para animación 2D tradicional dentro de Blender como para storyboards, concept art o efectos tipo 'dibujado a mano' sobre escenas 3D. Al añadirlo (Add > Grease Pencil) hay varios sub-tipos (Blank, Stroke, Monkey...): confirmado por captura que solo cambia el contenido del panel Layers (algunos vienen con más capas/trazos ya creados de fábrica), el resto de la estructura de Object Data es idéntica en todos. |
| ✏️ | **Grease Pencil: qué pestañas de Properties tiene (a diferencia de Mesh/Curve/Text/Metaball)** | *Panel Properties (varias pestañas)* | Intermediate | Confirmado por captura: Grease Pencil añade una pestaña EXTRA y exclusiva suya, Effects (icono de estrella), que no existe en ningún otro tipo de objeto visto hasta ahora. No verificado en esta tanda de capturas si Modifiers/Particles están presentes o ausentes para Grease Pencil (pendiente confirmar con una captura de la barra vertical completa de iconos). |
| 🗂️ | **Grease Pencil > Layers: Layer (entrada) - Blend Mode / Opacity / Lights** | *Panel Properties > Object Data > Layers* | Intermediate | Cada capa de dibujo aparece como una entrada en esta lista (aquí una única 'Layer', en Grease Pencil tipo Blank). | 💡 | **Point: Radius / Soft Falloff** | *Panel Properties > Object Data > Light (Point)* | Intermediate | Radius: tamaño físico de la bombilla (0 = punto matemático perfecto con sombras muy duras; mayor Radius = sombras más suaves y difusas, como una bombilla real con superficie). Soft Falloff (activado): suaviza la caída de intensidad de la luz cerca de su origen, evitando puntos sobreexpuestos justo debajo de la luz. |
| 💡 | **Sun: Temperature / Color / Strength / Exposure / Normalize** | *Panel Properties > Object Data > Light (Sun)* | Intermediate | Sun simula una luz paralela infinita (como el sol real): su posición en la escena no importa, solo su ROTACIÓN define la dirección de los rayos. Temperature/Color/Exposure/Normalize funcionan igual que en Point. Strength sustituye a Power: se mide en irradiancia (W/m², intensidad por unidad de superficie) en vez de vatios totales, porque una luz infinita no tiene una 'potencia total' con sentido físico. |
| 💡 | **Sun: Angle** | *Panel Properties > Object Data > Light (Sun)* | Intermediate | Sustituye al Radius de Point: es el diámetro angular del disco solar visto desde la escena, en grados (11.4° por defecto, similar al sol real ~0.5° da sombras muy nítidas).
