# Modifier: Bevel


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Amount** | *Dentro del modificador* | Basic | Cuánto material se achafla desde la arista original (distancia). |
| - | **Segments** | *Dentro del modificador* | Basic | Nº de caras que forman el chaflán: 1 = corte recto, varios = curva redondeada. |
| - | **Limit Method (Angle/Weight/Vertex Group)** | *Dentro del modificador* | Intermediate | Qué aristas se biselan: por el ángulo entre caras, por un peso puesto a mano (Bevel Weight), o por un grupo de vértices. |
| - | **Shape** | *Dentro del modificador* | Advanced | Curvatura del perfil del bisel, de totalmente plano a muy redondeado (tipo "superelipse"). |
| - | **Miter (Outer/Inner)** | *Dentro del modificador* | Advanced | Cómo se resuelven las esquinas donde se cruzan varios biseles a la vez (en punta, redondeadas, cortadas...). |
