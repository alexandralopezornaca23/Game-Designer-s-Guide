# T Panel: Pose Mode


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Herramientas: solo las comunes, sin exclusivas** | <kbd>Barra T (Pose Mode)</kbd> | Basic | Confirmado por captura real: Pose Mode NO añade ninguna herramienta exclusiva a la Barra T, a diferencia de Object Mode (Breakdowner) o Edit Mode Armature (B-Bone Size/Bone Envelope, Extrude). Muestra únicamente las 9 herramientas comunes a todos los modos (ver 'Barra T: Comunes a todos los modos': Select Box/Tweak, Cursor, Move, Rotate, Scale, Transform, Annotate, Measure, Add Cube), en el mismo orden que en Object Mode, aplicadas aquí a los huesos (Pose Bones) seleccionados. |
