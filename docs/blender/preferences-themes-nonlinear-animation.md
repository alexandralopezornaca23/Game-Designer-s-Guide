# Preferences > Themes: Nonlinear Animation


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔑 | **Strips del NLA** | *Edit > Preferences > Themes > Nonlinear Animation* | Advanced | Colorea cada tipo de bloque (strip) del editor NLA según su función: Active Action/No Active Action (si el objeto tiene una acción activa siendo editada), Strips/Strips Selected (bloques normales), Transitions/Transitions Selected (mezclas entre strips), Meta Strips/Meta Strips Selected (strips que agrupan otros dentro), Sound Strips/Sound Strips Selected, Tweak (modo edición dentro de un strip) y Tweak Duplicate Flag, más Keyframe Border/Keyframe Border Selected para los keyframes visibles dentro de un strip. |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Nonlinear Animation > Theme Space* | Basic | Mismo patrón repetido en todos los editores (colapsado en la captura). |
