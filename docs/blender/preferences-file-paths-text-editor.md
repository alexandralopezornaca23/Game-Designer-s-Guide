# Preferences > File Paths: Text Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔤 | **Program** | *Edit > Preferences > File Paths* | Advanced | Editor de texto/código externo (VS Code, Sublime...) que se abre al usar 'Edit Externally' sobre un script desde el editor de texto de Blender. |
| - | **Arguments** | *Edit > Preferences > File Paths* | Advanced | Argumentos de línea de comandos que se pasan a ese programa externo al abrirlo, por ejemplo para indicarle en qué línea abrir el archivo. |
