# Preferences > Animation: F-Curves


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Unselected Opacity** | *Edit > Preferences > Animation > F-Curves* | Advanced | Transparencia con la que se dibujan en el Graph Editor las curvas de animación NO seleccionadas, para resaltar visualmente la que sí lo está. |
| - | **Default Smoothing** | *Edit > Preferences > Animation > F-Curves* | Advanced | Método de suavizado aplicado por defecto a las curvas nuevas (aquí 'Continuous Acceleration', el más suave y recomendado para animación de personajes). |
| - | **Default Interpolation** | *Edit > Preferences > Animation > F-Curves* | Basic | Tipo de interpolación con la que se crean los keyframes nuevos por defecto (aquí Bézier, la más habitual para animar de forma orgánica). |
| - | **Default Handles** | *Edit > Preferences > Animation > F-Curves* | Intermediate | Tipo de manejadores (handles) de los keyframes Bézier nuevos (aquí 'Auto Clamped', que evita que la curva se pase de largo sin tener que ajustarlo a mano). |
| - | **XYZ to RGB** | *Edit > Preferences > Animation > F-Curves* | Basic | Colorea las curvas de los canales X/Y/Z de posición, rotación o escala en rojo/verde/azul, para identificarlas de un vistazo en el Graph Editor. |
| - | **Channel Group Colors** | *Edit > Preferences > Animation > F-Curves* | Advanced | Usa el color asignado al grupo de canales (p. ej. un bone group) para colorear también sus curvas en el Graph Editor. |
| - | **Only Show Selected Curve Keyframes** | *Edit > Preferences > Animation > F-Curves* | Advanced | En el Dopesheet/Graph Editor, muestra solo los keyframes de las curvas seleccionadas, ocultando el resto para no saturar la vista (el texto aparece truncado en el menú como 'Only Show Se...ve Keyframes'). |
| - | **F-Curve High Quality Drawing** | *Edit > Preferences > Animation > F-Curves* | Advanced | Dibuja las curvas del Graph Editor con antialiasing/mayor calidad visual; puede afectar algo al rendimiento con escenas muy grandes. |
