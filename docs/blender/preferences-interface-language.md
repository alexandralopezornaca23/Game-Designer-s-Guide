# Preferences > Interface: Language


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🌐 | **Language** | *Edit > Preferences > Interface > Language* | Basic | Idioma de todo el interfaz de Blender. |
| - | **Translate (Tooltips/Interface/Reports/New Data)** | *Edit > Preferences > Interface > Language* | Basic | Qué partes exactas del programa se traducen cuando el idioma no es inglés; puedes, por ejemplo, traducir el interfaz pero dejar los tooltips en inglés. |
| - | **Date Format** | *Edit > Preferences > Interface > Language* | Advanced | Formato en que Blender muestra las fechas (por ejemplo en el explorador de archivos). |
| - | **Time** | *Edit > Preferences > Interface > Language* | Advanced | Formato de hora, 24 horas o 12 horas (AM/PM). |
