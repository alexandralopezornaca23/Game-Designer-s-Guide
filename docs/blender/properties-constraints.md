# Properties > Constraints


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ⛓️ | **Add Object Constraint: categorías** | *Panel Properties > pestaña Object Constraints > Add Object Constraint* | Intermediate | Los 27 Object Constraints de Blender se agrupan en 4 categorías: Motion Tracking (vincula objetos al tracking de vídeo), Transform (copian o limitan la transformación de otro objeto), Tracking (hacen que un objeto 'mire' o siga a otro) y Relationship (relaciones más complejas: jerarquía, rigs, caminos, atributos de geometría...). Se pueden añadir varios Constraints al mismo objeto; se ejecutan en orden, de arriba a abajo en la pila. |
| - | **Cabecera común: icono ojo / flecha desplegar / X / Influence** | *Panel Properties > Object Constraints (cabecera de cada Constraint)* | Basic | Todo Constraint comparte esta cabecera: el icono de ojo lo activa/desactiva (en viewport y render) sin borrarlo, la flecha despliega/colapsa sus opciones, el icono de puntos permite arrastrarlo para reordenar la pila, y la X lo elimina. El slider Influence (0 a 1, siempre al final) controla cuánto se aplica su efecto — 0 = como si no existiera, 1 = efecto completo — y se puede animar con keyframes para que el constraint entre en acción gradualmente. |
| - | **Target Space / Owner Space (común a varios Constraints)** | *Panel Properties > Object Constraints (varios paneles)* | Advanced | Cuando un Constraint usa un objeto Target, estos desplegables definen en qué sistema de coordenadas se lee la transformación del Target (Target) y en cuál se aplica al objeto que tiene el constraint (Owner): World Space (espacio global de la escena, el más habitual) u otras opciones relativas a padres/Armature — importante para que el constraint se comporte bien dentro de jerarquías. |
| ⛓️ | **Motion Tracking > Camera Solver: Active Clip** | *Panel Properties > Object Constraints > Add Object Constraint > Motion Tracking* | Advanced | Solo tiene sentido en un objeto Cámara: calcula automáticamente su posición y rotación reales a partir de un tracking 3D resuelto en el Movie Clip Editor. Active Clip usa el clip activo de la escena en vez de tener que elegirlo a mano. |
| ⛓️ | **Motion Tracking > Follow Track: Active Clip / 3D Position / Undistort / Frame Method / Camera / Depth Object** | *Panel Properties > Object Constraints > Add Object Constraint > Motion Tracking* | Advanced | Ata cualquier objeto (no solo la cámara) a un punto de tracking 2D concreto del clip. 3D Position usa la posición 3D ya reconstruida del punto en vez de proyectarlo en 2D. Undistort corrige la distorsión de lente. Frame Method ajusta cómo encaja la imagen de fondo en el encuadre (Stretch la estira). Camera y Depth Object dan la referencia de perspectiva/profundidad para proyectar el punto. |
| ⛓️ | **Motion Tracking > Object Solver: Active Clip / Camera / Set Inverse** | *Panel Properties > Object Constraints > Add Object Constraint > Motion Tracking* | Advanced | Aplica a un objeto la transformación calculada por el tracking de OBJETOS (Object Tracking, no de cámara) de un clip. Set Inverse fija un desfase para que el objeto conserve su posición actual en el momento de añadir el constraint, en vez de saltar de golpe a la del tracking; Clear Inverse lo revierte. |
| ⛓️ | **Transform > Copy Location: Axis X/Y/Z / Invert X/Y/Z / Offset** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Copia la posición del objeto Target. Axis activa qué ejes se copian (puede copiar solo Z, por ejemplo, para igualar altura). Invert copia el eje con el signo cambiado. Offset suma la posición copiada a la posición actual del objeto en vez de sustituirla. |
| ⛓️ | **Transform > Copy Rotation: Order / Axis X/Y/Z / Invert X/Y/Z / Mix** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Copia la rotación del Target. Order define el orden de ejes de Euler usado para descomponer la rotación. Axis/Invert igual que en Copy Location pero para rotación. Mix define cómo se combina con la rotación previa del objeto: Replace la sustituye, otras opciones (Add/Before/After Original) la suman. |
| ⛓️ | **Transform > Copy Scale: Axis X/Y/Z / Power / Make Uniform / Offset / Additive** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Copia la escala del Target. Power aplica un exponente a la escala copiada (2 = la eleva al cuadrado). Make Uniform usa el mismo valor de escala en los 3 ejes en vez de copiar cada eje por separado. Offset/Additive suman la escala copiada a la actual en vez de sustituirla, de forma multiplicativa o aditiva. |
| ⛓️ | **Transform > Copy Transforms: Remove Target Shear / Mix** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Copia posición, rotación y escala del Target de una vez (equivale a los tres Copy anteriores juntos). Remove Target Shear corrige distorsiones de cizalla que puede arrastrar el Target. Mix define cómo se combina con la transformación previa del objeto. |
| ⛓️ | **Transform > Limit Distance: Distance / Clamp Region / Affect Transform** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Impide que el objeto se aleje o acerque más de una Distance al Target. Clamp Region define la zona permitida: Inside (dentro del radio), Outside (fuera) o On Surface (justo en el borde). Affect Transform hace que el límite se refleje también en los valores de Transform del objeto (N-panel), no solo visualmente. |
| ⛓️ | **Transform > Limit Location: Minimum/Maximum X/Y/Z / Affect Transform** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Restringe la posición del objeto dentro de un rango por eje (cada Minimum/Maximum se activa por separado con su casilla). Sin Target: limita en coordenadas absolutas de la escena. Útil para evitar que un objeto animado o controlado por el usuario salga de una zona. |
| ⛓️ | **Transform > Limit Rotation: Limit X/Y/Z (Min/Max) / Order / Affect Transform / Legacy Behavior** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Restringe la rotación del objeto por eje a un rango de ángulos. Order define el orden de ejes de Euler usado. Legacy Behavior usa el método de cálculo de versiones antiguas de Blender por compatibilidad. |
| ⛓️ | **Transform > Limit Scale: Minimum/Maximum X/Y/Z / Affect Transform** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Intermediate | Restringe la escala del objeto por eje a un rango mínimo/máximo, evitando que se encoja o crezca más de la cuenta (por ejemplo, en rigs con controladores que el animador puede escalar libremente). |
| ⛓️ | **Transform > Maintain Volume: Mode / Free Axis / Volume** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Advanced | Compensa automáticamente los otros ejes al escalar uno, simulando que el objeto conserva su volumen (como un músculo al estirarse). Free Axis: el eje que se escala libremente (los otros se ajustan para compensar). Mode: Strict (volumen exacto) o versiones más suaves. Volume: el volumen de referencia a mantener. |
| ⛓️ | **Transform > Transformation: Target / Extrapolate** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Advanced | El más flexible de los Transform: convierte un rango de transformación del Target (Map From) en otro rango de transformación distinto aplicado al objeto (Map To), pudiendo incluso mezclar tipos (p. ej. que la rotación del Target controle la posición del objeto). Extrapolate permite que la conversión siga funcionando fuera del rango Min/Max definido, en vez de quedar fija en el límite. |
| - | **Transform > Transformation > Map From / Map To: Location / Rotation / Scale, Source Axis, Mix** | *Panel Properties > Object Constraints > Add Object Constraint > Transform > Transformation* | Advanced | Map From define, con pestañas Location/Rotation/Scale, el rango de entrada del Target (Min/Max por eje) que se va a leer. Map To define el rango de salida aplicado al objeto, con Source Axis para remapear un eje de entrada a otro de salida distinto, y Mix (Replace/Add...) para combinarlo con la transformación previa del objeto. |
| ⛓️ | **Transform > Transform Cache: Open / Time / Velocity / Override Layers** | *Panel Properties > Object Constraints > Add Object Constraint > Transform* | Advanced | Aplica al objeto la transformación guardada en un archivo de caché externo (Alembic/USD) mediante el botón Open para elegirlo. Time controla el desfase/escala temporal de la reproducción de esa caché. Velocity y Override Layers (paneles colapsados) afinan el cálculo de movimiento y permiten sustituir capas concretas del archivo de caché. |
| ⛓️ | **Tracking > Clamp To: Target / Main Axis / Cyclic** | *Panel Properties > Object Constraints > Add Object Constraint > Tracking* | Intermediate | Obliga al objeto a moverse siempre pegado a una curva Target, aunque se mueva libremente en la escena (proyecta su posición sobre la curva). Main Axis: el eje de la curva usado como referencia principal (Auto lo detecta solo). Cyclic: si la curva se trata como un bucle cerrado. |
| ⛓️ | **Tracking > Damped Track: Target / Track Axis** | *Panel Properties > Object Constraints > Add Object Constraint > Tracking* | Intermediate | Hace que el eje Track Axis del objeto apunte siempre hacia el Target, con una rotación suave y sin el efecto de 'volteo' brusco (gimbal flip) que puede dar Track To; el más usado para que cámaras o luces sigan a un objeto. |
| ⛓️ | **Tracking > Locked Track: Target / Track Axis / Locked Axis** | *Panel Properties > Object Constraints > Add Object Constraint > Tracking* | Intermediate | Igual que Damped Track (el Track Axis apunta al Target), pero fijando además un Locked Axis que nunca gira — típico para que un objeto mire a otro sin inclinarse ni volcarse, manteniendo siempre su eje 'arriba' fijo. |
| ⛓️ | **Tracking > Stretch To: Target / Original Length / Volume Variation / Volume Min/Max / Smooth / Maintain Volume / Rotation** | *Panel Properties > Object Constraints > Add Object Constraint > Tracking* | Advanced | Estira al objeto para que siempre llegue hasta el Target, como una goma elástica (muy usado en huesos IK tipo 'stretchy bones'). Original Length: longitud de referencia sin estirar. Volume Variation/Min/Max: cuánto se adelgaza el objeto al estirarse para simular conservación de volumen. Maintain Volume/Rotation: en qué ejes se aplica esa compensación de volumen y cómo se calcula la rotación hacia el objetivo. |
| ⛓️ | **Tracking > Track To: Target / Track Axis / Up / Target Z** | *Panel Properties > Object Constraints > Add Object Constraint > Tracking* | Intermediate | El constraint de seguimiento más clásico (heredado de versiones antiguas de Blender): el eje Track Axis apunta al Target y el eje Up define qué dirección se mantiene 'hacia arriba'. Target Z fuerza que el eje Z del Target también influya en la orientación. Puede sufrir volteos bruscos en ciertos ángulos, por eso Damped Track suele preferirse hoy en día. |
| ⛓️ | **Relationship > Action: Target / Evaluation Time / Mix** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Advanced | Usa la transformación del Target como si fuera el cursor de tiempo (playhead) de una Action de animación: en vez de reproducirse con los frames de la escena, la Action avanza según el propio movimiento del Target. Evaluation Time fuerza un tiempo fijo en vez de calcularlo del Target. Mix define cómo se combina con la transformación previa del objeto. |
| - | **Relationship > Action > Target (Channel / Range) y Action (Action / Object Action / Frame Start-End)** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship > Action* | Advanced | Target > Channel elige qué canal de transformación del Target controla el tiempo (p. ej. X Location) y Range Min/Max el rango de valores de ese canal que se mapea. Action > Action es la Action de animación a reproducir; Object Action usa una Action distinta por cada instancia si el objeto está instanciado; Frame Start/End acotan qué rango de fotogramas de esa Action se recorre. |
| ⛓️ | **Relationship > Armature: Preserve Volume / Use Envelopes / Add Target Bone / Normalize Weights / Bones** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Advanced | Deforma el objeto según uno o varios huesos de un Armature con sus pesos, sin necesidad de un modifier Armature aparte (uso más puntual, p. ej. en un solo hueso de control). Preserve Volume evita que se adelgace al doblarse mucho. Use Envelopes usa el radio de influencia del hueso en vez de Vertex Groups. Add Target Bone/Normalize Weights y la lista Bones gestionan qué huesos afectan y con qué peso relativo. |
| ⛓️ | **Relationship > Child Of: Target / Location-Rotation-Scale X/Y/Z / Set Inverse** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Advanced | Hace que el objeto herede la transformación del Target como si fuera su padre (parenting), pero de forma más controlable: las casillas Location/Rotation/Scale por eje permiten heredar solo parte de la transformación. Set Inverse fija un desfase para que el objeto no salte de posición al añadir el constraint (imprescindible casi siempre); Clear Inverse lo revierte. |
| ⛓️ | **Relationship > Floor: Target / Offset / Min/Max / Use Rotation** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Intermediate | Impide que el objeto atraviese un 'suelo' virtual definido por el Target (o por su propio origen si no hay Target). Offset: distancia extra respecto al suelo. Min/Max: qué eje y en qué sentido actúa como suelo (Z = el habitual, -Z = techo invertido, etc.). Use Rotation: si el suelo también rota con el Target, en vez de mantenerse siempre horizontal. |
| ⛓️ | **Relationship > Follow Path: Target / Offset / Forward Axis / Up Axis / Fixed Position / Curve Radius / Follow Curve / Animate Path** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Intermediate | Hace que el objeto se mueva a lo largo de una curva Target. Offset/Fixed Position controlan en qué punto del recorrido está (como porcentaje o valor fijo). Forward Axis/Up Axis definen la orientación del objeto respecto a la curva. Curve Radius aplica el grosor variable de la curva como escala. Follow Curve orienta al objeto siguiendo la dirección de la curva en cada punto. El botón Animate Path crea automáticamente los keyframes para recorrerla. |
| ⛓️ | **Relationship > Geometry Attribute: Target / Offset with Target Transform / Attribute Name / Data Type / Domain / Sample Index / Mix Mode** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Advanced | Constraint más reciente: lee un atributo de geometría (creado, por ejemplo, con Geometry Nodes) de la malla del Target y lo usa para mover/orientar el objeto. Attribute Name/Data Type/Domain identifican qué atributo leer y de qué tipo es (Vector, en un dominio como Point). Sample Index elige qué punto/elemento concreto se muestrea. Mix Mode define cómo se combina con la transformación previa. |
| ⛓️ | **Relationship > Pivot: Target / Use Relative Offset / Pivot Point X/Y/Z / Rotation Range** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Advanced | Desplaza el punto de pivote (centro de rotación) del objeto a una posición distinta de su origen, solo mientras rota dentro del Rotation Range indicado (p. ej. 'Rotación en X' hace que el pivote alternativo solo se use al girar en ese eje) — útil para bisagras de puertas o tapas sin mover el origen real del objeto. Use Relative Offset suma el Pivot Point al Target en vez de usarlo como posición absoluta. |
| ⛓️ | **Relationship > Shrinkwrap: Target / Distance / Mode / Snap Mode / Align to Normal** | *Panel Properties > Object Constraints > Add Object Constraint > Relationship* | Intermediate | Pega el origen del objeto a la superficie de una malla Target, a una Distance de separación. Mode: Nearest Surface Point (punto más cercano), Project (proyecta en una dirección), Nearest Vertex, entre otros. Snap Mode: On Surface, Above Surface o Inside. Align to Normal orienta el objeto según la normal de la superficie en el punto de contacto. |
