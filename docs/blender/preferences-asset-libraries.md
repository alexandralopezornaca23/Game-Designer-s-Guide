# Preferences > Asset Libraries


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🌐 | **Allow Online Access / Continue Offline** | *Edit > Preferences > Asset Libraries* | Basic | Igual que en Get Extensions: pide permiso para conectarse a internet, aquí para poder explorar y descargar assets online. |
| 📚 | **All Libraries** | *Edit > Preferences > Asset Libraries* | Basic | Vista combinada que muestra en el Asset Browser los assets de todas las bibliotecas a la vez. |
| ⭐ | **Essentials** | *Edit > Preferences > Asset Libraries* | Basic | Biblioteca integrada de Blender con assets básicos de fábrica (pinceles, materiales, poses...). |
| 📚 | **User Library** | *Edit > Preferences > Asset Libraries* | Intermediate | Tu biblioteca personal de assets guardados; la casilla activa o desactiva que aparezca en el Asset Browser. Con el botón '+' puedes añadir tu propia carpeta de assets como biblioteca reutilizable entre proyectos. |
