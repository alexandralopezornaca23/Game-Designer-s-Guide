# Preferences > Navigation: Zoom


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Zoom Method** | *Edit > Preferences > Navigation > Zoom* | Advanced | Cómo interpreta Blender el gesto de zoom; Dolly (acercar la cámara físicamente) es el más habitual. |
| - | **Zoom Axis** | *Edit > Preferences > Navigation > Zoom* | Advanced | Con qué eje del ratón/trackpad se hace zoom (Vertical es lo más común). |
| - | **Zoom to Mouse Position** | *Edit > Preferences > Navigation > Zoom* | Intermediate | Si está activo, el zoom con la rueda se centra donde está el cursor en vez del centro de la pantalla; muchos artistas lo activan por resultar más natural. |
| - | **Invert Zoom Direction (Mouse / Wheel)** | *Edit > Preferences > Navigation > Zoom* | Basic | Invierte el sentido del zoom para el ratón y/o la rueda por separado. |
