# Properties > Object


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🧭 | **Transform (posición/rotación/escala numérica)** | *Panel Properties > pestaña Object > Transform* | Basic | Igual que el panel N del viewport, pero como valores editables con precisión. |
| - | **Transform > Location / Rotation / Mode / Scale** | *Panel Properties > Object > Transform* | Basic | Location X/Y/Z: posición del origen del objeto. Rotation X/Y/Z: giro en cada eje, en el sistema que marque Mode (XYZ Euler por defecto; también hay otros órdenes de Euler, Quaternion y Axis Angle). Scale X/Y/Z: escala en cada eje (1.000 = tamaño original). |
| Δ | **Delta Transform** | *Panel Properties > Object > Delta Transform* | Advanced | Una transformación extra que se suma a la normal; útil para animar sin tocar los valores "reales" del objeto. |
| - | **Delta Transform > Location / Rotation / Scale** | *Panel Properties > Object > Delta Transform* | Advanced | Mismos campos que el Transform normal (Location/Rotation/Scale X/Y/Z), pero se SUMAN al valor normal en vez de sustituirlo; muy usado en rigging/Geometry Nodes para desplazar un objeto sin que se note en su Transform 'real' (por ejemplo, para que un Driver o constraint seguido calcule sobre el valor base sin el ajuste manual). |
| 🔗 | **Relations / Collections** | *Panel Properties > Object > Relations* | Intermediate | A qué colecciones pertenece el objeto y quién es su padre (parent). |
| - | **Relations > Parent / Parent Type / Camera Parent Lock** | *Panel Properties > Object > Relations* | Intermediate | Parent: objeto padre asignado (equivalente a Ctrl+P en el viewport). Parent Type: cómo hereda la transformación del padre (Object, Bone si el padre es un armature, Vertex...). Camera Parent Lock: solo visible si el objeto es una cámara con padre; bloquea la cámara para que siga exactamente al padre sin desfases. |
| - | **Relations > Tracking Axis / Up Axis / Pass Index** | *Panel Properties > Object > Relations* | Advanced | Tracking Axis/Up Axis: qué eje del objeto apunta hacia su Track To (usado con constraints de tipo Track To/Damped Track). Pass Index: número identificador propio del objeto, usado en compositing (nodo ID Mask) para aislarlo de otros objetos con el mismo material. |
| - | **Relations > Collections: Add to Collection** | *Panel Properties > Object > Relations > Collections* | Basic | Lista de colecciones a las que pertenece el objeto (equivalente a M en el viewport); el botón + añade el objeto también a otra colección adicional sin sacarlo de la actual. |
| 👥 | **Instancing: None / Vertices / Faces** | *Panel Properties > Object > Instancing* | Advanced | Convierte este objeto en emisor de instancias de sus hijos: None (normal, sin instanciar), Vertices (coloca una copia de cada hijo en cada vértice de este objeto, como partículas manuales), Faces (una copia en cada cara). Muy usado para vegetación o multitudes de bajo coste. |
| 〰️ | **Motion Paths: Paths Type / Calculation Range / Frame Range / Step** | *Panel Properties > Object > Motion Paths* | Advanced | Dibuja en el viewport la trayectoria que sigue el objeto a lo largo de los frames, como una guía visual de su movimiento. Paths Type: In Range calcula solo el tramo indicado, Frame Range Start/End/Step definen ese tramo; Calculation Range: Scene Frame Range usa el rango global de la escena en vez de uno manual. |
| - | **Motion Paths > Bake to Active Camera / Calculate / Update All Paths** | *Panel Properties > Object > Motion Paths* | Advanced | Bake to Active Camera: calcula la trayectoria proyectada tal y como se ve desde la cámara activa, en vez de en espacio 3D global. Calculate genera el Motion Path del objeto seleccionado; Update All Paths lo recalcula para todos los objetos que ya tengan uno (útil tras mover keyframes). |
| - | **Motion Paths > Display: Frame Numbers / Keyframes / Keyframe Numbers** | *Panel Properties > Object > Motion Paths > Display* | Advanced | Controla qué se muestra sobre la línea de trayectoria dibujada: los números de frame de cada punto, marcas resaltadas en los frames que tienen keyframe, y el número de esos keyframes. |
| 🔗 | **Shading > Light Linking / Shadow Linking** | *Panel Properties > Object > Shading* | Advanced | Light Linking: restringe qué luces concretas de la escena afectan a este objeto (en vez de recibir todas), añadiendo una colección de luces con el botón New/+. Shadow Linking: igual pero para decidir qué objetos pueden proyectar sombra sobre este. Permite, por ejemplo, iluminar un personaje sin que le afecte una luz pensada solo para el fondo. |
| - | **Shading > Shadow Terminator: Normal Offset / Geometry Offset** | *Panel Properties > Object > Shading* | Advanced | Corrige un artefacto visual (bandas oscuras falsas, 'terminator problem') que aparece en el límite luz/sombra de mallas con poca geometría o normales suavizadas; Normal Offset y Geometry Offset desplazan ligeramente dónde se calcula ese límite para disimularlo. |
| 👁️ | **Visibility** | *Panel Properties > Object > Visibility* | Intermediate | Mostrar/ocultar en viewport, render, o hacerlo invisible a la cámara/reflejos/sombras por separado. |
| - | **Visibility > Selectable / Surface Picking / Show In** | *Panel Properties > Object > Visibility* | Intermediate | Selectable: si se puede seleccionar con click en el viewport. Surface Picking: permite hacer snap/pick sobre su superficie aunque no sea seleccionable. Show In Viewports/Renders: si aparece en el viewport 3D y/o en el render final, de forma independiente. |
| - | **Visibility > Ray Visibility: Camera / Shadow / Raycast** | *Panel Properties > Object > Visibility* | Advanced | Controla, para EEVEE Next/Cycles, si el objeto es visible directamente para los rayos de Camera (se ve en el render), Shadow (proyecta sombra) y Raycast (aparece en reflejos/refracciones y en cálculos de Geometry Nodes que usan raycast), cada uno desactivable por separado — típico para tener un objeto que solo proyecta sombra pero no se ve, o viceversa. |
| - | **Visibility > Light Probes: Volume / Sphere / Plane / Mask: Holdout** | *Panel Properties > Object > Visibility* | Advanced | Si el objeto se tiene en cuenta al hornear cada tipo de Light Probe de EEVEE Next (Volume/Sphere/Plane). Holdout: hace que el objeto actúe como máscara de recorte en el render (se ve el fondo/alpha en su lugar en vez del objeto). |
| 🌓 | **Viewport Display > Show: Name / Axes / Wireframe / All Edges / Texture Space / Shadow / In Front** | *Panel Properties > Object > Viewport Display* | Intermediate | Ayudas visuales que se dibujan sobre el objeto SOLO en el viewport (no afectan al render): Name (etiqueta con su nombre), Axes (ejes de orientación), Wireframe (malla siempre visible encima del sombreado), All Edges (aristas ocultas también, no solo el contorno), Texture Space (caja de mapeo UV generado), Shadow (sombra de contacto en Solid mode), In Front (se dibuja siempre por delante de otros objetos, aunque esté detrás en 3D). |
| - | **Viewport Display > Color / Display As / Bounds** | *Panel Properties > Object > Viewport Display* | Intermediate | Color: tinte que se le aplica en modos de visualización simplificados. Display As: cómo se dibuja el objeto en el viewport (Textured/Solid/Wire/Bounds), útil para aligerar objetos muy pesados mostrándolos solo como caja. Bounds: forma de esa caja simplificada (Box/Sphere/Cylinder...) cuando Display As = Bounds. |
| ✒️ | **Line Art: Usage / Override Crease / Intersection Priority** | *Panel Properties > Object > Line Art* | Advanced | Igual que en Collection pero a nivel de objeto individual: Usage decide si genera/bloquea líneas de contorno; Override Crease fuerza un ángulo de Crease propio distinto del global para calcular sus líneas; Intersection Priority decide qué objeto gana al cruzarse dos líneas. |
| 🔑 | **Animation (Object) / Custom Properties** | *Panel Properties > Object > Animation / Custom Properties* | Advanced | Animation: crea (New) una acción de animación asociada al objeto (accesible también desde el Dope Sheet/Action Editor). Custom Properties: añade tus propios atributos al objeto (útil para exponerlos luego vía Python o Geometry Nodes). |
