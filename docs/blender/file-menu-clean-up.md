# File Menu: Clean Up


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🗑️ | **Purge Unused Data...** | *File > Clean Up* | Intermediate | Elimina del archivo los datos 'huérfanos' (materiales, mallas, imágenes...) que ya no usa ningún objeto de la escena, con un diálogo para elegir qué tipos de datos limpiar; reduce el peso del .blend. |
| 🗑️ | **Manage Unused Data...** | *File > Clean Up* | Advanced | Abre un panel donde puedes revisar uno por uno los datos huérfanos antes de decidir cuáles borrar, en vez de purgarlos todos de golpe. |
