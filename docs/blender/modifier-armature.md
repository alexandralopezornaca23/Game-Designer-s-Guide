# Modifier: Armature


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Object** | *Dentro del modificador* | Basic | El armature (esqueleto) que va a controlar la deformación de esta malla. |
| - | **Vertex Groups** | *Dentro del modificador* | Intermediate | Activa que se usen los pesos de los Vertex Groups (Weight Paint) para repartir cuánto influye cada hueso. |
| - | **Preserve Volume** | *Dentro del modificador* | Advanced | Intenta que la malla no se "aplaste" o encoja de forma antinatural en rotaciones extremas de una articulación. |
