# Spreadsheet > N Panel


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔍 | **Pestaña Filters + botón Add Row Filter** | *Panel lateral N del Spreadsheet > pestaña Filters > Add Row Filter* | Advanced | El panel lateral N de este editor tiene una única pestaña vertical, 'Filters'. Dentro, el botón '+ Add Row Filter' añade un filtro de filas: en vez de recorrer a mano miles de filas, se le pide a la tabla que muestre solo las que cumplan una condición sobre una columna (por ejemplo, solo los vértices cuya position en Z sea mayor que 0). Se pueden apilar varios filtros a la vez, y el contador Rows de abajo a la derecha refleja cuántas filas quedan tras aplicarlos. |
| 🎚️ | **Panel de un filtro: casilla de activación / X / agarre / campo Column** | *Panel lateral N del Spreadsheet > pestaña Filters > un filtro concreto* | Advanced | Cada filtro añadido aparece como un bloque plegable llamado 'Filter' con: una CASILLA a la izquierda del nombre para activarlo o desactivarlo sin borrarlo (probar qué pasa con y sin él), una X a la derecha para eliminarlo, un agarre de puntos para reordenarlo respecto a los demás filtros, y dentro el campo 'Column', donde se elige sobre qué columna/atributo actúa. En la captura el campo Column está vacío, así que el filtro todavía no recorta nada; las opciones de condición y valor que aparecen DESPUÉS de elegir columna quedan pendientes de captura. |
