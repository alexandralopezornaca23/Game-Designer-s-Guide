# Preferences > Themes: File/Asset Browser


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📁 | **Selected File y Alternate Rows** | *Edit > Preferences > Themes > File/Asset Browser* | Intermediate | Color de resaltado de un archivo/asset seleccionado en el explorador de archivos o el Asset Browser, y Alternate Rows (color de fondo alterno de filas, en vista de lista, para facilitar la lectura de listas largas). |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > File/Asset Browser > Theme Space* | Basic | Mismo patrón de Title, Text, Text Highlight, Header, Header Text y Header Text Highlight, aplicado a la ventana del File/Asset Browser. |
