# Preferences > Themes: Color Sets


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🦴 | **Bone Color Sets (Color Set 1-20)** | *Edit > Preferences > Themes > Color Sets* | Advanced | 20 paletas predefinidas para pintar grupos de huesos (Bone Groups) en un Armature; cada set define un color Regular (hueso normal) y Selected (hueso seleccionado), más un color Active y la opción Colored Constraints para que las restricciones (constraints) de ese hueso también se pinten con ese color. |
| 📦 | **Collection Colors (Color 1-8)** | *Edit > Preferences > Themes > Color Sets* | Intermediate | Los 8 colores disponibles para etiquetar Collections en el Outliner (clic derecho > Color Tag); útil para organizar visualmente escenas grandes. |
| 🎞️ | **Sequencer Strip Color Tags** | *Edit > Preferences > Themes > Color Sets* | Intermediate | Colores disponibles para etiquetar clips/strips en el Video Sequence Editor, para organizar visualmente una edición con muchas pistas. |
