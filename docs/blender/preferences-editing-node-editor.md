# Preferences > Editing: Node Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Auto-Offset** | *Edit > Preferences > Editing > Node Editor* | Intermediate | Al insertar un nodo sobre una conexión ya existente, separa automáticamente los nodos vecinos para hacerle sitio (aquí con un margen de 40 px). |
| - | **Preview Resolution** | *Edit > Preferences > Editing > Node Editor* | Advanced | Resolución en píxeles de las miniaturas de previsualización que se muestran dentro de los nodos (por ejemplo en Shading). |
