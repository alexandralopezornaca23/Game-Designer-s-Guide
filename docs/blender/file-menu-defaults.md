# File Menu: Defaults


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💾 | **Save Startup File** | *File > Defaults* | Advanced | Guarda la escena y disposición de paneles actual como la que se carga cada vez que abres Blender (File > New > General); ideal para dejar tu propio setup por defecto. |
| ⚙️ | **Load Factory Settings** | *File > Defaults* | Advanced | Restaura la disposición de paneles y las preferencias del programa (tema, atajos, add-ons) a los valores de fábrica, sin tocar tus modelos ni escenas; úsalo para 'resetear' Blender por completo. |
