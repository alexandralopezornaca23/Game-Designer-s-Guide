# Properties > Particles


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🪮 | **Sistema de partículas (Emitter)** | *Panel Properties > pestaña Particles* | Intermediate | Genera partículas desde la superficie del objeto: cantidad, tiempo de vida, velocidad inicial... |
| - | **Hair (pelo/pelaje)** | *Panel Properties > Particles > tipo Hair* | Advanced | Variante de partículas pensada para pelo, pelaje o hierba, con opción de peinar en modo edición. |
| - | **Render As (Object/Collection)** | *Panel Properties > Particles > Render* | Advanced | Cada partícula puede instanciar un objeto o colección entera (ej. esparcir rocas o vegetación). |
| - | **Emission: Number / Seed / Frame Start / End / Lifetime / Lifetime Randomness** | *Panel Properties > Particles > Emission* | Intermediate | Number: cantidad total de partículas. Seed: semilla aleatoria (cambiarla varía la distribución sin tocar el resto de valores). Frame Start/End: rango de frames en el que se van emitiendo. Lifetime: cuántos frames vive cada partícula antes de desaparecer. Lifetime Randomness: variación aleatoria de esa vida entre partículas. |
| - | **Emission > Source: Emit From / Use Modifier Stack / Distribution / Random Order / Even Distribution / Particles per Face / Jittering Amount** | *Panel Properties > Particles > Emission > Source* | Advanced | Emit From: desde dónde se emite (Faces por defecto). Use Modifier Stack: emite desde la forma final tras aplicar los modificadores anteriores, no desde la malla base. Distribution: patrón de reparto (Jittered/Random/Grid). Random Order/Even Distribution: aleatorizan el orden o reparten de forma más uniforme. Particles per Face: fuerza un número fijo por cara en vez de repartir proporcionalmente. Jittering Amount: cuánto se desordena el patrón Jittered. |
| - | **Cache: Bake / Calculate to Frame / Current Cache to Bake / Bake All Physics / Delete All Bakes / Update All to Frame** | *Panel Properties > Particles > Cache* | Advanced | Bake precalcula y guarda la simulación de partículas en memoria/disco para que se reproduzca igual siempre (necesario si hay física involucrada). Calculate to Frame la calcula solo hasta el frame actual. Current Cache to Bake convierte una caché temporal en caché fija. Bake All Physics / Delete All Bakes / Update All to Frame operan sobre TODAS las simulaciones físicas de la escena a la vez, no solo esta. |
| - | **Cache > External / Cache Step** | *Panel Properties > Particles > Cache* | Advanced | External guarda la caché como archivos sueltos en disco (fuera del .blend) para simulaciones muy pesadas. Cache Step: cada cuántos frames se guarda un punto de caché completo (los intermedios se interpolan), afectando precisión vs. peso. |
| - | **Velocity: Normal / Tangent / Tangent Phase / Object Aligned X/Y/Z / Object Velocity / Randomize** | *Panel Properties > Particles > Velocity* | Advanced | Normal: velocidad inicial hacia fuera de la superficie. Tangent/Tangent Phase: velocidad a lo largo de la superficie y el desfase de esa dirección. Object Aligned X/Y/Z: velocidad inicial en los ejes del propio objeto. Object Velocity: cuánto hereda la partícula el movimiento del objeto emisor si este se mueve. Randomize: variación aleatoria de la velocidad inicial entre partículas. |
| - | **Rotation: Orientation Axis / Randomize / Phase / Randomize Phase / Dynamic / Angular Velocity** | *Panel Properties > Particles > Rotation* | Advanced | Orientation Axis: a qué se alinea la rotación inicial de cada partícula (p. ej. a su dirección de Velocity/Hair). Randomize/Phase/Randomize Phase: aleatoriedad y desfase de esa orientación inicial. Dynamic: permite que la rotación cambie con la física durante la simulación (si no, queda fija). Angular Velocity Axis/Amount: eje y velocidad de giro constante añadida a cada partícula. |
| - | **Physics: Physics Type / Mass / Multiply Mass with Size** | *Panel Properties > Particles > Physics* | Intermediate | Physics Type: None (sin física), Newtonian (física realista con masa/fuerzas, la más común), Keyed (encadenada a objetos clave), Boids (comportamiento de bandada/enjambre) o Fluid. Mass: masa de cada partícula, afecta cómo reaccionan a fuerzas. Multiply Mass with Size: las partículas más grandes (por Scale Randomness) pesan más. |
| - | **Physics > Forces: Brownian / Drag / Damp** | *Panel Properties > Particles > Physics > Forces* | Advanced | Brownian: movimiento aleatorio tipo 'polvo en el aire'. Drag: resistencia del aire que frena la partícula. Damp: amortiguación general del movimiento a lo largo del tiempo. |
| - | **Physics > Deflection: Size Deflect / Die on Hit / Collision Collection** | *Panel Properties > Particles > Physics > Deflection* | Advanced | Size Deflect: usa el tamaño real de la partícula para calcular colisiones (no solo su punto central). Die on Hit: la partícula desaparece al chocar contra un objeto Collision. Collision Collection: limita contra qué colección de objetos colisiona, en vez de contra toda la escena. |
| - | **Physics > Integration: Integration / Timestep / Subframes** | *Panel Properties > Particles > Physics > Integration* | Advanced | Integration: método matemático usado para calcular el movimiento en cada paso (Euler/Midpoint/RK4, de menos a más preciso y costoso). Timestep: duración de cada paso de simulación. Subframes: pasos de cálculo adicionales entre cada frame, para movimientos muy rápidos que si no 'atraviesan' colisiones. |
| - | **Render: Render As / Scale / Scale Randomness / Material / Coordinate System / Show Emitter** | *Panel Properties > Particles > Render* | Intermediate | Render As: cómo se dibuja cada partícula (Halo/Object/Collection/Path/None...). Scale/Scale Randomness: tamaño y variación aleatoria de tamaño. Material: qué material del objeto se usa para las partículas tipo Halo. Coordinate System: en qué espacio se orienta el objeto instanciado. Show Emitter: si el objeto emisor original también se renderiza además de las partículas. |
| - | **Render > Extra: Parent Particles / Unborn / Dead** | *Panel Properties > Particles > Render > Extra* | Advanced | Controla si se renderizan también las partículas 'padre' (cuando hay hijas/Children), las que aún no han nacido (antes de su Frame Start) o las que ya murieron (tras su Lifetime). |
| - | **Viewport Display: Display As / Color / Amount / Size / Show Emitter** | *Panel Properties > Particles > Viewport Display* | Basic | Igual que Render pero solo para cómo se ven en el viewport (no afecta al render final): útil para simplificar la vista y trabajar más fluido con sistemas de muchas partículas (por ejemplo, Amount al 100% en render pero reducido en viewport). |
| - | **Children: None / Simple / Interpolated** | *Panel Properties > Particles > Children* | Advanced | Genera partículas 'hijas' extra alrededor de cada partícula padre para aumentar la densidad (típico en pelo/hierba) sin tener que simular tantas partículas padre: Simple las agrupa cerca del padre, Interpolated las reparte entre varios padres de forma más suave. |
| - | **Field Weights: Effector Collection / Gravity / Force / Vortex / Wind / Curve Guide / Texture / Fluid Flow / Magnetic / Harmonic / Charge / Lennard-Jones / Turbulence / Drag / Boid** | *Panel Properties > Particles > Field Weights* | Advanced | Effector Collection limita qué Force Fields de la escena afectan a este sistema. Cada campo (Gravity, Wind, Vortex, Turbulence...) tiene su propio multiplicador de 0 a 1 (o negativo) para ajustar cuánto le afecta ese tipo de fuerza en concreto, sin tener que tocar el Force Field original. |
| - | **Field Weights > Force Field Settings: Self Effect / Effector Amount / Type 1 / Type 2 / Falloff** | *Panel Properties > Particles > Field Weights > Force Field Settings* | Advanced | Permite que las propias partículas actúen COMO un campo de fuerza que afecta a otros sistemas: Self Effect activa que se afecten entre sí; Type 1/Type 2 definen hasta dos tipos de fuerza que emite cada partícula, con su propio Falloff (caída de intensidad con la distancia). |
| 👥 | **Vertex Groups: Density / Length / Clump / Kink / Roughness 1/2/End / Twist** | *Panel Properties > Particles > Vertex Groups* | Advanced | Vincula cada parámetro a un Vertex Group pintado en Weight Paint, para que varíe según la zona de la malla: Density (dónde nacen más/menos partículas), Length, Clump (agrupamiento), Kink (ondulado), Roughness (aspereza) y Twist (retorcido) — imprescindible para variar el pelo/hierba por zonas (p. ej. más corto en la nuca). |
| - | **Textures / Animation / Custom Properties** | *Panel Properties > Particles > Textures / Animation / Custom Properties* | Advanced | Textures: lista de texturas que pueden controlar varios parámetros de las partículas (densidad, tamaño, color...) según su valor en cada punto. Animation: crea una acción de animación para los propios ajustes de partículas. Custom Properties: añade atributos propios al sistema de partículas. |
