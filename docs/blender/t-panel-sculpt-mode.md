# T Panel: Sculpt Mode


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Herramientas comunes** | *Barra T (Sculpt Mode)* | Basic | En Sculpt Mode, las 9 herramientas comunes a todos los modos (ver 'Barra T: Comunes a todos los modos': Select Box/Cursor/Move/Rotate/Scale/Transform/Annotate/Measure/Add Cube) aparecen al FINAL de la barra T en lugar de al principio; el resto de iconos, situados por encima de ellas, son exclusivos de este modo y se documentan aquí. |
| 🖌️ | **Brush** | *Barra T (Sculpt Mode) > Brush (Mayús+Barra espaciadora → 1)* | Basic | Herramienta general de escultura con pincel: activa el modo de pintar/esculpir deformando la malla con el pincel actualmente seleccionado en el Brush Asset Shelf de la parte inferior del Viewport (Draw, Clay Strips, Crease, Smooth, Inflate...); esta herramienta en sí no define una forma de pincel concreta, solo activa el modo pincel, y el pincel activo se elige aparte en ese estante inferior. |
| ⭕ | **Radio y fuerza del pincel** | *F (radio) / Mayús + F (fuerza)* | Basic | Arrastra el ratón tras pulsar; clic para confirmar. |
| 🖍️ | **Paint** | *Barra T (Sculpt Mode) > Paint (Mayús+Barra espaciadora → 2)* | Basic | Modo de pintado con pincel sobre los atributos de color del vértice/cara de la malla (Color Attributes), en vez de deformar la geometría; el pincel activo también se elige en el Brush Asset Shelf inferior. |
| 🎭 | **Mask** | *Barra T (Sculpt Mode) > Mask (Mayús+Barra espaciadora → 3)* | Intermediate | Modo de pintado de máscara: pinta con el pincel una máscara de escultura (zonas protegidas en negro/blanco) que restringe dónde afectan después los pinceles de escultura; el pincel/intensidad se elige en el Brush Asset Shelf inferior. |
| 🏷️ | **Draw Face Sets** | *Barra T (Sculpt Mode) > Draw Face Sets (Mayús+Barra espaciadora → 4)* | Intermediate | Pinta Face Sets (agrupaciones de caras) directamente sobre la malla con un pincel, usados para organizar zonas del modelo y como límites para máscaras, filtros o el Multires; el color/creación de sets se ajusta en las opciones de la herramienta. |
| 🎭 | **Box Mask** | *Barra T (Sculpt Mode) > Box Mask (Mayús+Barra espaciadora → B)* | Intermediate | Mask within a rectangle defined by the cursor: crea una máscara con la forma de un rectángulo que dibujas arrastrando sobre el Viewport, en vez de pintarla a mano libre. |
| 🙈 | **Box Hide** | *Barra T (Sculpt Mode) > Box Hide (Mayús+Barra espaciadora → Mayús+3)* | Intermediate | Show/hide some vertices: oculta o muestra vértices dentro de un rectángulo definido con el cursor; útil para trabajar solo en una parte del modelo sin que el resto estorbe (Alt+H para mostrar todo de nuevo). |
| 🏷️ | **Box Face Set** | *Barra T (Sculpt Mode) > Box Face Set (Mayús+Barra espaciadora → Mayús+7)* | Intermediate | Add a face set in a rectangle defined by the cursor: crea un Face Set nuevo con la forma de un rectángulo que dibujas, en vez de pintarlo a mano con Draw Face Sets. |
| ∩ | **Box Trim** | *Barra T (Sculpt Mode) > Box Trim (Mayús+Barra espaciadora → Ctrl+1)* | Advanced | Execute a boolean operation on the mesh and a rectangle defined by the cursor: recorta (o añade) geometría de la malla usando una operación booleana con un rectángulo que dibujas en pantalla; permite cortes duros y limpios de forma muy rápida. |
| 📽️ | **Line Project** | *Barra T (Sculpt Mode) > Line Project (Mayús+Barra espaciadora → Ctrl+5)* | Advanced | Project the geometry onto a plane defined by a line: aplana/proyecta la geometría sobre un plano definido al dibujar una línea en el Viewport; útil para crear cortes planos limpios (por ejemplo, la base de un objeto). |
| 🎚️ | **Mesh Filter** | *Barra T (Sculpt Mode) > Mesh Filter (Mayús+Barra espaciadora → Ctrl+6)* | Advanced | Applies a filter to modify the current mesh: aplica filtros globales sobre toda la malla (o la zona no enmascarada) arrastrando el ratón, como Smooth, Inflate, Sharpen o Relax, sin necesidad de pintar pincelada a pincelada. |
| 🧵 | **Cloth Filter** | *Barra T (Sculpt Mode) > Cloth Filter (Mayús+Barra espaciadora → Ctrl+7)* | Advanced | Applies a cloth simulation deformation to the entire mesh: deforma toda la malla (o la zona no enmascarada) aplicando una simulación de tela en tiempo real mientras arrastras el ratón, útil para dar caída o movimiento tipo tela a una superficie. |
| 🌈 | **Color Filter** | *Barra T (Sculpt Mode) > Color Filter (Mayús+Barra espaciadora → Ctrl+X)* | Advanced | Applies a filter to modify the active color attribute: aplica filtros globales (brillo, contraste, saturación, etc.) sobre el atributo de color activo de la malla, arrastrando el ratón, en vez de pintarlos pincelada a pincelada. |
| 🏷️ | **Edit Face Set** | *Barra T (Sculpt Mode) > Edit Face Set (Mayús+Barra espaciadora → Ctrl+W)* | Advanced | Edits the current active face set: edita el Face Set activo (por ejemplo, lo extrae, lo infla o lo separa) arrastrando el ratón, según la operación elegida en las opciones de la herramienta. |
| 🎭 | **Mask by Color** | *Barra T (Sculpt Mode) > Mask by Color (Mayús+Barra espaciadora → Ctrl+8)* | Advanced | Creates a mask based on the active color attribute: genera una máscara automáticamente a partir de zonas de color similar al atributo de color activo, haciendo clic sobre la zona de referencia; útil para aislar una parte pintada de un color concreto sin tener que pintar la máscara a mano. |
