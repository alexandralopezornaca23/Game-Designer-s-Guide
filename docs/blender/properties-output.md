# Properties > Output


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Format: Resolution X/Y / %** | *Panel Properties > Output > Format* | Basic | Resolución final del render en píxeles (X/Y) y un porcentaje de escala rápido sobre esa resolución (100% = tamaño completo, bajarlo es útil para previsualizar renders rápidos sin cambiar los valores X/Y reales). |
| - | **Format: Aspect X/Y** | *Panel Properties > Output > Format* | Advanced | Relación de aspecto del PÍXEL (no de la imagen); se deja en 1.000/1.000 salvo que exportes para un formato con píxeles no cuadrados (algunos estándares de vídeo antiguos). |
| - | **Format: Render Region / Crop to Render Region** | *Panel Properties > Output > Format* | Advanced | Render Region permite marcar en el Viewport (Ctrl+B) una zona rectangular y renderizar solo esa parte, útil para previsualizar rápido un detalle; Crop to Render Region además recorta la imagen final a ese rectángulo en vez de dejarla del tamaño completo con el resto en negro. |
| - | **Format: Frame Rate** | *Panel Properties > Output > Format* | Basic | Fotogramas por segundo (fps) de la animación; debe coincidir con el proyecto de destino (24 fps cine, 30/60 fps la mayoría de motores de videojuego) para que la velocidad no cambie al exportar. |
| - | **Frame Range: Frame Start / End / Step** | *Panel Properties > Output > Frame Range* | Basic | Primer y último fotograma que se renderizan al lanzar una animación (Ctrl+F12); Step permite saltar fotogramas (Step=2 renderiza solo los pares, útil para previsualizar rápido). |
| - | **Frame Range > Time Stretching: Old / New** | *Panel Properties > Output > Frame Range > Time Stretching* | Advanced | Reescala toda la animación en el tiempo: 'Old' fotogramas pasan a durar 'New' fotogramas (p. ej. Old=100/New=200 estira la animación al doble de duración, ralentizándola) sin tener que mover los keyframes a mano. |
| 🥽 | **Stereoscopy** | *Panel Properties > Output > Stereoscopy* | Advanced | Activa el renderizado estereoscópico (visión 3D) con dos modos: Stereo 3D (una cámara izquierda/derecha combinadas en un solo archivo, para gafas 3D) o Multi-View (varias cámaras/vistas independientes, para VR o multi-monitor). |
| - | **Stereoscopy > left / right / File Suffix** | *Panel Properties > Output > Stereoscopy* | Advanced | Activa/desactiva por separado el renderizado del ojo izquierdo y derecho; File Suffix es el texto que se añade al nombre de archivo de cada uno para distinguirlos (p. ej. '_L' y '_R'). |
| 📁 | **Output: ruta de guardado** | *Panel Properties > Output* | Basic | Carpeta y nombre base donde se guardan las imágenes/vídeo renderizados; se puede usar // al principio para una ruta relativa al archivo .blend. |
| - | **Output > Saving: File Extensions / Cache Result** | *Panel Properties > Output > Saving* | Intermediate | File Extensions añade automáticamente la extensión correcta (.png, .exr...) al nombre de archivo. Cache Result mantiene el render en memoria tras generarlo, para poder reutilizarlo (por ejemplo en el Compositor) sin recalcularlo. |
| - | **Output > Media Type / File Format** | *Panel Properties > Output > Saving* | Basic | Media Type: si se guarda como Image (una imagen por fotograma) o vídeo. File Format: el formato concreto de archivo (PNG, JPEG, OpenEXR, FFmpeg Video...); cada formato desbloquea sus propias opciones justo debajo (Color, Color Depth, Compression, etc.). |
| - | **Output > Color / Color Depth / Compression** | *Panel Properties > Output > Saving* | Intermediate | Color: canales guardados (BW=blanco y negro, RGB=color, RGBA=color + canal alfa/transparencia). Color Depth: bits por canal (8 = estándar, 16 = más rango de color, archivos más pesados). Compression: nivel de compresión del archivo (sin pérdida en PNG, a más % más comprimido y más lento de guardar). |
| - | **Output > Image Sequence: Overwrite / Placeholders** | *Panel Properties > Output > Saving* | Advanced | Overwrite sobrescribe sin preguntar un fotograma ya renderizado antes con el mismo nombre. Placeholders crea de golpe un archivo vacío por cada fotograma de la animación antes de empezar a renderizar, útil para lanzar varias instancias de Blender en paralelo sin que se pisen el trabajo entre sí. |
| - | **Output > Color Management: Follow Scene / Override** | *Panel Properties > Output > Color Management* | Advanced | Follow Scene usa la misma configuración de Color Management de la pestaña Render (Display/View/Look/Exposure/Gamma, ya documentada). Override permite definir aquí una configuración de color DISTINTA solo para el archivo guardado en disco (por ejemplo, guardar en sRGB para revisar aunque el proyecto trabaje internamente en otro espacio), con sus propios Use Curves y Use White Balance independientes. |
| - | **Output > Pixel Density: Pixels / Unit** | *Panel Properties > Output > Pixel Density* | Advanced | Metadato de densidad de píxeles (PPI/PPCM) que se guarda dentro del archivo de imagen, usado por programas de maquetación/impresión para saber a qué tamaño físico imprimirla; no afecta a la resolución en píxeles del render en sí. |
| 🏷️ | **Stamp (metadatos incrustados)** | *Panel Properties > Output > Metadata* | Advanced | Graba texto sobre la imagen final o en sus metadatos: fecha, hora, tiempo de render, nº de frame, cámara, escena, nombre de archivo, etc. Útil para revisiones y para llevar la cuenta de qué versión es cada render. |
| - | **Metadata > Include (Date/Time/Render Time/Frame/Camera/Scene/Filename...)** | *Panel Properties > Output > Metadata > Include* | Advanced | Qué datos concretos se incluyen como metadato: Date, Time, Render Time (cuánto tardó en renderizarse), Frame, Frame Range, Memory (RAM usada), Hostname (nombre del ordenador), Camera, Lens, Scene, Marker, Filename, Strip Name. Se guardan como metadato del archivo; para que además se VEAN escritos sobre la imagen hace falta activar Burn Into Image. |
| - | **Metadata > Note** | *Panel Properties > Output > Metadata > Note* | Advanced | Campo de texto libre para añadir una nota personalizada a los metadatos del render (por ejemplo, la versión del archivo o un comentario para el equipo). |
| - | **Metadata > Burn Into Image** | *Panel Properties > Output > Metadata > Burn Into Image* | Advanced | Además de guardarse como metadato invisible, escribe visiblemente los datos marcados en Include directamente sobre los píxeles de la imagen; Font Size, Text Color y Background controlan su aspecto, e Include Labels añade el nombre de cada dato (p. ej. 'Frame:') delante del valor. |
| - | **Post Processing: Pipeline (Compositing/Sequencer) / Dither** | *Panel Properties > Output > Post Processing* | Intermediate | Pipeline: si el render final pasa por el Compositor de nodos y/o por el Video Sequencer antes de guardarse (con ambos desactivados se guarda el render 'en crudo'). Dither añade un ruido aleatorio mínimo al guardar para evitar bandas visibles de color en degradados suaves. |
