# T Panel: Edit Mode (Armature)


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Herramientas comunes** | *Barra T (Edit Mode, Armature)* | Basic | Comparte las mismas 9 herramientas comunes a todos los modos (ver 'Barra T: Comunes a todos los modos'), aquí aplicadas a huesos (Edit Bones) en vez de a objetos completos. A partir de aquí se documentan solo las herramientas propias de Edit Mode de un Armature. |
| 🦴 | **B-Bone Size / Bone Envelope** | *Barra T (Edit Mode, Armature) > desplegable tras Measure* | Advanced | Herramienta exclusiva de Edit Mode en un Armature, con 2 variantes: B-Bone Size ajusta arrastrando el ratón el Display Size del Bendy Bone (mismo valor que Properties > Bone > Bendy Bones > Display Size X/Z) directamente en el Viewport. Bone Envelope ajusta arrastrando el radio del Envelope (mismo valor que Properties > Bone > Deform > Radius Head/Tail) usado para la deformación por Envelope, también visible como una esfera alrededor del hueso en el Viewport. |
| ⬆️ | **Extrude / Extrude to Cursor** | *Barra T (Edit Mode, Armature) > desplegable de Extrude* | Basic | Extrude añade un hueso nuevo conectado a la punta (Tail) del hueso seleccionado, arrastrando para definir su longitud y dirección; equivale a pulsar E. Extrude to Cursor hace lo mismo pero coloca directamente la punta del hueso nuevo en la posición del 3D Cursor, sin necesidad de arrastrar. |
