# File Browser > Header


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📁 | **Previous Folder / Next Folder / Parent Directory / Refresh File List / Create New Directory** | *Cabecera del File Browser (barra de navegación, izquierda)* | Basic | Previous Folder / Next Folder: retroceden/avanzan por el historial de carpetas visitadas, como en un explorador de archivos normal. Parent Directory: sube un nivel a la carpeta contenedora. Refresh File List: refresca la lista por si ha cambiado algo fuera de Blender. Create New Directory: crea una carpeta nueva dentro de la actual. |
| ⌨️ | **Previous Folder** | *Alt+Izquierda* | Basic | Previous Folder |
| ⌨️ | **Next Folder** | *Alt+Derecha* | Basic | Next Folder |
| ⌨️ | **Parent Directory** | *Alt+Arriba* | Basic | Parent Directory |
| ⌨️ | **Refresh File List** | <kbd>R</kbd> | Basic | Refresh File List |
| ⌨️ | **Create New Directory** | <kbd>I</kbd> | Basic | Create New Directory |
| 📂 | **Ruta de la carpeta actual (campo de texto)** | *Cabecera del File Browser, junto a los botones de navegación* | Basic | Muestra la ruta completa de la carpeta que se está explorando; se puede escribir o pegar una ruta directamente y pulsar Intro para saltar a ella. |
| 🗂️ | **Display Mode: Vertical List / Horizontal List / Thumbnails** | *Cabecera del File Browser, junto al buscador* | Basic | Cambia cómo se muestra la lista de archivos: Vertical List (una columna con detalles como la fecha), Horizontal List (filas más compactas), Thumbnails (miniaturas en cuadrícula, útil para previsualizar imágenes). |
| ⚙️ | **List Settings: Size / Recursions / Sort By / Reverse Sorting** | *Cabecera del File Browser, desplegable junto a Display Mode* | Intermediate | Size: tamaño de icono en modo Thumbnails (64 por defecto). Recursions: mismo control que 'View > Recursion', para mostrar también el contenido de subcarpetas hasta el nivel elegido. Sort By: criterio de orden de la lista (Name/Extension/Modified Date/Size). Reverse Sorting: invierte el orden de la lista. |
| 🔽 | **Filter: Folders / .blend Files / Backup .blend Files / Image Files / Movie Files / Script Files / Font Files / Sound Files / Text Files / Volume Files / Show Hidden** | *Cabecera del File Browser, icono de embudo* | Intermediate | Filtra qué tipos de archivo se muestran en la lista marcando/desmarcando cada categoría (Folders e Image Files activados en la captura enviada, el resto desactivados). Show Hidden muestra también archivos y carpetas ocultos del sistema. |
| 🔎 | **Search** | *Cabecera del File Browser, arriba a la izquierda* | Basic | Filtra la lista de archivos/carpetas visibles según el texto escrito, igual que el buscador de otros editores (Outliner, etc.). |
