# Modifier: UV Project


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **UV Map / Aspect X-Y / Scale X-Y** | *Dentro del modificador* | Intermediate | UV Map: sobre qué mapa UV de la malla se proyecta el resultado. Aspect X/Y y Scale X/Y (1.000 por defecto) ajustan la proporción y el tamaño de la proyección, útiles para que la imagen proyectada no salga estirada si su proporción no es cuadrada. |
| - | **Projectors: número y Object** | *Dentro del modificador > Projectors* | Advanced | Projectors (1): cuántos objetos-cámara actúan como proyector a la vez (hasta varios, mezclando su resultado). Object: qué objeto (normalmente una Cámara o un Empty) define el ángulo y posición desde el que se proyectan las UV, como una diapositiva o un cañón de proyección. |
