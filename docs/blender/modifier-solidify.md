# Modifier: Solidify


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Thickness** | *Dentro del modificador* | Basic | Grosor que se añade a una superficie sin espesor (como una plancha o una tela). |
| - | **Offset** | *Dentro del modificador* | Intermediate | Hacia qué lado crece el grosor respecto a la superficie original: -1 hacia dentro, 1 hacia fuera, 0 reparte a ambos lados. |
| - | **Rim** | *Dentro del modificador* | Intermediate | Si genera o no el borde de cierre en los bordes abiertos de la malla, para que no quede hueco por dentro. |
