# Preferences > Input: Mouse


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖱️ | **Emulate 3 Button Mouse** | *Edit > Preferences > Input > Mouse* | Advanced | Simula el clic central del ratón con Alt+Clic izquierdo; pensado para ratones de solo 2 botones. |
| - | **Continuous Grab** | *Edit > Preferences > Input > Mouse* | Intermediate | Al arrastrar un valor (como un slider) más allá del borde de la pantalla, el cursor reaparece por el lado contrario en vez de quedarse bloqueado en el borde. |
| - | **Release Confirms** | *Edit > Preferences > Input > Mouse* | Advanced | En herramientas modales (mover, rotar...), soltar el botón del ratón confirma la acción, en vez de necesitar un clic aparte. |
| - | **Double Click Speed** | *Edit > Preferences > Input > Mouse* | Advanced | Tiempo máximo en milisegundos entre dos clics para que Blender los cuente como un doble clic. |
| - | **Mouse Drag Threshold** | *Edit > Preferences > Input > Mouse* | Advanced | Distancia mínima en píxeles que debe moverse el ratón antes de que Blender considere que estás arrastrando en vez de haciendo clic. |
| - | **Tablet Drag Threshold** | *Edit > Preferences > Input > Mouse* | Advanced | Igual que el anterior pero para tableta gráfica, normalmente algo más alto porque el trazo con lápiz es menos preciso. |
| - | **Drag Threshold** | *Edit > Preferences > Input > Mouse* | Advanced | Umbral general de arrastre usado por otras operaciones de interfaz, como reordenar elementos en listas. |
| - | **Motion Threshold** | *Edit > Preferences > Input > Mouse* | Advanced | Distancia mínima de movimiento del ratón para que se registre como un gesto direccional, por ejemplo en menús tipo pie/radial. |
