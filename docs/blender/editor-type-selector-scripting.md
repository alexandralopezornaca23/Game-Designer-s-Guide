# Editor Type Selector: Scripting


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📝 | **Text Editor** | *Icono de tipo de editor > Text Editor (Mayús+F11)* | Intermediate | Convierte el panel activo en el editor de texto/scripts integrado, donde se escriben y ejecutan los scripts de Python (ver pestaña Python de esta guía). |
| 🐍 | **Python Console** | *Icono de tipo de editor > Python Console (Mayús+F4)* | Intermediate | Convierte el panel activo en una consola interactiva de Python, para probar comandos línea a línea sin necesidad de un script completo. |
| ℹ️ | **Info** | *Icono de tipo de editor > Info* | Intermediate | Convierte el panel activo en el historial de operaciones: registra cada acción realizada en la interfaz junto a su equivalente en código Python (bpy.ops...), útil para aprender a scriptear viendo qué genera cada clic. |
