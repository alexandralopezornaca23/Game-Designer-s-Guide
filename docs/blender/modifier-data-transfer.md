# Modifier: Data Transfer


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Source / Vertex Group** | *Dentro del modificador* | Basic | Source: el objeto del que se copian los datos (normalmente una versión high-poly o una malla de referencia). Vertex Group: si se rellena, limita a qué vértices de ESTE objeto se les copian los datos, dejando el resto sin tocar. |
| - | **Mix Mode / Mix Factor** | *Dentro del modificador* | Intermediate | Mix Mode (Replace): cómo se combina el dato copiado con el que ya tenía la malla — Replace lo sustituye sin más, otras opciones mezclan o solo rellenan huecos. Mix Factor (1.000): cuánto influye el dato nuevo sobre el original, de 0 (sin efecto) a 1 (sustitución completa). |
| - | **Generate Data Layers** | *Dentro del modificador* | Intermediate | Botón que crea automáticamente en ESTE objeto las capas de datos (Vertex Groups, capas de color, UVs...) que le falten para poder recibir la transferencia, sin tener que crearlas antes a mano. |
| - | **Vertex Data: Vertex Groups / Bevel Weight / Colors + Mapping** | *Dentro del modificador > Vertex Data* | Advanced | Activa qué datos ligados a los VÉRTICES se copian (checkbox general para activar la sección, más un botón por tipo de dato). Mapping (Nearest Vertex) define cómo se empareja cada vértice de este objeto con uno del Source: por el vértice más cercano en el espacio. |
| - | **Vertex Data > Vertex Groups / Colors: Layer Selection / Layer Mapping** | *Dentro del modificador > Vertex Data > Vertex Groups / Colors* | Advanced | Al activar Vertex Groups o Colors se despliega: Layer Selection (All Layers) elige si se copian todas las capas de ese tipo o solo una en concreto. Layer Mapping (By Name) empareja las capas del Source con las de este objeto por su nombre, en vez de por el orden en que aparecen en la lista. |
| - | **Edge Data: Sharp / UV Seam / Crease / Bevel Weight / Freestyle + Mapping** | *Dentro del modificador > Edge Data* | Advanced | Copia atributos ligados a las ARISTAS: si están marcadas como Sharp, como costura UV (Seam), su valor de Crease/Bevel Weight, o si son Freestyle Mark (para el renderizado de contornos tipo cómic). Mapping (Nearest Edge) empareja cada arista con la más cercana del Source. |
| - | **Face Corner Data: Custom Normals / Colors / UVs + Mapping** | *Dentro del modificador > Face Corner Data* | Advanced | Copia datos que dependen de la combinación cara+vértice (no solo del vértice): Custom Normals (muy usado para transferir el sombreado suave de una malla high-poly a una low-poly), Colors y UVs. Mapping (Nearest Corner and Best Matching Face Normal) busca la esquina más cercana Y que además mire en una dirección similar, para un emparejamiento más preciso que solo la distancia. |
| - | **Face Corner Data > Colors / UVs: Layer Selection / Layer Mapping / Islands Precision** | *Dentro del modificador > Face Corner Data > Colors / UVs* | Advanced | Mismo patrón de Layer Selection (All Layers) / Layer Mapping (By Name) que en Vertex Data, aplicado aquí a capas de color o de UV. Islands Precision (0 m, solo en UVs) afina cómo se gestionan las islas UV separadas al mapear entre ambas mallas. |
| - | **Face Data: Smooth / Freestyle Mark + Mapping** | *Dentro del modificador > Face Data* | Advanced | Copia si cada cara está marcada como Smooth (sombreado suave) o como Freestyle Mark. Mapping (Nearest Face) empareja cada cara con la más cercana del Source. |
| - | **Topology Mapping: Max Distance / Ray Radius** | *Dentro del modificador > Topology Mapping* | Advanced | Panel común a todos los tipos de Mapping anteriores: Max Distance (checkbox + 1 m) limita la distancia máxima a la que se busca un emparejamiento válido, para no copiar datos de algo demasiado lejano. Ray Radius (0 m) da grosor al rayo usado para buscar coincidencias en los métodos de mapeado que proyectan un rayo (como los de tipo Projected), en vez de un rayo perfectamente fino. |
