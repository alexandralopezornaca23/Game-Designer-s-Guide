# Modifier: Mirror


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Axis (X/Y/Z)** | *Dentro del modificador* | Basic | Eje o ejes sobre los que se espeja la malla. Puedes activar varios a la vez. |
| - | **Bisect** | *Dentro del modificador* | Intermediate | Corta la mitad original por el plano de simetría, para que no queden dos mitades solapadas si tu malla no estaba perfectamente centrada. |
| - | **Flip** | *Dentro del modificador* | Advanced | Invierte hacia qué lado corta el Bisect, cuando el resultado sale al revés de lo esperado. |
| - | **Merge / Merge Distance** | *Dentro del modificador* | Basic | Fusiona los vértices que coinciden en el centro para que no se note la "costura" entre las dos mitades. |
| - | **Clipping** | *Dentro del modificador* | Intermediate | Impide que muevas vértices más allá del centro de simetría en modo edición, evitando que se abra un hueco en la costura. |
