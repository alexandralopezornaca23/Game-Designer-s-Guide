# Preferences > Input: NDOF


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Navigation Mode** | *Edit > Preferences > Input > NDOF* | Advanced | Cómo se comporta un dispositivo 3D de navegación (ratón espacial tipo SpaceMouse); en modo Object mueve la vista como si movieras la cámara/objeto. |
| - | **Lock Horizon** | *Edit > Preferences > Input > NDOF* | Advanced | Evita que el horizonte se incline al navegar con el dispositivo NDOF, manteniendo siempre la vertical. |
| - | **Auto Fly Speed** | *Edit > Preferences > Input > NDOF* | Advanced | Ajusta automáticamente la velocidad de vuelo del NDOF según la distancia a los objetos cercanos; solo se activa en modo Fly. |
| - | **Orbit Center (Auto / Selected Items)** | *Edit > Preferences > Input > NDOF* | Advanced | En modo Auto, orbita alrededor de un punto calculado automáticamente; con Selected Items, orbita siempre alrededor del objeto seleccionado. |
| - | **Show (Orbit Axis / Orbit Center)** | *Edit > Preferences > Input > NDOF* | Advanced | Muestra en el viewport indicadores visuales del eje de órbita y/o el punto sobre el que estás orbitando con el NDOF. |
