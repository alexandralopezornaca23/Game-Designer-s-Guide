# Viewport 3D > Pose


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🕺 | **Pose: menú general (solo visible en Pose Mode)** | *Barra superior del Viewport 3D > Pose* | Intermediate | Sustituye al menú Object cuando el Armature está en Pose Mode. Agrupa en bloques: Transform/Clear Transform/Apply/Snap (mover y fijar la pose), Copy/Paste Pose, Animation/Propagate (keyframes de la pose), Motion Paths/Bone Collections, Parent/Inverse Kinematics/Constraints (relaciones entre huesos), Names/Flip Quaternions, Show/Hide/Bone Settings, y Create Pose Asset al final. |
| 🕺 | **Pose > Transform: Move / Rotate / Scale / To Sphere / Shear / Bend / Push-Pull** | *Barra superior > Pose > Transform* | Basic | Mismos 7 comandos de transformación ya documentados en Object > Transform (Move/Rotate/Scale con sus atajos G/R/S, más To Sphere/Shear/Bend/Push-Pull), aquí aplicados al hueso o huesos seleccionados de la pose en vez de a objetos completos. |
| 🕺 | **Pose > Clear Transform: All / Location / Rotation / Scale / Reset Unkeyed** | *Barra superior > Pose > Clear Transform* | Basic | All, Location (Alt+G), Rotation (Alt+R) y Scale (Alt+S) devuelven la pose del hueso a su posición de descanso (Rest Pose) en ese canal, igual que Object > Clear pero sobre huesos. Reset Unkeyed es exclusivo de Pose Mode: solo resetea los canales que NO tengan ya un keyframe insertado en el frame actual, dejando intactos los que sí lo tienen. |
| 🕺 | **Pose > Apply: Apply Pose as Rest Pose / Apply Selected as Rest Pose** | *Barra superior > Pose > Apply (Ctrl+A)* | Advanced | Convierte la pose actual (la deformación que ves con los huesos movidos) en la nueva Rest Pose del Armature, la que se ve en Edit Mode: Apply Pose as Rest Pose lo hace para TODOS los huesos, Apply Selected as Rest Pose solo para los seleccionados. Muy usado tras esculpir/corregir una pose base antes de empezar a animar, para no arrastrar esa corrección como si fuera una animación más. |
| 🕺 | **Pose > Apply: Apply Visual Transform to Pose / Assign Custom Property Values as Default** | *Barra superior > Pose > Apply* | Advanced | Apply Visual Transform to Pose aplica como pose real el resultado visual actual de Constraints/IK sobre los huesos, quitando el efecto de esos constraints pero dejando el hueso donde se veía (igual que el Object > Apply > Visual Transform ya documentado). Assign Custom Property Values as Default guarda el valor actual de las Custom Properties del hueso como su valor por defecto. |
| 🧲 | **Pose > Snap: Selection to Grid / to Cursor / to Cursor (Keep Offset) / to Active** | *Barra superior > Pose > Snap* | Intermediate | Mueve los huesos seleccionados (su pose) hasta la rejilla, el 3D Cursor o el hueso activo. To Cursor (Keep Offset) los desplaza todos en bloque para que uno de referencia llegue al Cursor, sin perder la posición relativa entre ellos, a diferencia de To Cursor a secas que los junta todos en el mismo punto. |
| 🧲 | **Pose > Snap: Cursor to Selected / to World Origin / to Grid / to Active** | *Barra superior > Pose > Snap* | Intermediate | Igual que en Object > Snap (ya documentado) pero moviendo el 3D CURSOR a la posición de los huesos seleccionados/al origen/a la rejilla/al hueso activo, en vez de mover los huesos. |
| 🕺 | **Pose: Copy Pose / Paste Pose / Paste Pose Flipped** | *Barra superior del Viewport 3D > Pose* | Intermediate | Copy Pose (Ctrl+C) copia al portapapeles la pose de los huesos seleccionados. Paste Pose (Ctrl+V) la pega sobre la selección actual, incluso en otro Armature u otra instancia de Blender. Paste Pose Flipped (Mayús+Ctrl+V) la pega invertida en espejo (izquierda↔derecha, según el nombre de los huesos con sufijo .L/.R), muy usado para copiar una pose de un lado del personaje al otro. |
| 🔑 | **Pose > Animation: Insert Keyframe / Insert Keyframe with Keying Set / Delete Keyframes / Clear Keyframes / Change Keying Set** | *Barra superior > Pose > Animation* | Basic | Insert Keyframe (I) crea un keyframe en el frame actual para los canales de la pose seleccionada. Insert Keyframe with Keying Set (K) usa un Keying Set concreto (grupo predefinido de canales) en vez de insertar todos. Delete Keyframes (Alt+I) y Clear Keyframes borran keyframes del frame actual o todos los de esos huesos respectivamente. Change Keying Set (Mayús+K) cambia qué Keying Set está activo. |
| 🔑 | **Pose > Animation > In-Betweens: Blend Pose with Rest Pose / Push Pose from Breakdown / Relax Pose to Breakdown / Pose Breakdowner / Blend to Neighbor** | *Barra superior > Pose > Animation > In-Betweens* | Advanced | Herramientas para generar poses intermedias entre keyframes, arrastrando el ratón para ajustar la cantidad: Blend Pose with Rest Pose mezcla hacia la Rest Pose. Push Pose from Breakdown (Ctrl+E) exagera la pose alejándola de la referencia. Relax Pose to Breakdown (Alt+E) la suaviza acercándola. Pose Breakdowner (Mayús+E) crea una pose intermedia entre la anterior y la siguiente (misma función que la herramienta Breakdowner de la Barra T en Object Mode). Blend to Neighbor (Mayús+Alt+E) mezcla hacia el keyframe vecino más cercano en el tiempo. |
| 🔑 | **Pose > Animation: Bake Action / Bake Object Transform to Grease Pencil / Replace Action / Replace with New Action** | *Barra superior > Pose > Animation* | Advanced | Bake Action 'hornea' la animación (incluyendo constraints/IK) en keyframes explícitos frame a frame, útil antes de exportar a motores que no soportan esos constraints. Bake Object Transform to Grease Pencil convierte la animación del objeto en trazos de Grease Pencil. Replace Action sustituye la Action activa por otra ya existente. Replace with New Action la sustituye por una Action nueva y vacía. |
| 🔑 | **Pose > Propagate: To Next Keyframe / To Last Keyframe (Make Cyclic) / On Selected Keyframes / On Selected Markers** | *Barra superior > Pose > Propagate (Alt+P)* | Advanced | Copia el valor de la pose del frame actual hacia adelante en el tiempo: To Next Keyframe hasta el siguiente keyframe. To Last Keyframe (Make Cyclic) hasta el último, dejando además el ciclo listo para repetirse. On Selected Keyframes y On Selected Markers la propagan solo a los keyframes o marcadores de tiempo que tengas seleccionados en el Dope Sheet/Timeline. |
| 🛤️ | **Pose > Motion Paths: Calculate / Clear** | *Barra superior > Pose > Motion Paths* | Intermediate | Calculate dibuja en el Viewport la trayectoria (una línea con un punto por frame) que sigue el hueso seleccionado a lo largo de la animación, útil para juzgar arcos de movimiento. Clear la quita del Viewport. |
| 📦 | **Pose > Bone Collections: Move to Collection / Assign to Collection / Show All / Assign to New Collection** | *Barra superior > Pose > Bone Collections* | Intermediate | Bone Collections es el sistema de Blender para agrupar huesos (equivalente a las Collections de objetos, pero dentro de un mismo Armature) y mostrar/ocultar grupos completos a la vez. Move to Collection (M) saca al hueso de su colección actual y lo mete en otra. Assign to Collection (Mayús+M) lo añade a otra sin sacarlo de la actual. Show All muestra todas las Bone Collections ocultas. Assign to New Collection crea una colección nueva con la selección. |
| 🔗 | **Pose > Parent: Object / Armature Deform / Bone / Bone Relative** | *Barra superior > Pose > Parent (Ctrl+P)* | Advanced | Mismo menú de emparentado que Object > Parent (Ctrl+P), aquí también accesible desde Pose Mode: Object empareja el objeto activo (no un hueso) a otro objeto sin deformación. Armature Deform empareja una MALLA al Armature para que los huesos la deformen (el paso de 'rigging' básico; despliega With Empty Groups/With Automatic Weights/With Envelope Weights según cómo se reparta la influencia de cada hueso). Bone empareja a un hueso concreto sin deformarse con él. Bone Relative empareja igual que Bone pero ignorando la posición de descanso del hueso padre, útil para que el hijo no 'salte' al emparentar. |
| 🔗 | **Pose > Parent: Curve Deform / Follow Path / Path Constraint / Lattice Deform / Vertex / Vertex (Triangle)** | *Barra superior > Pose > Parent* | Advanced | Formas de emparentar a una Curve (deformándose a lo largo de ella, o siguiéndola como constraint), a un Lattice (deformándose con su jaula), o a uno (Vertex) o tres (Vertex Triangle) vértices concretos de una malla, para que el objeto/hueso siga exactamente ese punto o plano de la malla al moverse. |
| 🔗 | **Pose > Parent: Make Parent without Inverse / Clear Parent / Clear and Keep Transformation / Clear Parent Inverse** | *Barra superior > Pose > Parent* | Advanced | Make Parent without Inverse empareja sin compensar la posición actual (el hijo puede 'saltar' de sitio al emparentar). Clear Parent quita el parentesco (el objeto puede saltar a su posición sin padre). Clear and Keep Transformation lo quita pero ajusta la transformación para que se quede donde se veía. Clear Parent Inverse resetea solo la matriz de compensación interna sin quitar el parentesco. |
| 🦴 | **Pose > Inverse Kinematics: Add IK to Bone / Remove IK** | *Barra superior > Pose > Inverse Kinematics* | Advanced | Add IK to Bone (Mayús+I) añade rápidamente un constraint de Inverse Kinematics al hueso activo (con un Target ya sugerido), sin tener que ir al panel de Properties > Bone Constraint. Remove IK (Ctrl+Alt+I) lo quita. |
| ⛓️ | **Pose > Constraints: Add (with Targets)... / Copy Constraints to Selected Bones / Clear Pose Constraints** | *Barra superior > Pose > Constraints* | Advanced | Add (with Targets)... (Mayús+Ctrl+C) abre un menú para añadir un constraint al hueso activo ya con su Target elegido en el mismo paso, más rápido que hacerlo desde Properties > Bone Constraint. Copy Constraints to Selected Bones copia TODOS los constraints del hueso activo al resto de huesos seleccionados. Clear Pose Constraints (Ctrl+Alt+C) los borra todos de la selección. |
| - | **Pose > Names: Auto-Name Left/Right / Front/Back / Top/Bottom / Flip Names** | *Barra superior > Pose > Names* | Intermediate | Renombra automáticamente los huesos seleccionados según su posición en el espacio, añadiendo el sufijo correspondiente (.L/.R, .F/.B, .T/.B) para que el sistema de Paste Pose Flipped y simetrías (Mirror) los reconozca como pareja. Flip Names cambia el sufijo de cada hueso por su opuesto (por ejemplo, Arm.L pasa a llamarse Arm.R). |
| - | **Pose: Flip Quaternions** | *Barra superior del Viewport 3D > Pose (Alt+F)* | Advanced | Cambia la representación matemática de la rotación del hueso (Quaternion) por su equivalente negado, que da la MISMA rotación visual pero puede evitar giros erráticos ('gimbal flips') al interpolar entre keyframes muy separados en ángulo. |
| 👁️ | **Pose > Show/Hide: Reveal Selected / Hide Selected / Hide Unselected** | *Barra superior > Pose > Show/Hide* | Basic | Mismo patrón que Object > Show/Hide (ya documentado) pero sobre huesos: Reveal Selected (Alt+H) vuelve a mostrar los huesos ocultos. Hide Selected (H) oculta los huesos seleccionados (sin borrarlos del Armature). Hide Unselected (Mayús+H) oculta todos menos la selección actual. |
| 🦴 | **Pose > Bone Settings: Display Wire / Deform / Multiply Vertex Group with Envelope / Inherit Rotation** | *Barra superior > Pose > Bone Settings (Mayús+W)* | Advanced | Ajustes rápidos por hueso, alternativa a entrar en Properties > Bone: Display Wire lo fuerza a dibujarse en wireframe. Deform activa/desactiva si ese hueso deforma la malla. Multiply Vertex Group with Envelope combina el peso del Vertex Group con el del Envelope en vez de usar solo uno. Inherit Rotation activa/desactiva si el hueso hereda la rotación de su padre. |
| 🗂️ | **Pose: Create Pose Asset...** | *Barra superior del Viewport 3D > Pose* | Advanced | Guarda la pose actual de los huesos seleccionados como un Asset reutilizable en el Asset Browser, para poder aplicarla más adelante a este u otro Armature con un clic en vez de reconstruirla a mano. |
| - | **Pose Options: Auto IK / X-Axis Mirror / Relative Mirror / Affect Only Locations** | *Botón 'Pose Options' en la cabecera del Viewport (solo visible en Pose Mode)* | Advanced | Auto IK (desactivado): al mover un hueso con Move, dobla automáticamente toda la cadena de huesos hasta el padre para alcanzarlo, como un Inverse Kinematics temporal sin tener que añadir el constraint. X-Axis Mirror (desactivado): aplica en espejo, sobre el hueso del lado opuesto (según el sufijo .L/.R del nombre), cualquier cambio que hagas — muy usado al posar personajes simétricos ('Apply changes to matching bone on opposite side of X-Axis', según su propio tooltip). Relative Mirror (solo activable con X-Axis Mirror encendido) hace ese espejado relativo a la pose actual del otro lado en vez de absoluto. Affect Only > Locations (desactivado) limita el X-Axis Mirror para que solo espeje la posición, sin tocar rotación ni escala. |
