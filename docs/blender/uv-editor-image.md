# UV Editor > Image


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖼️ | **New... / Open... / Open Cached Render** | *Barra superior del UV Editor > Image* | Basic | New...: crea una imagen nueva en blanco y la carga en el editor. Open...: abre un archivo de imagen existente del disco. Open Cached Render: carga como imagen el último render que Blender tiene guardado en caché en memoria. |
| 📋 | **Copy / Paste / Save All Images** | *Barra superior del UV Editor > Image* | Basic | Aparecen en gris cuando no hay ninguna imagen cargada en el editor (como en la captura). Copy/Paste: copian y pegan los píxeles de la imagen activa. Save All Images: guarda de golpe todas las imágenes abiertas que tengan cambios sin guardar. |
| ⌨️ | **New... (Imagen)** | <kbd>Alt</kbd> + <kbd>N</kbd> | Basic | New... (Imagen) |
| ⌨️ | **Open... (Imagen)** | <kbd>Alt</kbd> + <kbd>O</kbd> | Basic | Open... (Imagen) |
| ⌨️ | **Open Cached Render** | <kbd>Ctrl</kbd> + <kbd>R</kbd> | Basic | Open Cached Render |
