# Preferences > File Paths: Data


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔤 | **Fonts** | *Edit > Preferences > File Paths* | Advanced | Carpeta donde Blender busca fuentes tipográficas adicionales (aquí la carpeta de fuentes de Windows). |
| 🖼️ | **Textures** | *Edit > Preferences > File Paths* | Advanced | Carpeta por defecto que se abre al importar una textura ('//' significa 'relativa a la carpeta del .blend actual'). |
| 🔊 | **Sounds** | *Edit > Preferences > File Paths* | Advanced | Carpeta por defecto al importar archivos de audio. |
| - | **Temporary Files** | *Edit > Preferences > File Paths* | Advanced | Dónde guarda Blender sus archivos temporales; vacío = usa la carpeta temporal del sistema operativo. |
