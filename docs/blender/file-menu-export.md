# File Menu: Export


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📤 | **Alembic (.abc)** | *File > Export* | Advanced | Exporta la geometría ya deformada fotograma a fotograma; ideal para mandar simulaciones (tela, pelo, fluidos) a otro programa sin depender de huesos. |
| 📤 | **Universal Scene Description (.usd*)** | *File > Export* | Advanced | Exporta la escena en formato USD; cada vez más estándar en pipelines de estudio. |
| ✏️ | **Grease Pencil as SVG** | *File > Export* | Intermediate | Exporta los trazos de Grease Pencil como curvas vectoriales SVG (por ejemplo para llevarlos a Illustrator). |
| ✏️ | **Grease Pencil as PDF** | *File > Export* | Intermediate | Exporta los trazos de Grease Pencil como páginas PDF. |
| 📄 | **Wavefront (.obj)** | *File > Export* | Basic | Formato universal para mallas estáticas; no exporta huesos ni animación. |
| 📄 | **Stanford PLY (.ply)** | *File > Export* | Intermediate | Exporta geometría con color por vértice; típico para escaneos o point clouds. |
| 📄 | **STL (.stl)** | *File > Export* | Basic | Exporta solo geometría, sin materiales ni animación; pensado para impresión 3D. |
| 📄 | **glTF 2.0 (.glb / .gltf)** | *File > Export* | Intermediate | Formato ligero pensado para web y tiempo real; conserva los materiales PBR de forma muy fiel. |
| 📄 | **FBX (.fbx)** | *File > Export* | Basic | El formato más usado para llevar modelos, armaduras (rigs) y animaciones a Unity, Unreal o Maya. |
| 🦴 | **Motion Capture (.bvh)** | *File > Export* | Advanced | Exporta la animación del esqueleto como datos BVH; en 5.2 puede aparecer atenuado/deshabilitado si no hay una armadura o acción válida seleccionada. |
