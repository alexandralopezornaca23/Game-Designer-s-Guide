# Properties > Effects


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🪄 | **Effects: qué es esta pestaña y cuándo aparece** | *Panel Properties > Effects (icono de estrella, solo en objetos Grease Pencil)* | Intermediate | Pestaña EXTRA exclusiva de los objetos Grease Pencil (no existe en Mesh/Curve/Text/Metaball ni en ningún otro tipo visto hasta ahora). Aplica efectos visuales de post-proceso 2D al dibujo, apilables como un stack (parecido en concepto a los Modifiers pero pensado para trazos 2D en vez de geometría 3D). Se añaden desde el desplegable Add Effect; cada efecto añadido aparece como un panel propio con icono de ojo/cámara para activar su visibilidad en Viewport/Render y una X para eliminarlo. |
| - | **Effects: ¿aparece también en otros tipos de objeto?** | — | Intermediate | No verificado con captura de la barra vertical de Properties para el resto de tipos aún pendientes (Lattice/Surface/Point Cloud/Volume/Light Probe), pero de los 9 tipos ya profundizados (Mesh, Cámara, Light x4, Speaker, Armature, Curve, Text, Metaball) ninguno tiene esta pestaña — Effects trabaja sobre trazos 2D tipo stroke, así que conceptualmente no debería aparecer en objetos con geometría 3D normal. Se confirmará type por type según se vaya completando la verificación pestaña-por-tipo-de-objeto ya en marcha; si aparece en alguno de los pendientes, probablemente comparta los mismos 9 efectos ya documentados aquí (misma lógica que Bone Constraint reutilizando los 27 Object Constraints). |
| 🌫️ | **Add Effect > Blur: Samples / Use Depth of Field / Size X-Y / Rotation** | *Panel Properties > Effects > Blur* | Advanced | Difumina el dibujo. Samples (8 verificado): calidad/suavidad del desenfoque, más samples = más suave pero más lento de calcular. Use Depth of Field (desactivado): si se activa, el desenfoque varía según la distancia a la cámara en vez de ser uniforme, ligado a los ajustes de profundidad de campo de la cámara. Size X/Y (50.000/50.000): intensidad del desenfoque en cada eje. Rotation (0°): gira la dirección del desenfoque cuando X e Y no son iguales. |
| 🌈 | **Add Effect > Colorize: Mode / Factor** | *Panel Properties > Effects > Colorize* | Intermediate | Recolorea el dibujo. Mode (desplegable, Gray Scale verificado: convierte el dibujo a blanco y negro; existen otros modos no verificados en esta captura como teñir con un color concreto o un degradado). Factor (0.500): mezcla entre el color original y el resultado del efecto. |
| ↔️ | **Add Effect > Flip: Axis (Horizontal / Vertical)** | *Panel Properties > Effects > Flip* | Basic | Voltea el dibujo. Axis con dos botones tipo interruptor, Horizontal activado en la captura (voltea de izquierda a derecha); Vertical (voltea arriba/abajo) puede activarse a la vez o en su lugar. |
| 🌟 | **Add Effect > Glow: Mode / Threshold / Glow Color / Blend Mode / Opacity** | *Panel Properties > Effects > Glow* | Advanced | Añade un resplandor luminoso al dibujo. Mode (Luminance verificado): qué parte del dibujo brilla, según su luminosidad. Threshold (0.100): a partir de qué brillo empieza a generarse el resplandor. Glow Color (swatch cian en la captura): color del resplandor. Blend Mode (Regular) y Opacity (1.000): cómo y cuánto se mezcla el resplandor con el dibujo original. |
| - | **Add Effect > Glow: Size X-Y / Rotation / Samples / Glow Under** | *Panel Properties > Effects > Glow* | Advanced | Size X/Y (50.000/50.000): extensión del resplandor alrededor del dibujo. Rotation (0°): gira esa extensión cuando X e Y no son iguales. Samples (8): calidad del resplandor. Glow Under (desactivado): si está activo, el resplandor se dibuja por debajo del trazo original en vez de por encima, para que no tape el propio dibujo. |
| 🔲 | **Add Effect > Pixelate: Size X-Y / Antialiasing** | *Panel Properties > Effects > Pixelate* | Basic | Pixela el dibujo, como un efecto retro de baja resolución. Size X/Y (5px/5px verificado): tamaño de cada 'píxel' resultante. Antialiasing (activado): suaviza los bordes entre píxeles en vez de dejarlos completamente duros/dentados. |
| 🌗 | **Add Effect > Rim: Rim Color / Mask Color / Blend Mode / Offset X-Y** | *Panel Properties > Effects > Rim* | Advanced | Añade un contorno/silueta al dibujo tipo 'rim light'. Rim Color (swatch amarillo en la captura): color de ese contorno. Mask Color (swatch negro): color que se usa internamente para calcular qué parte del dibujo genera el contorno. Blend Mode (Overlay verificado): cómo se mezcla el contorno con el dibujo. Offset X/Y (50px/-100px): desplaza el contorno respecto al dibujo original, para efectos de sombra proyectada estilo cómic. |
| - | **Add Effect > Rim > Blur (sub-panel)** | *Panel Properties > Effects > Rim > Blur* | Advanced | Sub-panel colapsado en la captura, no expandido - no verificado su contenido exacto en esta tanda (pendiente de una captura con este sub-panel desplegado). |
| 🌑 | **Add Effect > Shadow: Shadow Color / Offset X-Y / Scale X-Y / Rotation** | *Panel Properties > Effects > Shadow* | Advanced | Genera una sombra proyectada del dibujo, como un drop shadow 2D. Shadow Color (negro/transparente en la captura): color de la sombra. Offset X/Y (15px/20px): desplazamiento de la sombra respecto al dibujo original. Scale X/Y (1.000/1.000): tamaño de la sombra respecto al original. Rotation (0°): gira la sombra. |
| - | **Add Effect > Shadow: Object Pivot** | *Panel Properties > Effects > Shadow* | Advanced | Object Pivot (desactivado, campo Object vacío en la captura): en vez de desplazar la sombra con valores fijos de Offset, permite indicar otro objeto de la escena como pivote, para que la sombra se proyecte y se mueva en función de la posición de ese objeto (por ejemplo, simulando una fuente de luz que se mueve). |
| - | **Add Effect > Shadow > Blur (sub-panel): Blur X-Y / Samples** | *Panel Properties > Effects > Shadow > Blur* | Advanced | Sub-panel expandido en la captura, activo por defecto: difumina la sombra para que no tenga un borde completamente duro. Blur X/Y (5px/5px verificado): intensidad del desenfoque en cada eje. Samples (2 verificado): calidad de ese desenfoque. |
| - | **Add Effect > Shadow > Wave Effect (sub-panel): Orientation / Amplitude / Period / Phase** | *Panel Properties > Effects > Shadow > Wave Effect* | Advanced | Sub-panel presente pero desactivado (checkbox sin marcar) en la captura, por lo que sus valores no están activos: Orientation (Vertical verificado), Amplitude (10.000), Period (20.000), Phase (0.000). Al activarlo, deforma la sombra con una onda según esos parámetros, para sombras tipo agua/bandera en vez de una silueta recta. |
| 🌀 | **Add Effect > Swirl: Object / Radius / Angle** | *Panel Properties > Effects > Swirl* | Intermediate | Retuerce el dibujo en espiral alrededor de un punto. Object (campo vacío en la captura): objeto de la escena cuya posición marca el centro del remolino; sin uno asignado, no verificado qué punto se usa por defecto en esta captura. Radius (100px): hasta qué distancia del centro llega el efecto. Angle (90° verificado): cuánto se retuerce el dibujo dentro de ese radio. |
| 🌊 | **Add Effect > Wave Distortion: Orientation / Amplitude / Period / Phase** | *Panel Properties > Effects > Wave Distortion* | Intermediate | Deforma el dibujo con una onda, como si ondeara al viento o flotara en agua. Orientation (Horizontal/Vertical, Vertical verificado en la captura): eje a lo largo del cual viaja la onda. Amplitude (10.000): qué tan pronunciada es la onda. Period (20.000): longitud de cada ciclo de onda. Phase (0.000): desplaza el punto de inicio de la onda, útil para animarla cambiando este valor con el tiempo. |
