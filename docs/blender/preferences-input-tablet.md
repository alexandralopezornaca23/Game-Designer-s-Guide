# Preferences > Input: Tablet


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖊️ | **Tablet API** | *Edit > Preferences > Input > Tablet* | Advanced | Qué controlador usa Blender para leer la tableta gráfica; 'Automatic' deja que Blender elija el mejor disponible en tu sistema. |
| - | **Max Threshold** | *Edit > Preferences > Input > Tablet* | Advanced | Presión del lápiz a partir de la cual se considera presión máxima (1.0 = necesitas apretar a fondo para llegar al 100%). |
| - | **Softness** | *Edit > Preferences > Input > Tablet* | Advanced | Suaviza la curva de respuesta de la presión del lápiz, para que los cambios de presión se noten más progresivos. |
