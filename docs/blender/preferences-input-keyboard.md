# Preferences > Input: Keyboard


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Emulate Numpad** | *Edit > Preferences > Input > Keyboard* | Advanced | Permite usar los números normales de la fila superior del teclado como si fueran el numpad; útil en portátiles sin teclado numérico, ya que Blender usa mucho el numpad para las vistas (1=Front, 7=Top...). |
| - | **Default to Advanced Numeric Input** | *Edit > Preferences > Input > Keyboard* | Advanced | Al escribir un valor numérico en un campo, activa por defecto el modo avanzado que permite meter expresiones matemáticas (como *2 o +5) en vez de solo el número. |
