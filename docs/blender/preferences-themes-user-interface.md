# Preferences > Themes: User Interface


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎨 | **Categorías de User Interface** | *Edit > Preferences > Themes > User Interface* | Intermediate | Contiene el color de los elementos genéricos que se repiten en TODOS los editores de Blender (no son específicos de uno): Box, Curve, List Item, Menu, Menu Background, Menu Item, Number Field, Option, Pie Menu, Progress Bar, Pulldown, Radio Buttons, Regular, Scroll Bar, Tab, Text, Toggle, Tool, Toolbar Item, Tooltip, Value Slider, Panel, State, Icons, Text Style, Axes & Gizmos y Editor & Widgets. Cambiar aquí un color lo cambia en todas partes donde aparezca ese tipo de elemento. |
| - | **Box (patrón que siguen la mayoría de sub-paneles)** | *Edit > Preferences > Themes > User Interface > Box* | Intermediate | La mayoría de estos sub-paneles repiten esta misma estructura: colores de Text/Selected/Item (texto normal, seleccionado y de un ítem), Inner/Selected/Outline (relleno normal, relleno al seleccionar y borde), un slider de Roundness (0 a 1, qué tan redondeadas son las esquinas) y un grupo opcional Shaded con Shade Top/Down para un degradado falso de luz. El resto de sub-paneles (Menu, Tab, Panel...) cambian QUÉ elemento visual afectan, pero casi siempre con esta misma lógica de colores. |
