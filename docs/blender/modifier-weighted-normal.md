# Modifier: Weighted Normal


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Weight** | *Dentro del modificador* | Intermediate | Cuánto peso tiene el ángulo/área de cada cara al recalcular las normales; afecta a lo suave o marcado que se ve el sombreado. |
| - | **Keep Sharp** | *Dentro del modificador* | Intermediate | Respeta las aristas marcadas como Sharp (clic derecho > Mark Sharp) al recalcular el sombreado, para no perder los cortes duros. |
