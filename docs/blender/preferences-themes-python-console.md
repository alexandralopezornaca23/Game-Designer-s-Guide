# Preferences > Themes: Python Console


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🐍 | **Colores de la consola** | *Edit > Preferences > Themes > Python Console* | Intermediate | Colorea cada tipo de línea de la Python Console: Line Input (lo que escribes tú), Line Output (lo que devuelve Blender), Line Info (mensajes informativos), Line Error, y Cursor/Selection para el cursor de texto y el texto seleccionado dentro de la consola. |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Python Console > Theme Space* | Basic | Mismo patrón repetido en todos los editores. |
