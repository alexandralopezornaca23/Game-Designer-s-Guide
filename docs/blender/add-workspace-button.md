# Add Workspace (+ button)


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ➕ | **¿Qué hace el botón +?** | *Pestañas superiores > + (al final de todas las pestañas)* | Basic | Abre un menú para añadir una pestaña de Workspace NUEVA a las que ya tienes (se pueden repetir, por ejemplo tener dos pestañas 'Shading' distintas configuradas de forma diferente); no sustituye a las que ya existen. Estos son los Workspaces predefinidos de Blender, agrupados por categoría en el menú. |
| - | **General** | *Botón + > General* | Basic | Categoría con los Workspaces 'estándar', los mismos 11 que trae Blender por defecto y que ya están documentados uno a uno más arriba: Animation, Compositing, Geometry Nodes, Layout, Modeling, Rendering, Scripting, Sculpting, Shading, Texture Paint, UV Editing. |
| ✏️ | **2D Animation** | *Botón + > 2D Animation* | Intermediate | Categoría con 2 plantillas pensadas para animación 2D/Grease Pencil: '2D Animation' (para animar dibujando fotograma a fotograma) y '2D Full Canvas' (lienzo 2D a pantalla completa, sin paneles alrededor). |
| 🖌️ | **Sculpting** | *Botón + > Sculpting* | Intermediate | Categoría con 2 plantillas: 'Sculpting' (igual a la pestaña Sculpting ya documentada) y 'Shading' (igual a la pestaña Shading ya documentada); útil si quieres, por ejemplo, una segunda pestaña de Sculpting configurada de otra forma. |
| 🎬 | **Storyboarding** | *Botón + > Storyboarding* | Intermediate | Categoría con 2 plantillas: 'Storyboarding' (pensada para dibujar y planificar tomas con Grease Pencil antes de animar) y 'Video Editing' (igual a la de la categoría Video Editing). |
| 🎆 | **VFX** | *Botón + > VFX* | Advanced | Categoría con 4 plantillas para efectos visuales: 'Compositing' (igual a la ya documentada), 'Masking' (para dibujar máscaras 2D de rotoscopia sobre un vídeo/imagen), 'Motion Tracking' (para el tracking de cámara/objetos sobre una filmación real, ver 'Selector de tipo de editor: General > Movie Clip Editor') y 'Rendering' (igual a la ya documentada). |
| 🎞️ | **Video Editing** | *Botón + > Video Editing* | Intermediate | Categoría con 2 plantillas: 'Rendering' (igual a la ya documentada) y 'Video Editing' (Video Sequencer a pantalla completa para montar clips, ver 'Selector de tipo de editor: General > Video Sequencer'). |
| 📑 | **Duplicate Current** | *Botón + > Duplicate Current* | Basic | En vez de una plantilla nueva, duplica la pestaña de Workspace que tengas activa ahora mismo (con toda su configuración de paneles tal cual está), para tener dos versiones distintas del mismo tipo de Workspace, por ejemplo dos 'Layout' con distinta distribución de paneles. |
