# Preferences > Themes: Image/UV Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🗺️ | **Selección de malla UV** | *Edit > Preferences > Themes > Image/UV Editor* | Intermediate | Color de la rejilla, y de Vertex/Vertex Select, Face/Face Selection/Face Mode Selection, Active Vertex/Edge/Face y Wire Edit/Edge Select: los mismos conceptos de selección que en el Viewport 3D pero aplicados a los vértices UV desplegados en el Image/UV Editor. |
| 🗺️ | **Stitch Preview y otros** | *Edit > Preferences > Themes > Image/UV Editor* | Advanced | Scope Region Background (fondo de los histogramas/scopes); los Stitch Preview Face/Edge/Vertex/Stitchable/Unstitchable/Active Island son los colores que se ven al usar la herramienta Stitch (coser dos bordes UV) para previsualizar qué se va a unir; Texture Paint/Modifier UVs colorea el mapa UV usado por Texture Paint o un modifier; Metadata Background/Text es la info superpuesta a la imagen (EXIF, cámara); Vertex Size, Face Dot Size y Edge Width controlan el tamaño en píxeles de esos elementos. |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Image/UV Editor > Theme Space* | Basic | Mismo patrón repetido en todos los editores: Window Background, Title, Text, Text Highlight, Header, Header Text y Header Text Highlight. |
