# T Panel: Node Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Select / Annotate** | *Barra T del editor de nodos (Compositor/Shader/Geometry Nodes)* | Basic | En cualquier editor de nodos (Compositor, Shader Editor, Geometry Nodes, Texture Node Editor) la Barra T se reduce a solo estas herramientas, ya que no aplican transformaciones 3D: Select (selección por caja de nodos, igual que Select Box) y Annotate (dibujar notas a mano alzada sobre el propio grafo de nodos). |
| ✂️ | **Links Cut** | *Barra T del editor de nodos > Links Cut (Mayús+Barra espaciadora, 6)* | Intermediate | Corta (elimina) las conexiones entre nodos: arrastra el ratón como si fueran unas tijeras sobre los cables/links que quieras desconectar. |
| 🔇 | **Mute Links** | *Barra T del editor de nodos > Mute Links (Mayús+Barra espaciadora, 7)* | Intermediate | Silencia (desactiva temporalmente sin borrar el cableado) las conexiones sobre las que arrastras el ratón: el nodo de destino deja de recibir esos datos hasta que se vuelva a activar el link, sin tener que reconectar nada a mano. |
| 🔌 | **Add Reroute** | *Barra T del editor de nodos > Add Reroute (Mayús+Barra espaciadora, 8)* | Intermediate | Añade sobre la marcha un nodo Reroute (un punto de paso neutro, sin efecto en el resultado) allí donde arrastres sobre un link; útil para organizar visualmente conexiones largas o que se cruzan, sin cambiar nada del cálculo final. |
| ✂️ | **Links Cut** | *Barra T de cualquier editor de nodos (Compositor/Shader Editor/Geometry Nodes) > Links Cut (Mayús+Barra espaciadora → 6)* | Intermediate | Corta (elimina) los cables por los que se arrastre el ratón, sin tocar los nodos; mismo efecto que 'Node > Cut Links' pero como herramienta persistente en vez de un solo gesto con Ctrl+arrastrar. |
| ⌨️ | **Links Cut** | *Mayús+Barra espaciadora, 6* | Intermediate | Links Cut |
| 🔇 | **Mute Links** | *Barra T de cualquier editor de nodos (Compositor/Shader Editor/Geometry Nodes) > Mute Links (Mayús+Barra espaciadora → 7)* | Intermediate | Silencia los cables por los que se arrastre el ratón (deja de pasar el dato por ellos sin borrarlos); mismo efecto que 'Node > Mute Links' pero como herramienta persistente. |
| ⌨️ | **Mute Links** | *Mayús+Barra espaciadora, 7* | Intermediate | Mute Links |
| 🔀 | **Add Reroute** | *Barra T de cualquier editor de nodos (Compositor/Shader Editor/Geometry Nodes) > Add Reroute (Mayús+Barra espaciadora → 8)* | Intermediate | Añade un nodo Reroute justo en el punto del cable donde se hace clic, dividiéndolo en dos tramos; útil para reordenar el cableado sin usar el menú Add > Layout > Reroute. |
| ⌨️ | **Add Reroute** | *Mayús+Barra espaciadora, 8* | Intermediate | Add Reroute |
