# Preferences > Viewport: Textures


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Limit Size** | *Edit > Preferences > Viewport > Textures* | Advanced | Limita la resolución máxima con la que se muestran las texturas en el viewport (aquí 'Off' = sin límite); bajarlo ayuda al rendimiento sin tocar la textura real. |
| - | **Anisotropic Filtering** | *Edit > Preferences > Viewport > Textures* | Advanced | Mejora la nitidez de las texturas vistas en ángulo (por ejemplo un suelo alejándose hacia el horizonte); más nivel = más nítido pero más coste. |
| - | **Clip Alpha** | *Edit > Preferences > Viewport > Textures* | Advanced | Umbral de transparencia por debajo del cual el viewport deja de dibujar los píxeles de una textura con canal alfa (hojas, vallas...), para ahorrar rendimiento. |
