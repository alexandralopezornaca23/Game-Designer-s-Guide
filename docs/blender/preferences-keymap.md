# Preferences > Keymap


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ⌨️ | **Perfil activo, Import.../Export...** | *Edit > Preferences > Keymap* | Intermediate | Es la pestaña donde se ven y se personalizan TODOS los atajos de teclado/ratón de Blender, organizados por editor o contexto. El desplegable de arriba (por defecto 'Blender') selecciona el perfil de atajos activo (por ejemplo, hay perfiles alternativos como 'Industry Compatible' para quien viene de otros programas); los botones +/- crean o borran un perfil propio partiendo del activo; Import.../Export... guardan o cargan un perfil de atajos como archivo .py, útil para llevarte tu configuración a otro ordenador o compartirla. |
| ⌨️ | **Pestañas Name / Key-Binding y Search by Name** | *Edit > Preferences > Keymap* | Basic | Name muestra la lista de acciones por su nombre; Key-Binding cambia la vista para centrarse en qué tecla tiene asignada cada una; el buscador 'Search by Name' filtra toda la lista gigante por el nombre de la acción, la forma más rápida de encontrar y cambiar UN atajo concreto sin bajar a mano por las categorías. |
| ⌨️ | **Lista completa de categorías (Window, Screen, 3D View, Graph Editor...)** | *Edit > Preferences > Keymap* | Advanced | Debajo de Preferences se despliega la lista completa de contextos de Blender (Window, Screen, View2D, User Interface, 3D View, Graph Editor, Dopesheet, NLA Editor, Image, Outliner, Node Editor, Spreadsheet, Video Sequence Editor, File Browser, Info, Property Editor, Text, Console, Clip, Grease Pencil, Mask Editing, Frames, Markers, Animation, Animation Channels, los Modal Maps de gestos y herramientas, Generic Gizmo, etc.). Cada una, al expandirla, muestra TODOS los atajos de ese contexto y permite hacer clic en la combinación de teclas para reasignarla a otra. No se documenta cada atajo individual aquí porque ya están reflejados en la columna 'Atajo / Ubicación' de cada herramienta a lo largo de esta guía; esta pestaña es el sitio donde ir si quieres CAMBIAR alguno de esos atajos por otro de tu preferencia, no una lista nueva de información. |
