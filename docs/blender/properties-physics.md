# Properties > Physics


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🌪️ | **Force Field: Type** | *Panel Properties > pestaña Physics > Force Field* | Intermediate | Convierte el objeto en un campo de fuerza (Force, Wind, Vortex, Magnetic, Harmonic, Charge, Lennard-Jones, Turbulence, Drag, Fluid Flow, Boid, Curve Guide, Texture...) que afecta a otras simulaciones (partículas, cloth, soft body...). |
| - | **Force Field > Settings: Shape / Strength / Flow / Affect / Noise / Seed** | *Panel Properties > Physics > Force Field > Settings* | Advanced | Shape: forma del campo (Point, Plane, Surface, Curve...). Strength: intensidad de la fuerza. Flow: cuánto arrastra el campo a fluidos/partículas como si fuera viento en un medio. Affect Location/Rotation: si la fuerza mueve la posición y/o gira el objeto afectado. Noise Amount: aleatoriedad añadida a la fuerza. Seed: semilla de esa aleatoriedad. |
| - | **Force Field > Settings: Gravitation / Absorption / Wind Factor** | *Panel Properties > Physics > Force Field > Settings* | Advanced | Gravitation: si el campo se comporta como gravedad (atrae hacia sí según la masa). Absorption: cuánta fuerza 'absorbe' un objeto Force Field al ser atravesado (resta al campo). Wind Factor: solo en Type Wind, cuánta velocidad transmite a objetos con Rigid Body. |
| - | **Force Field > Falloff: Shape / Z Direction / Power / Min Distance / Max Distance** | *Panel Properties > Physics > Force Field > Falloff* | Advanced | Shape: cómo decae la fuerza con la distancia (Sphere = en todas direcciones, Tube = en un cilindro). Z Direction: limita el efecto a Positive Z, Negative Z o Both Z. Power: exponente de la caída (más alto = cae más rápido). Min/Max Distance: activan un rango de distancia fuera del cual el campo no afecta (o afecta al máximo). |
| 💥 | **Collision** | *Panel Properties > Physics > Collision* | Intermediate | Hace que el objeto actúe como obstáculo sólido para telas, partículas o fluidos de otros objetos. |
| - | **Collision > Particle: Permeability / Stickiness / Kill Particles / Friction / Randomize / Damping / Randomize** | *Panel Properties > Physics > Collision > Particle* | Advanced | Controla cómo reaccionan las PARTÍCULAS al chocar con este objeto: Permeability (probabilidad de atravesarlo igualmente), Stickiness (se quedan pegadas), Kill Particles (mueren al tocarlo), Friction/Damping (frenado al rozar/rebotar) y sus respectivos Randomize (variación aleatoria de cada valor). |
| - | **Collision > Softbody & Cloth: Damping / Thickness Outer/Inner / Friction / Single Sided / Override Normals** | *Panel Properties > Physics > Collision > Softbody & Cloth* | Advanced | Controla cómo reaccionan TELA y SOFT BODY al chocar con este objeto: Damping amortigua el rebote, Thickness Outer/Inner define el grosor de colisión por fuera/dentro de la malla, Friction frena el deslizamiento, Single Sided solo colisiona por el lado de las normales, Override Normals fuerza el cálculo de normales para la colisión. |
| 🧵 | **Cloth: header Quality Steps / Speed Multiplier** | *Panel Properties > Physics > Cloth* | Advanced | Simulación de tela (ropa, banderas, cortinas...). Quality Steps: pasos de cálculo por frame (más = más precisión y coste). Speed Multiplier: acelera o ralentiza la simulación entera sin recalcular los frames. |
| - | **Cloth > Physical Properties: Vertex Mass / Air Viscosity / Bending Model** | *Panel Properties > Physics > Cloth > Physical Properties* | Advanced | Vertex Mass: masa de cada vértice de la tela, afecta inercia y caída. Air Viscosity: resistencia del aire que frena el movimiento. Bending Model: Angular (más estable, recomendado) o Linear (método de cálculo del pliegue de la tela). |
| - | **Cloth > Stiffness & Damping: Tension / Compression / Shear / Bending** | *Panel Properties > Physics > Cloth > Stiffness and Damping* | Advanced | Tension/Compression: rigidez y amortiguación al estirar/comprimir la tela. Shear: resistencia a deformarse en diagonal. Bending: rigidez al doblarse/plegarse (bajo = tela fina y flexible, alto = tipo cuero o cartón). |
| - | **Cloth > Internal Springs** | *Panel Properties > Physics > Cloth > Internal Springs* | Advanced | Crea muelles internos entre capas opuestas de la tela (por ejemplo, para que un cojín no se aplaste del todo): Max Spring Creation Length, Max Creation Diversion, Check Surface Normals, Tension/Compression y un Vertex Group para limitar dónde se generan, con sus valores Max. |
| - | **Cloth > Pressure** | *Panel Properties > Physics > Cloth > Pressure* | Advanced | Simula presión interna de aire dentro de una malla cerrada (globos, cojines inflables): Pressure/Pressure Scale (cantidad de presión), Custom Volume (volumen de referencia manual), Fluid Density (si está conectada a una simulación de fluidos) y un Vertex Group para variar la presión por zona. |
| - | **Cloth > Cache: Simulation Start/End / Bake** | *Panel Properties > Physics > Cloth > Cache* | Advanced | Igual que la Cache de Particles: Simulation Start/End definen el rango de frames simulado y los botones Bake precalculan y guardan la simulación para que se reproduzca siempre igual. |
| - | **Cloth > Shape: Pin Group / Stiffness / Shrinking Factor / Sewing / Dynamic Mesh** | *Panel Properties > Physics > Cloth > Shape* | Advanced | Pin Group: Vertex Group que fija ciertos vértices en el aire (para colgar la tela). Stiffness: rigidez de esos puntos fijados. Shrinking Factor: encoge la tela un porcentaje. Sewing/Max Sewing Force: cose bordes marcados como Seam, tirando de ellos hasta unirlos. Dynamic Mesh: permite que la simulación siga funcionando si la malla cambia de topología (Shape Keys, Modifiers previos...). |
| - | **Cloth > Collisions: Object Collisions / Self Collisions** | *Panel Properties > Physics > Cloth > Collisions* | Advanced | Object Collisions: activa que la tela choque con otros objetos Collision (con Distance, Impulse Clamping, Vertex Group y Collision Collection para afinar). Self Collisions: activa que la tela choque consigo misma (imprescindible en ropa arrugada), con sus propios ajustes de distancia y grosor. |
| - | **Cloth > Property Weights: Structural / Shear / Bending / Shrinking Groups** | *Panel Properties > Physics > Cloth > Property Weights* | Advanced | Vincula Tension/Compression/Shear/Bending/Shrinking a Vertex Groups pintados en Weight Paint, con un valor Max por grupo, para que la rigidez de la tela varíe por zona (por ejemplo, cuello más rígido que la falda). |
| 🖌️ | **Dynamic Paint: Type Canvas / Brush** | *Panel Properties > Physics > Dynamic Paint* | Advanced | Permite que un objeto 'pinte' sobre otro al tocarlo: huellas, charcos que se mojan, calor o texturas que reaccionan al contacto. Un objeto se marca como Canvas (superficie que recibe la pintura, con el botón 'Add Canvas') y otro como Brush (el que pinta, con 'Add Brush'). |
| 🫧 | **Soft Body** | *Panel Properties > Physics > Soft Body* | Advanced | Simulación de cuerpo blando/gelatinoso: la malla se deforma por gravedad, colisiones y su propia física interna, como si fuera goma o gel. |
| - | **Soft Body > Object: Friction / Mass / Control Point** | *Panel Properties > Physics > Soft Body > Object* | Advanced | Friction: rozamiento general del cuerpo blando. Mass: masa por defecto de cada punto de la malla (se puede afinar por Vertex Group en Goal). Control Point: vértice/objeto que puede usarse como referencia para efectos adicionales. |
| - | **Soft Body > Simulation: Speed** | *Panel Properties > Physics > Soft Body > Simulation* | Advanced | Acelera o ralentiza la simulación completa de Soft Body sin cambiar el resto de parámetros físicos. |
| - | **Soft Body > Cache: Simulation Start/End / Bake** | *Panel Properties > Physics > Soft Body > Cache* | Advanced | Mismo sistema de caché/Bake que Cloth y Particles: fija el rango de frames y precalcula la simulación para reproducirla siempre igual. |
| - | **Soft Body > Goal: Vertex Group / Stiffness / Damping / Strength Default-Min-Max** | *Panel Properties > Physics > Soft Body > Goal* | Advanced | Goal ancla la malla a su forma original (como si tuviera un imán hacia la posición de reposo). Vertex Group permite que unas zonas sean más rígidas que otras (0 = se mueve libre, 1 = fijo). Stiffness/Damping controlan la fuerza y amortiguación de ese anclaje, y Strength Default/Min/Max limitan el rango cuando se usa Vertex Group. |
| - | **Soft Body > Edges: Springs / Pull / Push / Damp / Length / Plasticity / Bending / Collision Edge-Face** | *Panel Properties > Physics > Soft Body > Edges* | Advanced | Convierte cada arista en un muelle: Pull/Push controlan la resistencia a estirarse/comprimirse, Damp la amortiguación, Length su longitud de reposo, Plasticity si la deformación queda permanente, Bending la rigidez al doblar caras adyacentes, y Collision Edge/Face activa que las propias aristas o caras colisionen entre sí (evita que la malla se autoatraviese). |
| - | **Soft Body > Aerodynamics: Type / Factor** | *Panel Properties > Physics > Soft Body > Aerodynamics* | Advanced | Simula el efecto del aire sobre la superficie: Type Simple (resistencia básica) o Lift Force (también genera sustentación, como una vela o un ala). Factor: intensidad de ese efecto. |
| - | **Soft Body > Stiffness: Shear** | *Panel Properties > Physics > Soft Body > Stiffness* | Advanced | Rigidez adicional frente a la deformación en diagonal (cizalla) de la malla del cuerpo blando. |
| - | **Soft Body > Self Collision: Calculation Type / Ball Size / Stiffness / Dampening** | *Panel Properties > Physics > Soft Body > Self Collision* | Advanced | Evita que la propia malla del cuerpo blando se atraviese a sí misma, tratando cada vértice como una bola (Ball Size = su radio); Calculation Type define el método de cálculo de esas colisiones, y Stiffness/Dampening su rigidez y amortiguación. |
| - | **Soft Body > Solver: Step Size Min/Max / Auto-Step / Error Limit** | *Panel Properties > Physics > Soft Body > Solver* | Advanced | Controla la precisión del cálculo físico: Step Size Min/Max define el rango de subpasos por frame, Auto-Step lo ajusta automáticamente según la velocidad del movimiento, y Error Limit la tolerancia de error antes de forzar más precisión. |
| - | **Soft Body > Solver > Diagnostics / Helpers: Choke / Fuzzy** | *Panel Properties > Physics > Soft Body > Solver* | Advanced | Diagnostics muestra información de depuración del solver en pantalla. Helpers (Choke/Fuzzy) ayudan a estabilizar colisiones difíciles, reduciendo la velocidad o suavizando el contacto en los puntos donde la simulación se atasca. |
| 💧 | **Fluid: Type None / Domain / Flow / Effector** | *Panel Properties > Physics > Fluid* | Advanced | Simulación de líquidos y humo/fuego. Cada objeto implicado se marca con un Type: Domain (la caja que contiene y calcula toda la simulación), Flow (emite líquido, humo o fuego), Effector (obstáculo o influencia dentro del dominio) o None (sin física de fluidos). |
| 🪨 | **Rigid Body** | *Panel Properties > Physics > Rigid Body* | Intermediate | Simulación de cuerpo rígido: el objeto se mueve y choca de forma realista por gravedad y colisiones, sin deformarse (piedras, muebles, escombros...). |
| - | **Rigid Body > Settings: Type / Mass / Dynamic / Animated** | *Panel Properties > Physics > Rigid Body > Settings* | Advanced | Type: Active (se mueve por la física) o Passive (obstáculo fijo, como el suelo). Mass: peso del objeto, afecta a los choques. Dynamic: si está desactivado, el objeto Active no se mueve solo pero sigue chocando con otros. Animated: permite mezclar keyframes normales con la simulación física en el mismo objeto. |
| - | **Rigid Body > Collisions: Shape / Source** | *Panel Properties > Physics > Rigid Body > Collisions* | Advanced | Shape: forma simplificada usada para calcular colisiones (Box, Sphere, Convex Hull, Mesh...); formas simples son mucho más rápidas de calcular que Mesh exacta. Source: si la forma se calcula a partir de Base (malla original) o Deform (malla ya deformada por modificadores). |
| - | **Rigid Body > Surface Response: Friction / Bounciness** | *Panel Properties > Physics > Rigid Body > Surface Response* | Advanced | Friction: rozamiento al deslizar contra otras superficies. Bounciness (restitución): cuánto rebota el objeto al chocar (0 = no rebota, 1 = rebote perfecto). |
| - | **Rigid Body > Sensitivity: Collision Margin** | *Panel Properties > Physics > Rigid Body > Sensitivity* | Advanced | Collision Margin: un pequeño margen extra alrededor de la Shape de colisión para evitar que los objetos se atraviesen o se 'hundan' ligeramente al tocarse; puede desactivarse para colisiones más exactas pero menos estables. |
| - | **Rigid Body > Collections** | *Panel Properties > Physics > Rigid Body > Collections* | Advanced | Agrupa objetos Rigid Body en colecciones de colisión: solo los objetos que comparten al menos una casilla marcada chocan entre sí, útil para separar simulaciones que no deben interactuar. |
| - | **Rigid Body > Dynamics: Damping Translation / Rotation** | *Panel Properties > Physics > Rigid Body > Dynamics* | Advanced | Frena progresivamente la velocidad lineal (Translation) y de giro (Rotation) del objeto con el tiempo, simulando resistencia del aire; valores altos hacen que el objeto se detenga antes. |
| - | **Rigid Body > Deactivation** | *Panel Properties > Physics > Rigid Body > Deactivation* | Advanced | Panel colapsado por defecto: controla si el objeto 'se duerme' (deja de calcularse) al quedar quieto, para ahorrar rendimiento en escenas con muchos Rigid Bodies. |
| ⛓️ | **Rigid Body Constraint: Type** | *Panel Properties > Physics > Rigid Body Constraint* | Intermediate | Une dos objetos Rigid Body entre sí, como una articulación física. Type define el tipo de unión: Fixed (soldados, no se mueven entre sí), Point (bisagra libre en todos los ejes, tipo rótula), Hinge (bisagra en un solo eje, como una puerta), Slider (desliza en un eje), Piston (desliza y gira en un eje, como un amortiguador), Generic (combina límites lineales y angulares en los 3 ejes a la vez), Generic Spring (como Generic pero con muelles) y Motor (gira o desliza con fuerza propia, motorizado). |
| - | **Rigid Body Constraint > Settings: Enabled / Disable Collisions / Breakable / Threshold** | *Panel Properties > Physics > Rigid Body Constraint > Settings* | Advanced | Enabled: activa o desactiva la unión sin borrarla. Disable Collisions: evita que los dos objetos unidos choquen entre sí (evita temblores por su propia unión). Breakable: la unión se rompe si la fuerza supera el Threshold indicado, simulando roturas. |
| - | **Rigid Body Constraint > Objects: First / Second** | *Panel Properties > Physics > Rigid Body Constraint > Objects* | Advanced | Los dos objetos Rigid Body que quedan unidos por este constraint; el orden no suele importar salvo en tipos con Motor. |
| - | **Rigid Body Constraint > Override Iterations** | *Panel Properties > Physics > Rigid Body Constraint > Override Iterations* | Advanced | Permite fijar manualmente cuántas Iterations de cálculo usa esta unión en concreto, en vez de heredar el valor global de la escena; más iteraciones = unión más estable pero más costosa. |
| - | **Rigid Body Constraint > Type: Fixed / Point (sin Limits)** | *Panel Properties > Physics > Rigid Body Constraint > Limits* | Advanced | Fixed y Point no tienen sección Limits: Fixed no permite ningún movimiento relativo entre los objetos, y Point permite rotación libre en los 3 ejes (rótula) sin límites configurables. |
| - | **Rigid Body Constraint > Type Hinge: Limits > Angular Z Angle** | *Panel Properties > Physics > Rigid Body Constraint > Limits* | Advanced | Hinge solo gira en el eje Z: Angular Z Angle (desactivado por defecto) permite fijar un ángulo mínimo y máximo de apertura, por ejemplo -45°/45°, como el tope de una puerta. |
| - | **Rigid Body Constraint > Type Slider: Limits > Linear X Axis** | *Panel Properties > Physics > Rigid Body Constraint > Limits* | Advanced | Slider solo se desliza en el eje X: Linear X Axis (desactivado por defecto) permite fijar una distancia mínima y máxima de desplazamiento, por ejemplo -1m/1m, como un cajón que no se puede sacar del todo. |
| - | **Rigid Body Constraint > Type Piston: Limits > Angular X Angle + Linear X Axis** | *Panel Properties > Physics > Rigid Body Constraint > Limits* | Advanced | Piston combina giro y desplazamiento en el eje X (como un amortiguador de coche): tiene tanto Angular X Angle como Linear X Axis, cada uno con su propio rango mín/máx desactivado por defecto. |
| - | **Rigid Body Constraint > Type Generic: Limits > Angular X/Y/Z + Linear X/Y/Z** | *Panel Properties > Physics > Rigid Body Constraint > Limits* | Advanced | Generic expone los 6 límites a la vez (Angular y Linear en X, Y y Z), todos desactivados por defecto con rangos tipo -45°/45° o -1m/1m: el tipo más flexible, permite crear casi cualquier articulación combinando qué ejes se limitan. |
| - | **Rigid Body Constraint > Type Generic Spring: Limits** | *Panel Properties > Physics > Rigid Body Constraint > Limits* | Advanced | Generic Spring parte de los mismos 6 límites que Generic (Angular X/Y/Z Angle y Linear X/Y/Z Axis, todos desactivados por defecto con rango -45°/45° o -1m/1m), pero además añade una sección Springs propia para que esos ejes se comporten como un muelle en vez de un tope rígido. |
| - | **Rigid Body Constraint > Type Generic Spring: Springs > Type** | *Panel Properties > Physics > Rigid Body Constraint > Springs* | Advanced | Type elige el modelo de cálculo del muelle: Blender 2.8 (el actual, más estable) o la versión heredada de Blender 2.7, mantenida por compatibilidad con archivos antiguos. |
| - | **Rigid Body Constraint > Type Generic Spring: Springs > Angular X/Y/Z Angle (Stiffness / Damping)** | *Panel Properties > Physics > Rigid Body Constraint > Springs > Angular* | Advanced | Activa un muelle de giro independiente por eje (X, Y, Z), cada uno desactivado por defecto: Stiffness es la rigidez del muelle (más alto = vuelve más rápido a su posición) y Damping la amortiguación de ese rebote (por defecto Stiffness 10.000, Damping 0.500 en los tres ejes). |
| - | **Rigid Body Constraint > Type Generic Spring: Springs > Linear X/Y/Z Axis (Stiffness / Damping)** | *Panel Properties > Physics > Rigid Body Constraint > Springs > Linear* | Advanced | Igual que el Angular pero para el desplazamiento en cada eje (X, Y, Z): permite que el objeto 'rebote' elásticamente en esa dirección en vez de quedar fijo o deslizar libre, con su propio Stiffness/Damping por eje (mismos valores por defecto: 10.000 / 0.500). |
| - | **Rigid Body Constraint > Type Motor: Angular / Linear** | *Panel Properties > Physics > Rigid Body Constraint > Motor* | Advanced | Motor no tiene Limits, sino una sección Motor propia: Angular (Target Velocity y Max Impulse para girar la unión con fuerza propia) y Linear (Target Velocity y Max Impulse para desplazarla), cada uno activable por separado — útil para ruedas, hélices o pistones motorizados. |
