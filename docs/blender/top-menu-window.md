# Top Menu > Window


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🪟 | **New Window** | *Window > New Window* | Intermediate | Abre una ventana de sistema extra que sigue perteneciendo a la misma sesión de Blender (comparte escena y datos); útil para tener, por ejemplo, un Viewport en un segundo monitor. |
| 🪟 | **New Main Window** | *Window > New Main Window* | Advanced | Abre una ventana totalmente independiente, con su propia interfaz configurable por separado, a diferencia de New Window; también pensada para trabajar con varios monitores. |
| 🪟 | **Toggle Window Fullscreen** | *Window > Toggle Window Fullscreen* | Basic | Pone Blender en pantalla completa, ocultando la barra de título y bordes del sistema operativo, para aprovechar todo el espacio de la pantalla. |
| 🗂️ | **Next/Previous Workspace** | *Window > Next Workspace (Ctrl+Av Pág) / Previous Workspace (Ctrl+Re Pág)* | Basic | Cambia a la pestaña de Workspace siguiente o anterior (Layout, Modeling, Sculpting...) sin tener que hacer clic arriba del todo; útil para moverte rápido entre espacios de trabajo con las manos en el teclado. |
| - | **Show Status Bar** | *Window > Show Status Bar* | Basic | Casilla activable (activada por defecto): muestra u oculta la barra de estado inferior con las estadísticas de la escena y otra info rápida. |
| 📸 | **Save Screenshot...** | *Window > Save Screenshot...* | Basic | Guarda una captura de toda la ventana de Blender (con interfaz incluida) como imagen. |
| 📸 | **Save Screenshot (Editor)...** | *Window > Save Screenshot (Editor)...* | Intermediate | Igual que Save Screenshot pero captura solo el editor que tiene el cursor encima en ese momento, sin el resto de la interfaz. |
| 🖥️ | **Toggle System Console** | *Window > Toggle System Console* | Advanced | Muestra u oculta la ventana de consola del sistema (símbolo del sistema en Windows) donde Blender escribe sus mensajes internos, errores de Python y avisos; muy útil para depurar addons o scripts propios. |
