# T Panel: Common to all modes


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔀 | **Cambiar de Modo: desplegable de Modo / Ctrl+Tab** | *Header del Viewport 3D (arriba a la izquierda) / Ctrl+Tab* | Basic | Antes de usar las secciones de Barra T por modo: el Modo activo (Object Mode, Edit Mode, Sculpt Mode, Pose Mode...) se cambia desde el desplegable de arriba a la izquierda del Viewport 3D, con el objeto que quieras editar ya seleccionado. Ctrl+Tab (con el ratón sobre el Viewport) abre un menú circular (pie menu) para elegir el modo más rápido sin abrir el desplegable. IMPORTANTE: la lista de modos disponibles cambia según el TIPO de objeto activo — por ejemplo Pose Mode solo aparece si el objeto seleccionado es un Armature; con una malla seleccionada no lo verás en la lista. |
| 🔀 | **Alternar Object Mode ↔ Edit Mode** | *Tab (con el ratón sobre el Viewport)* | Basic | Atajo directo (sin pasar por el desplegable ni por Ctrl+Tab) para saltar entre Object Mode y el último modo de edición usado en el objeto activo — normalmente Edit Mode, pero en un objeto de tipo Grease Pencil, por ejemplo, puede volver a Draw Mode si fue el último usado. Solo alterna entre esos dos, no abre el menú de todos los modos. |
| 🖱️ | **Select Box (Tweak): qué es y cómo cambiar de variante** | *Barra T > primer icono (W cicla entre variantes)* | Basic | Primera herramienta de la Barra T, activa por defecto en cualquier modo. Tiene un pequeño desplegable (clic mantenido sobre el icono, o pulsar W repetidamente) con 4 variantes de selección: Tweak, Select Box, Select Circle y Select Lasso, cada una con una forma distinta de seleccionar (detalladas en las filas siguientes) — IMPORTANTE: la variante activa por defecto puede cambiar de una versión de Blender a otra o según el archivo/plantilla de inicio, así que conviene fijarse en el icono antes de dar por hecho cuál está activa. Estas 9 primeras herramientas son idénticas en todos los modos (Object, Edit, Sculpt, Paint, Pose...), así que se documentan aquí una sola vez en vez de repetirlas en cada categoría de modo. |
| 🖱️ | **Select Box (Tweak) > Tweak** | *Barra T > desplegable del primer icono > Tweak* | Basic | Clicar sobre un elemento lo selecciona Y permite moverlo directamente arrastrando en el mismo gesto, sin tener que soltar y pulsar G aparte. Clicar en un área vacía y arrastrar hace una selección por caja, igual que Select Box. Es la variante pensada para trabajar rápido combinando seleccionar y mover en un solo clic. |
| 🖱️ | **Select Box (Tweak) > Select Box** | *Barra T > desplegable del primer icono > Select Box* | Basic | Clicar y arrastrar dibuja un rectángulo; al soltar, todo lo que quede dentro (o que toque el rectángulo, según Properties > Tool) se selecciona de golpe. Clicar sin arrastrar sobre un elemento lo selecciona sin moverlo. Es la variante 'clásica' de selección por caja, la más predecible para seleccionar grupos de elementos alineados. |
| 🖱️ | **Select Box (Tweak) > Select Circle** | *Barra T > desplegable del primer icono > Select Circle* | Basic | El cursor se convierte en un círculo (su radio se ajusta con la rueda del ratón o las teclas [ y ]): mientras se mantiene pulsado el botón izquierdo y se arrastra, se van seleccionando como con un pincel todos los elementos que toca ese círculo, en vez de encerrarlos de una vez en un rectángulo. Botón derecho (o Ctrl+arrastrar) deselecciona en lugar de seleccionar. Por eso 'selecciona diferente' a Select Box: hay que pasar el círculo por encima de lo que se quiere seleccionar, y la herramienta se queda activa seleccionando hasta pulsar Intro, Esc o cambiar de herramienta, en vez de terminar con un solo arrastre. |
| 🖱️ | **Select Box (Tweak) > Select Lasso** | *Barra T > desplegable del primer icono > Select Lasso* | Basic | Clicar y arrastrar dibuja una forma libre a mano alzada; al soltar, se selecciona todo lo que quede dentro de esa forma. Útil para siluetas irregulares que no encajan bien en un rectángulo (Select Box) ni en un círculo (Select Circle). |
| - | **Tool Settings > Mode: Set / Extend / Subtract / Difference / Intersect** | *Fila de Tool Settings, justo bajo la barra superior (visible con Select Box/Circle/Lasso/Tweak activa)* | Intermediate | Fila de 5 iconos que decide cómo se combina cada nuevo gesto de selección con la selección que ya tenías, para Select Box/Select Circle/Select Lasso/Tweak. Set (por defecto): sustituye la selección anterior por la nueva. Extend (también con Mayús+arrastrar sin cambiar el icono): añade lo nuevo a lo ya seleccionado. Subtract (también con Ctrl+arrastrar): quita de la selección actual lo que toque el nuevo gesto. Difference: invierte el estado de cada elemento tocado por el gesto (lo seleccionado pasa a no estarlo y viceversa), en vez de solo deseleccionar. Intersect: deja seleccionado únicamente lo que ya estuviera seleccionado Y además quede dentro del nuevo gesto, quitando todo lo demás. |
| - | **Barra T: iconos con flyout (triángulo en la esquina)** | *Barra T > cualquier icono con triángulo inferior derecho* | Basic | Muchas herramientas de la Barra T esconden variantes alternativas además de su acción de un solo clic: se reconocen por un pequeño triángulo en la esquina inferior derecha del icono, y se despliegan manteniendo pulsado el clic izquierdo sobre el icono (no hace falta clic derecho). Ejemplos confirmados por captura: Select Box despliega Tweak/Select Box/Select Circle/Select Lasso, Scale despliega también Scale Cage, Annotate despliega Annotate Line/Annotate Polygon/Annotate Eraser, y Add Cube despliega también Add Cone/Add Cylinder/Add UV Sphere/Add Ico Sphere. Merece la pena mantener pulsado cada icono con triángulo para descubrir qué otras variantes tiene. |
| 📍 | **Cursor** | *Barra T > Cursor (Mayús+Clic Derecho)* | Basic | Coloca el 3D Cursor donde hagas clic. El 3D Cursor es el punto de referencia donde aparecen los objetos nuevos (Add > ...) y sirve como pivote alternativo para transformaciones. |
| ✛ | **Move** | *Barra T > Move (G)* | Basic | Mueve la selección arrastrando los ejes de colores del gizmo; equivale a pulsar G. |
| 🔄 | **Rotate** | *Barra T > Rotate (R)* | Basic | Gira la selección arrastrando los anillos del gizmo; equivale a pulsar R. |
| 📐 | **Scale** | *Barra T > Scale (S)* | Basic | Escala la selección arrastrando los ejes del gizmo; equivale a pulsar S. |
| 📐 | **Scale > Scale Cage** | *Barra T > desplegable de Scale > Scale Cage* | Intermediate | Variante de Scale con un gizmo de caja envolvente (cage) con tiradores en cada esquina/arista/cara: permite escalar solo desde un lado concreto de la selección (como estirar de una esquina) en vez de siempre desde el centro hacia fuera en las 3 direcciones a la vez. |
| 🎛️ | **Transform** | *Barra T > Transform* | Intermediate | Combina Move, Rotate y Scale en un único gizmo, para no tener que cambiar de herramienta constantemente entre las tres transformaciones básicas. |
| 🖊️ | **Annotate** | *Barra T > Annotate (D)* | Intermediate | Dibuja anotaciones a mano alzada directamente sobre el Viewport; son solo una referencia visual (no forman parte de la geometría ni se renderizan), útiles para dejarte notas o explicar algo en una presentación. |
| 🖊️ | **Annotate > Annotate Line / Annotate Polygon / Annotate Eraser** | *Barra T > desplegable de Annotate* | Intermediate | Annotate Line dibuja una única línea recta entre el punto donde clicas y donde sueltas, en vez de un trazo libre. Annotate Polygon dibuja un polígono clicando vértice a vértice (doble clic o Intro para cerrarlo). Annotate Eraser borra, arrastrando sobre ellos, los trazos ya dibujados con cualquiera de las otras variantes. |
| 📏 | **Measure** | *Barra T > Measure* | Intermediate | Mide distancias y ángulos arrastrando sobre la escena, mostrando el resultado en tiempo real superpuesto en el Viewport; el valor numérico se puede editar a mano. |
| 🧱 | **Add Cube** | *Barra T > Add Cube* | Intermediate | Al hacer clic y arrastrar sobre el Viewport, coloca y dimensiona un cubo nuevo de forma interactiva (con snap automático a superficies si el snapping está activado), sin tener que pasar por el menú Add > Mesh > Cube. En Edit Mode, el cubo se añade como parte de la misma malla (mesh data) del objeto activo en vez de como objeto independiente. |
| 🧱 | **Add Cube > Add Cone / Add Cylinder / Add UV Sphere / Add Ico Sphere** | *Barra T > desplegable de Add Cube* | Intermediate | Mismo comportamiento interactivo de clicar y arrastrar que Add Cube (con snap incluido), pero colocando un Cone, Cylinder, UV Sphere o Ico Sphere en vez de un Cube; mismas primitivas que Add > Mesh, solo que dimensionadas a mano en el Viewport en vez de con el tamaño por defecto. |
