# Preferences > Interface: Display


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Resolution Scale** | *Edit > Preferences > Interface > Display* | Advanced | Escala el tamaño de todo el interfaz (texto, iconos, paneles) independientemente de la resolución del monitor; útil en pantallas 4K si todo se ve diminuto. |
| - | **Line Width** | *Edit > Preferences > Interface > Display* | Advanced | Grosor de las líneas del interfaz (Default/Thin/Thick); ayuda en monitores de alta resolución donde las líneas finas cuestan de ver. |
| - | **Splash Screen** | *Edit > Preferences > Interface > Display* | Basic | Muestra u oculta la pantalla de bienvenida al abrir Blender. |
| - | **Developer Extras** | *Edit > Preferences > Interface > Display* | Advanced | Añade opciones pensadas para desarrolladores de Blender (como copiar el nombre de un dato-bloque o ver más info de depuración); no hace falta para uso normal. |
| - | **User Tooltips** | *Edit > Preferences > Interface > Display* | Basic | Activa o desactiva los tooltips (textos de ayuda) al pasar el ratón sobre los botones. |
| - | **Python Tooltips** | *Edit > Preferences > Interface > Display* | Advanced | Añade a los tooltips el nombre técnico en Python del botón; útil solo si vas a hacer scripting. |
| - | **Sort by Most Recent** | *Edit > Preferences > Interface > Display* | Basic | En los buscadores del interfaz (como Menu Search), prioriza mostrar primero lo usado más recientemente. |
| - | **Show Hidden** | *Edit > Preferences > Interface > Display* | Advanced | Incluye en las búsquedas del interfaz elementos normalmente ocultos. |
