# Viewport 3D > Add


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ➕ | **Add: menú general (Mayús+A)** | *Barra superior del Viewport 3D > Add* | Basic | Añade objetos nuevos a la escena, apareciendo en la posición del 3D Cursor. Organizado por TIPO de objeto, cada uno con su propio icono de datos y comportamiento en Properties: Mesh, Curve, Surface, Metaball, Text, Point Cloud, Volume, Grease Pencil, Armature, Lattice, Empty, Image, Light, Light Probe, Camera, Speaker, Force Field y Collection Instance. Los que tienen flecha ▶ despliegan un submenú con variantes (detalladas en las filas siguientes); Text, Point Cloud, Armature, Camera y Speaker se añaden directamente con un clic, sin submenú. |
| 🧱 | **Add > Mesh: Plane / Cube / Circle / UV Sphere / Ico Sphere / Cylinder / Cone / Torus / Grid / Monkey** | *Barra superior > Add > Mesh* | Basic | Las 10 primitivas de malla clásicas, el punto de partida de casi cualquier modelado: Plane (plano cuadrado sin grosor), Cube, Circle (solo el contorno, sin caras; útil como base para extruir o como curva de referencia), UV Sphere (esfera con topología por gajos, tipo globo terráqueo), Ico Sphere (esfera con topología triangular uniforme, mejor para Sculpt/Subdivision), Cylinder, Cone, Torus (donut), Grid (plano ya subdividido en rejilla, útil para terrenos o paños de tela) y Monkey (Suzanne, la mascota de Blender, un modelo de prueba con más detalle para probar materiales/modificadores). |
| ➰ | **Add > Curve: Bézier / Circle / Nurbs Curve / Nurbs Circle / Path** | *Barra superior > Add > Curve* | Basic | Bézier: curva con tiradores editables, la más usada para trazar formas orgánicas o caminos de cámara/animación. Circle: círculo cerrado tipo Bézier. Nurbs Curve/Nurbs Circle: misma idea pero con matemática NURBS (cada punto de control atrae la curva sin que esta pase exactamente por él). Path: curva NURBS pensada específicamente para el constraint/animación Follow Path, con la sección Path Animation ya activada por defecto. |
| 🪮 | **Add > Curve: Empty Hair / Fur (bloqueados sin malla activa)** | *Barra superior > Add > Curve* | Advanced | Aparecen en gris/no seleccionables salvo que haya un objeto de tipo malla activo (confirmado en captura real). Generan curvas del sistema Hair Curves ancladas a la superficie de esa malla: Empty Hair las crea vacías para peinarlas a mano; Fur las genera ya repartidas automáticamente por toda la superficie a modo de pelaje base. |
| 🌐 | **Add > Surface: Nurbs Curve / Nurbs Circle / Nurbs Surface / Nurbs Cylinder / Nurbs Sphere / Nurbs Torus** | *Barra superior > Add > Surface* | Advanced | Mismas formas base que en Mesh/Curve pero construidas con superficies NURBS (matemáticamente curvas, sin facetas visibles), pensadas para diseño de producto/automoción donde se necesita continuidad de curvatura perfecta. Nurbs Curve/Circle aquí son 2D igual que en el menú Curve, pero pertenecen al tipo de objeto Surface, no Curve. |
| 🫧 | **Add > Metaball: Ball / Capsule / Plane / Ellipsoid / Cube** | *Barra superior > Add > Metaball* | Intermediate | Objetos que se fusionan orgánicamente entre sí cuando están cerca (como gotas de metal líquido, de ahí el nombre), muy usados para bocetar formas orgánicas rápidas ('blobs') antes de convertirlas en malla real con Object > Convert To. |
| 🔤 | **Add: Text / Point Cloud** | *Barra superior del Viewport 3D > Add* | Intermediate | Text: añade un objeto de texto 3D editable (Edit Mode para escribir), con su propia tipografía, extrusión y biselado en Object Data. Point Cloud: añade una nube de puntos vacía, tipo de dato usado sobre todo para importar simulaciones o escaneos, editable con Geometry Nodes. |
| ☁️ | **Add > Volume: Import OpenVDB... / Empty** | *Barra superior > Add > Volume* | Advanced | Import OpenVDB... carga un archivo .vdb externo (el formato estándar de volúmenes, usado por ejemplo para humo/fuego cacheados desde Blender u otros programas). Empty crea un objeto Volume vacío, pensado para rellenarlo después con Geometry Nodes u otras herramientas. |
| ✏️ | **Add > Grease Pencil: Blank / Stroke / Monkey** | *Barra superior > Add > Grease Pencil* | Intermediate | Grease Pencil es el sistema de dibujo 2D/2.5D de Blender (storyboards, animación 2D, trazos tipo VFX dentro de una escena 3D). Blank crea un objeto vacío listo para dibujar. Stroke añade ya un trazo de ejemplo. Monkey añade el contorno de Suzanne ya dibujado, como referencia rápida. |
| ✏️ | **Add > Grease Pencil: Scene Line Art / Collection Line Art / Object Line Art** | *Barra superior > Add > Grease Pencil* | Advanced | Generan automáticamente, como trazos de Grease Pencil, el contorno tipo cómic/técnico (line art) de toda la escena, de una Collection concreta o de un único Object respectivamente; se actualizan solos si la geometría de origen cambia, a diferencia de dibujarlo a mano. |
| 🦴 | **Add: Armature** | *Barra superior del Viewport 3D > Add* | Basic | Añade el hueso raíz de un Armature nuevo, el punto de partida para riggear un personaje u objeto animable. |
| 🕸️ | **Add > Lattice: Lattice / Lattice Deform Selected** | *Barra superior > Add > Lattice* | Advanced | Lattice añade una caja de rejilla vacía, usada junto a un modifier Lattice para deformar de forma suave todo lo que quede dentro de su volumen sin tocar directamente los vértices del objeto. Lattice Deform Selected hace lo mismo pero ajusta automáticamente el tamaño de la caja al bounding box de los objetos ya seleccionados y les añade el modifier Lattice de forma automática, ahorrando varios pasos manuales. |
| ⭕ | **Add > Empty: Plain Axes / Arrows / Single Arrow / Circle / Cube / Sphere / Cone** | *Barra superior > Add > Empty* | Intermediate | Formas de dibujo (solo visuales, sin geometría real) para un Empty: un objeto sin malla que sirve como punto de referencia, pivote, target de constraints o controlador. Cada forma es puramente estética (Plain Axes: ejes simples; Arrows: 3 flechas de eje; Single Arrow: una sola flecha; Circle/Cube/Sphere/Cone: esas siluetas); se elige la que resulte más clara visualmente para su función en la escena. |
| 🖼️ | **Add > Image: Reference... / Background... / Mesh Plane... / Empty Image** | *Barra superior > Add > Image* | Intermediate | Reference: añade una imagen de referencia flotando en el espacio 3D, visible desde cualquier ángulo (ideal para modelar con vistas de referencia tipo planos/turnaround). Background: similar pero solo visible desde el ángulo original en el que se colocó, como un fondo plano. Mesh Plane: crea directamente un plano de malla con la imagen ya aplicada como textura. Empty Image es el tipo de dato genérico (equivale a Reference con las opciones por defecto). |
| 💡 | **Add > Light: Point / Sun / Spot / Area** | *Barra superior > Add > Light* | Basic | Los 4 tipos de luz, ya documentados a fondo en Properties > Object Data > Light (Temperature/Color/Power-Strength/Exposure/Normalize, Shadow, Influence, Custom Distance...); aquí es donde se elige qué tipo crear en la escena. |
| 🔮 | **Add > Light Probe: Sphere / Plane / Volume** | *Barra superior > Add > Light Probe* | Advanced | Objetos invisibles en el render que capturan información de iluminación/reflejos del entorno para acelerar EEVEE. Sphere (Reflection Cubemap): captura reflejos desde un punto, ideal para objetos brillantes/metálicos aislados. Plane (Reflection Plane): captura reflejos planos muy nítidos, ideal para suelos o espejos. Volume (Irradiance Volume): captura solo iluminación indirecta suave repartida por un volumen del espacio, para que objetos mate se iluminen de forma realista sin recalcular todo el rebote de luz en tiempo real. |
| 🎥 | **Add: Camera / Speaker** | *Barra superior del Viewport 3D > Add* | Basic | Camera añade una cámara nueva en la posición del 3D Cursor (ya documentada a fondo en Properties > Object Data > Cámara). Speaker añade un emisor de sonido posicional (ya documentado a fondo en Properties > Object Data > Speaker). |
| 🌪️ | **Add > Force Field: Force / Wind / Vortex / Magnetic / Harmonic / Charge / Lennard-Jones / Texture / Curve Guide / Boid / Turbulence / Drag / Fluid Flow** | *Barra superior > Add > Force Field* | Advanced | Añade un Empty ya configurado como campo de fuerza de ese tipo, listo para afectar a partículas, Cloth, Soft Body, etc. Son los mismos tipos ya documentados en Properties > Physics > Force Field: Type; aquí es la forma rápida de crear uno como objeto independiente, en vez de convertir un objeto ya existente en campo de fuerza. |
| 📦 | **Add > Collection Instance: Collection** | *Barra superior > Add > Collection Instance* | Intermediate | Añade una instancia (copia enlazada y ligera, sin duplicar los datos reales) de una Collection completa ya existente en el archivo; el submenú lista las Collections disponibles para elegir (en la captura solo aparece 'Collection', al ser la única del archivo de prueba). Muy usado para repetir un mismo conjunto de objetos —por ejemplo, un árbol con todas sus piezas— muchas veces sin multiplicar el peso del archivo. |
