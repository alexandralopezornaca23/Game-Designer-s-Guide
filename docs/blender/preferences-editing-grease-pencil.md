# Preferences > Editing: Grease Pencil


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Manhattan** | *Edit > Preferences > Editing > Grease Pencil* | Advanced | Distancia mínima en píxeles (medida en horizontal/vertical) que debe moverse el ratón para registrar un nuevo punto al dibujar con Grease Pencil. |
| - | **Euclidean** | *Edit > Preferences > Editing > Grease Pencil* | Advanced | Distancia mínima real (línea recta, cualquier dirección) entre dos puntos consecutivos al dibujar con Grease Pencil. |
