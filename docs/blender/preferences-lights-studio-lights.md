# Preferences > Lights: Studio Lights


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💡 | **Studio Lights (panel)** | *Edit > Preferences > Lights* | Advanced | Set-ups de iluminación fija para el modo de sombreado Solid del viewport; no son luces de la escena (esas están en Properties > Object Data > Luz), sino una iluminación que se ve siempre igual, pensada para modelar cómodamente. |
| 💡 | **Edit Studio Light** | *Edit > Preferences > Lights* | Advanced | Activa el modo de edición de las 4 luces de estudio para ajustarlas en directo mientras ves el resultado en el viewport. |
| 💡 | **Save as Studio light** | *Edit > Preferences > Lights* | Advanced | Guarda la configuración actual de las 4 luces como un preset propio, seleccionable junto con los que trae Blender por defecto. |
| 💡 | **Use Light (por cada una de las 4 luces)** | *Edit > Preferences > Lights* | Advanced | Activa o desactiva esa luz concreta del set de iluminación de estudio; las 4 se combinan simulando un estudio fotográfico con luz principal, de relleno y contraluces. |
| - | **Diffuse / Specular / Smooth / Direction** | *Edit > Preferences > Lights* | Advanced | Por cada luz de estudio: color difuso, color/intensidad del brillo especular, qué tan suave o concentrado es ese brillo, y su dirección respecto al objeto (arrastrando sobre la esfera de previsualización). |
| - | **Ambient Color** | *Edit > Preferences > Lights* | Advanced | Color de luz ambiental de fondo que se suma a las 4 luces de estudio, para que las sombras nunca sean 100% negras. |
