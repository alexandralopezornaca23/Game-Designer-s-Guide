# T Panel: Object Mode


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔑 | **Breakdowner** | *Barra T (Object Mode) > Breakdowner (Mayús+Barra espaciadora → Mayús+4)* | Advanced | Además de las 9 herramientas comunes (ver 'Barra T: Comunes a todos los modos'), Object Mode añade esta: crea una pose de 'breakdown' (una pose intermedia) en el frame actual, pensada para animar huesos u objetos con Rig; al arrastrar el ratón ajusta cuánto se acerca esa pose intermedia a la pose anterior o a la siguiente. |
| 🔑 | **Breakdowner > Push / Relax** | *Barra T (Object Mode) > desplegable de Breakdowner* | Advanced | Push aleja la pose actual de la pose de referencia (la exagera un poco más en la misma dirección). Relax la acerca, suavizándola hacia la pose de referencia; ambas se usan igual que Breakdowner, arrastrando el ratón para ajustar la cantidad, muy usadas en animación de personajes para pulir el 'follow through' entre poses clave. |
