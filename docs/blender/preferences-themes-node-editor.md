# Preferences > Themes: Node Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💠 | **Nodos, wires y aspecto general** | *Edit > Preferences > Themes > Node Editor* | Intermediate | Grid, Node Outline, Node Selected y Active Node colorean la selección de nodos; Wires/Wire Color/Wire Select son los cables que conectan nodos; Node Backdrop es el fondo de la imagen de referencia en el Compositor; Dashed Lines Opacity controla la transparencia de las líneas discontinuas (reroute); Noodle Curving ajusta cuánto se curvan visualmente los cables (0 = rectos); Grid Levels controla cuántos niveles de rejilla se ven al hacer zoom. |
| 💠 | **Colores por tipo/categoría de nodo** | *Edit > Preferences > Themes > Node Editor* | Advanced | Cada categoría funcional de nodo tiene su propio color de cabecera para identificarla de un vistazo en gráficos de shaders o Geometry Nodes complejos: Converter, Color, Group, Group Socket, Frame, Matte, Distort, Input, Output, Filter, Vector, Texture, Shader, Script, Geometry, Attribute Node, y en Geometry Nodes además Simulation Zone, Repeat Zone, For Each Geometry Element Zone y Closure Zone (los recuadros que agrupan nodos de bucles/simulación). |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Node Editor > Theme Space* | Basic | Mismo patrón repetido en todos los editores (colapsado en la captura). |
