# T Panel: UV Editing


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💔 | **Rip Region** | *Barra T (UV Editing) > Rip Region (Mayús+Barra espaciadora → V)* | Advanced | Misma herramienta ya documentada en 'Barra T: Edit Mode (malla)': separa (rasga) la selección de UVs del resto, duplicando los vértices del corte, lista para moverla; aquí se aplica sobre el mapa UV en vez de sobre la malla 3D. |
| ✛ | **Grab** | *Barra T (UV Editing) > Grab (Mayús+Barra espaciadora → 7)* | Basic | Grab UVs: mueve (arrastra) los UVs seleccionados libremente por el editor UV; equivalente a Move pero pensado específicamente para el espacio 2D del mapa UV. |
| 〰️ | **Relax** | *Barra T (UV Editing) > Relax (Mayús+Barra espaciadora → 8)* | Intermediate | Relax UVs: suaviza/relaja la posición de los UVs seleccionados repartiéndolos de forma más uniforme según la tensión de la malla, reduciendo distorsión sin necesidad de volver a desenvolver (unwrap) desde cero. |
| 🤏 | **Pinch** | *Barra T (UV Editing) > Pinch (Mayús+Barra espaciadora → 9)* | Intermediate | Pinch UVs: junta (pellizca) los UVs seleccionados hacia el centro de la selección arrastrando el ratón; útil para cerrar huecos o concentrar UVs en una zona concreta del mapa. |
| 📏 | **Tool Settings > Size / Strength** | *Fila de Tool Settings, justo bajo la barra superior View/Select/Image/UV (visible con Grab/Relax/Pinch activos)* | Basic | Size (100 px): radio del pincel en la vista UV. Strength (1.000): intensidad del efecto por pincelada. Ambos se pueden editar arrastrando el campo o haciendo clic para escribir un valor. |
| 📉 | **Tool Settings > Falloff** | *Fila de Tool Settings, justo bajo la barra superior View/Select/Image/UV (visible con Grab/Relax/Pinch activos)* | Intermediate | Curva que define cómo decae la fuerza del pincel desde el centro hacia el borde: Custom (curva editable a mano), Smooth (por defecto), Smoother, Sphere, Root, Sharp, Linear, Sharper, Inverse Square y Constant (mismo efecto en toda el área, sin caída hacia el borde). |
| ⚙️ | **Tool Settings > Options: Lock Borders / Sculpt All Islands** | *Fila de Tool Settings, justo bajo la barra superior View/Select/Image/UV (visible con Grab/Relax/Pinch activos)* | Intermediate | Lock Borders (desactivado): impide que el pincel mueva los UVs que están en el borde exterior de una isla, para no deshacer sin querer un borde ya ajustado a mano. Sculpt All Islands (desactivado): aplica el efecto a todas las islas UV visibles a la vez, no solo a la isla que tiene el cursor encima. |
| 🧮 | **Tool Settings > Method: Laplacian / HC / Geometry** | *Fila de Tool Settings (solo visible con Relax activo)* | Advanced | Solo aparece con la herramienta Relax activa: elige el algoritmo usado para relajar los UVs. Laplacian (por defecto): suaviza según la posición de los vecinos. HC: variante que conserva mejor la forma/volumen general, evitando que la malla UV se encoja. Geometry: relaja teniendo en cuenta la forma real de la malla 3D en vez de solo la disposición 2D de los UVs. |
| 🖱️ | **Tool Settings > Drag: Active Tool / Tweak / Select Box / Select Circle / Select Lasso** | *Fila de Tool Settings, justo bajo la barra superior View/Select/Image/UV (visible con Grab/Relax/Pinch activos)* | Intermediate | Elige qué variante de selección se usa al hacer clic y arrastrar SIN mantener pulsado Mayús+Barra espaciadora (que es lo que activa el pincel Grab/Relax/Pinch): mismas 4 variantes ya documentadas en 'Barra T: Comunes a todos los modos' (ver 'Select Box (Tweak)'), aquí aplicadas al mapa UV. |
