# Preferences > Interface: Editors


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Region Overlap** | *Edit > Preferences > Interface > Editors* | Intermediate | Los paneles laterales (como el panel N) se superponen semitransparentes sobre el viewport en vez de ocupar espacio fijo; gana área de trabajo visible. |
| - | **Corner Handles** | *Edit > Preferences > Interface > Editors* | Advanced | Muestra unas esquinas arrastrables en cada editor para redimensionarlo o dividirlo, además del método normal de arrastrar el borde. |
| - | **Numeric Input Arrows** | *Edit > Preferences > Interface > Editors* | Basic | Añade flechitas ◄► a los campos numéricos para subir/bajar el valor con clic, además de poder escribirlo. |
| - | **Navigation Controls** | *Edit > Preferences > Interface > Editors* | Basic | Muestra en el viewport los controles de navegación en pantalla (gizmo de ejes y accesos de vista); pensado también para tablet/pantalla táctil. |
| - | **Border Width** | *Edit > Preferences > Interface > Editors* | Advanced | Grosor del borde que separa los distintos editores/paneles entre sí. |
| - | **Color Picker Type** | *Edit > Preferences > Interface > Editors* | Intermediate | Forma del selector de color (círculo HSV, cuadrado, etc.) que aparece al hacer clic en cualquier color del programa. |
| - | **Header Position** | *Edit > Preferences > Interface > Editors* | Advanced | Dónde aparece por defecto la barra de cabecera (arriba/abajo) al crear un editor nuevo. |
| - | **Factor Display Type** | *Edit > Preferences > Interface > Editors* | Advanced | Cómo se muestran los valores 'factor' (de 0 a 1) en los sliders: como número decimal o como porcentaje. |
