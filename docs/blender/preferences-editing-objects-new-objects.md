# Preferences > Editing: Objects (New Objects)


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Link Materials To** | *Edit > Preferences > Editing > Objects* | Advanced | Decide si un material nuevo se vincula al Object Data (la malla; se comparte entre todos los objetos que usen esos mismos datos) o al Object (solo a ese objeto); afecta a cómo se comportan los materiales al hacer Link/instancias. |
| - | **Align To** | *Edit > Preferences > Editing > Objects* | Basic | Con qué se alinea un objeto recién creado: World (ejes globales), View (orientado a la vista actual) o 3D Cursor. |
| - | **Enter Edit Mode** | *Edit > Preferences > Editing > Objects* | Basic | Si está activo, al crear un objeto nuevo (Add > Mesh...) entras directamente en modo Edición en vez de quedarte en modo Objeto. |
| ⭕ | **Instance Empty Size** | *Edit > Preferences > Editing > Objects* | Advanced | Tamaño por defecto del icono/gizmo de los objetos Empty al crearlos. |
