# Preferences > Get Extensions


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔍 | **Search Extensions** | *Edit > Preferences > Get Extensions* | Basic | Busca en el catálogo online de extensiones de Blender (antes 'Add-ons Community') por nombre. |
| 🔽 | **Filtro de tipo (Add-ons)** | *Edit > Preferences > Get Extensions* | Basic | Filtra el catálogo por tipo de extensión (Add-ons, Temas...) y por etiquetas, con el icono de filtro. |
| 📚 | **Repositories** | *Edit > Preferences > Get Extensions* | Advanced | Elige de qué repositorio(s) se listan las extensiones: el oficial de Blender u otros repositorios que hayas añadido tú. |
| 🌐 | **Allow Online Access / Continue Offline** | *Edit > Preferences > Get Extensions* | Basic | Blender pide permiso para conectarse a internet antes de poder instalar o actualizar extensiones online; si trabajas sin conexión, se pueden instalar igualmente con 'Install from Disk' desde la pestaña Add-ons. |
