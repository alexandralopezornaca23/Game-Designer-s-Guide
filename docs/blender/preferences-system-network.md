# Preferences > System: Network


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🌐 | **Allow Online Access** | *Edit > Preferences > System* | Basic | Interruptor general que permite a Blender conectarse a internet (extensiones online, comprobación de actualizaciones...); si está desactivado, Blender pide permiso puntual como en Get Extensions o Asset Libraries. |
| - | **Time Out** | *Edit > Preferences > System* | Advanced | Segundos que espera Blender antes de cancelar una conexión de red que no responde. |
| - | **Connection Limit** | *Edit > Preferences > System* | Advanced | Número máximo de conexiones de red simultáneas que puede abrir Blender, por ejemplo al descargar varias extensiones a la vez. |
