# Preferences > Themes: Text Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔤 | **Números de línea y selección** | *Edit > Preferences > Themes > Text Editor* | Intermediate | Line Numbers/Line Numbers Background colorean la columna de numeración a la izquierda; Selected Text y Cursor son el resaltado de texto seleccionado y el cursor de escritura dentro del Text Editor (usado para scripts Python, por ejemplo). |
| 🔤 | **Resaltado de sintaxis (Syntax Highlight)** | *Edit > Preferences > Themes > Text Editor* | Advanced | Colorea cada tipo de elemento del código según la sintaxis de Python al escribir scripts: Syntax Built-In (funciones/palabras propias del lenguaje), Syntax Symbols, Syntax Special, Syntax Preprocessor, Syntax Reserved (palabras reservadas como def, class, if), Syntax Comment, Syntax String y Syntax Numbers. |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Text Editor > Theme Space* | Basic | Mismo patrón repetido en todos los editores. |
