# UV Editor > Header


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🏝️ | **UV Island Selection** | *Cabecera del UV Editor (icono junto a Sticky Selection Mode)* | Intermediate | Alterna el modo de selección por isla UV completa: con este modo activo, un clic sobre cualquier UV selecciona toda la isla a la que pertenece, en vez de solo el vértice/arista/cara individual bajo el cursor. |
| 🧲 | **Sticky Selection Mode: Disabled / Shared Location / Shared Vertex** | *Cabecera del UV Editor (desplegable junto a UV Island Selection)* | Intermediate | Controla qué otros UVs se seleccionan a la vez que el que tocas. Disabled: solo el UV bajo el cursor. Shared Location: también los UVs de otras caras que coinciden exactamente en la misma posición 2D del mapa. Shared Vertex (opción por defecto): también los UVs de otras caras que comparten el mismo vértice 3D de origen, aunque estén separados en el mapa UV. |
| ⌨️ | **UV Island Selection** | <kbd>4</kbd> | Intermediate | UV Island Selection |
| 🔗 | **UV Sync Selection** | *Cabecera del UV Editor (icono a la izquierda de los botones de modo de selección)* | Advanced | Activa/desactiva la sincronización de la selección UV con la selección de la malla en Edit Mode. Desactivado (por defecto): la selección UV es independiente de la malla y aparecen los 4 botones UV Select Mode (Vertex/Edge/Face/Island). Activado: la selección UV queda sincronizada con la del Edit Mode del Viewport 3D y los botones cambian a los mismos Vertex/Edge/Face del modo de edición de la malla (sin el modo Island). |
| 🔘 | **UV Select Mode: Vertex / Edge / Face** | *Cabecera del UV Editor (junto a UV Island Selection, solo con UV Sync Selection desactivado)* | Intermediate | Elige si la selección en el mapa UV trabaja por vértice, arista o cara, de forma independiente a la malla 3D. Se combina con UV Island Selection (ver fila aparte) como cuarta opción para seleccionar por isla completa. |
| ⌨️ | **UV Select Mode: Vertex** | <kbd>1</kbd> | Intermediate | UV Select Mode: Vertex |
| ⌨️ | **UV Select Mode: Edge** | <kbd>2</kbd> | Intermediate | UV Select Mode: Edge |
| ⌨️ | **UV Select Mode: Face** | <kbd>3</kbd> | Intermediate | UV Select Mode: Face |
