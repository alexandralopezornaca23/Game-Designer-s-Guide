# Preferences > Save & Load: File Browser


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📁 | **Show Locations (Recent / System)** | *Edit > Preferences > Save & Load* | Basic | Qué atajos de carpeta aparecen en la barra lateral del explorador de archivos de Blender. |
| - | **Filter Files** | *Edit > Preferences > Save & Load* | Basic | Si está activo, el explorador de archivos filtra por defecto para mostrar solo los tipos de archivo relevantes (por ejemplo solo imágenes al importar una textura). |
| - | **Show Hidden Files/Data-Blocks** | *Edit > Preferences > Save & Load* | Advanced | Muestra también archivos ocultos del sistema y datos-bloque internos ocultos al explorar. |
