# Compositor > Node


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔗 | **Node: menú general (igual que en Shader Editor + Read View Layers)** | *Barra superior del Compositor > Node* | Basic | Mismo menú Node ya documentado en 'Shader Editor > Node' (Move/Rotate/Resize, Cut/Copy/Paste/Duplicate/Duplicate Linked/Delete/Delete with Reconnect, Join in New Frame/Remove from Frame/Join Group Inputs/Join in Named Frame, Rename, Make Links/Make and Replace Links, Cut Links/Detach Links/Mute Links, Make Group/Insert Into Group/Edit Group/Ungroup, Swap y Show/Hide), con un único añadido exclusivo del Compositor al final: Read View Layers (ver fila siguiente). |
| 🔗 | **Read View Layers** | *Barra superior del Compositor > Node > Read View Layers* | Intermediate | Fuerza a releer del disco/memoria los View Layers ya renderizados (por ejemplo, tras cambiar algo en la escena después de renderizar), para que los nodos Render Layers del árbol se actualicen sin tener que volver a lanzar el render completo. |
| ⌨️ | **Read View Layers** | <kbd>Ctrl</kbd> + <kbd>R</kbd> | Intermediate | Read View Layers |
