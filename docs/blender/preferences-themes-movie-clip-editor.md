# Preferences > Themes: Movie Clip Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎥 | **Marcadores de tracking** | *Edit > Preferences > Themes > Movie Clip Editor* | Intermediate | Color de la rejilla, Marker Outline (borde de un marcador de seguimiento) y el color del propio Marker según su estado: Active Marker, Selected Marker, Disabled Marker (desactivado) y Locked Marker (bloqueado). |
| 🎥 | **Paths y metadata** | *Edit > Preferences > Themes > Movie Clip Editor* | Advanced | Path Before/After colorea la trayectoria de un marcador de tracking antes y después del frame actual; Path Keyframe Before/After hace lo mismo pero solo en los frames donde ese marcador tiene un keyframe; Metadata Background/Text es la información superpuesta al clip de vídeo (datos de cámara, EXIF...). |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Movie Clip Editor > Theme Space* | Basic | Mismo patrón repetido en todos los editores (colapsado en la captura). |
