# Preferences > System: Sound


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔊 | **Audio Device** | *Edit > Preferences > System* | Advanced | Qué dispositivo de sonido del sistema usa Blender para reproducir audio (aquí WASAPI, el habitual en Windows). |
| - | **Channels** | *Edit > Preferences > System* | Advanced | Configuración de canales de audio (Stereo, Mono, 5.1...). |
| - | **Mixing Buffer** | *Edit > Preferences > System* | Advanced | Tamaño del buffer de mezcla de audio en muestras; más alto = más estable pero más latencia. |
| - | **Sample Rate** | *Edit > Preferences > System* | Advanced | Frecuencia de muestreo del audio (48 kHz es el estándar de vídeo/broadcast). |
| - | **Sample Format** | *Edit > Preferences > System* | Advanced | Precisión con la que se procesa el audio internamente (32-bit Float es la de mayor calidad). |
