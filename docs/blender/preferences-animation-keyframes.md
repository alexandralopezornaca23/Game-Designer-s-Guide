# Preferences > Animation: Keyframes


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Default Key Channels** | *Edit > Preferences > Animation > Keyframes* | Intermediate | Qué canales se insertan al usar el keyframe rápido (tecla I) sin especificar cuál; aquí Location, Rotation, Scale y Custom Properties están activados (se insertan los 4 a la vez), pero no Rotation Mode. |
| - | **Only Insert Needed (Manual/Auto)** | *Edit > Preferences > Animation > Keyframes* | Intermediate | En modo Auto, solo inserta un keyframe si el valor realmente ha cambiado respecto al keyframe anterior, evitando keys redundantes. |
| - | **Visual Keying** | *Edit > Preferences > Animation > Keyframes* | Advanced | Al insertar un keyframe sobre un hueso/objeto con constraints, guarda la posición/rotación final visible (ya con el efecto del constraint) en vez del valor 'crudo' del transform. |
| - | **Enable in New Scenes (Auto-Keyframing)** | *Edit > Preferences > Animation > Keyframes* | Intermediate | Si está activado, el grabado automático de keyframes (botón rojo de Auto-Key) viene ya encendido por defecto en cada escena nueva. |
| - | **Show Warning (Auto-Keyframing)** | *Edit > Preferences > Animation > Keyframes* | Basic | Muestra un aviso visual en pantalla cuando el Auto-Key está activado, para que no se te olvide que estás grabando cada cambio. |
| - | **Only Insert Available** | *Edit > Preferences > Animation > Keyframes* | Intermediate | Con Auto-Key activo, solo actualiza los canales que ya tenían un keyframe previo, en vez de crear canales nuevos automáticamente. |
