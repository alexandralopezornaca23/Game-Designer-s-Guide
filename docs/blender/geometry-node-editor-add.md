# Geometry Node Editor > Add


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ➕ | **Add: menú general** | *Barra superior del Geometry Node Editor > Add* | Advanced | Menú para crear nodos nuevos, y con diferencia el más grande de todos los editores de nodos de Blender. Sus 16 categorías, agrupadas por bloques: Input y Output (entradas y salidas del árbol); Attribute y Geometry (leer/escribir datos y operaciones generales de geometría); Curve, Grease Pencil, Instances, Mesh, Point y Volume (una por cada TIPO de geometría, con sus nodos específicos); Simulation (zonas de simulación entre fotogramas); Color, Texture y Utilities (color, texturas procedurales y todas las utilidades matemáticas y de control de flujo); y Group y Layout (agrupar nodos y organización visual). Casi todas siguen el mismo patrón de submenús: Read (leer datos), Sample (muestrear otra geometría), Write (escribir datos), Operations (transformar/convertir), Primitives (crear desde cero) y Topology (relaciones entre elementos). Las 16 categorías están documentadas en las filas siguientes, salvo Group (solo 'New Group') y Layout (Frame / Reroute), que se confirmaron IDÉNTICAS a las ya documentadas en 'Shader Editor > Add' y no se repiten aquí. |
| 📥 | **Add > Input: Constant / Gizmo / Group / Import / Scene** | *Barra superior > Add > Input* | Advanced | A diferencia de otros editores, aquí Input no tiene nodos sueltos: son 5 submenús (ver filas siguientes). Constant son valores fijos escritos a mano, Gizmo son controladores interactivos que aparecen en el Viewport, Group es la entrada del grupo de nodos, Import carga archivos externos como geometría, y Scene trae datos de la escena 3D. |
| 📥 | **Add > Input > Constant: Boolean / Collection / Color / Font / Image / Integer / Material / Menu / Object / Rotation / String / Value / Vector** | *Barra superior > Add > Input > Constant* | Advanced | Nodos que introducen a mano un valor fijo del tipo indicado, para alimentar otros nodos: Boolean (verdadero/falso), Color, Font (una fuente tipográfica), Image (una imagen), Integer (número entero), Menu (un desplegable de opciones propio), Rotation, String (texto), Value (número decimal) y Vector (3 números XYZ). Los tres que apuntan a datos de la escena son Collection, Material y Object, que permiten elegir una colección, un material o un objeto concretos del archivo para usarlos dentro del árbol de nodos. |
| 📥 | **Add > Input > Gizmo: Dial Gizmo / Linear Gizmo / Transform Gizmo** | *Barra superior > Add > Input > Gizmo* | Advanced | Crean CONTROLADORES visuales que aparecen en el Viewport 3D para manejar a mano un valor del árbol de nodos, sin tener que abrir el editor: Dial Gizmo es una rueda para controlar un ángulo/rotación, Linear Gizmo es una flecha para controlar un valor a lo largo de un eje (una distancia, una altura...) y Transform Gizmo es el gizmo completo de mover/rotar/escalar. Muy útiles para dejar una herramienta cómoda de usar a quien utilice el modificador después, sin que tenga que tocar los nodos. |
| 📥 | **Add > Input > Group: Group Input** | *Barra superior > Add > Input > Group* | Advanced | Único nodo del submenú. Group Input es el nodo de ENTRADA del grupo de nodos: representa la geometría y los parámetros que llegan desde fuera (desde el modificador, en el panel Properties del objeto). Cada socket nuevo que se cree aquí aparece como un campo editable en el modificador, que es la forma de dejar controles a mano sin abrir el árbol de nodos. |
| 📥 | **Add > Input > Import: CSV (.csv) / Wavefront (.obj) / Stanford PLY (.ply) / STL (.stl) / Text (.txt) / OpenVDB (.vdb)** | *Barra superior > Add > Input > Import* | Advanced | Cargan un ARCHIVO EXTERNO del disco directamente como datos dentro del árbol de nodos, sin importarlo previamente a la escena: CSV (una tabla de datos, por ejemplo para colocar objetos según una lista de coordenadas), Wavefront (.obj), Stanford PLY (.ply) y STL (.stl) son los tres formatos de malla más habituales (STL y PLY muy usados en escaneado 3D e impresión), Text (.txt) carga un texto plano y OpenVDB (.vdb) carga volúmenes (humo, nubes, fluidos) exportados desde otros programas. |
| 📥 | **Add > Input > Scene: Active Camera / Camera Info / Bone Info / Collection Children / Collection Info / Image Info / Is Viewport / Object Info / Scene Time / Self Object** | *Barra superior > Add > Input > Scene* | Advanced | Traen al árbol información de la ESCENA para que la geometría reaccione a ella: Active Camera y Camera Info dan la cámara activa y sus parámetros (posición, focal...), muy usado para efectos que dependen del punto de vista. Bone Info da los datos de un hueso de un Armature. Collection Children y Collection Info dan el contenido de una colección (para instanciar sus objetos). Image Info da resolución y datos de una imagen. Is Viewport devuelve verdadero si se está dibujando en el viewport y falso al renderizar, lo que permite bajar la densidad mientras trabajas y subirla solo al render. Object Info da la posición/rotación/escala y la geometría de un objeto concreto. Scene Time da el fotograma o segundo actual, la base de cualquier animación procedural. Self Object da el propio objeto que contiene el árbol de nodos. |
| 📤 | **Add > Output: Enable Output / Group Output / Viewer / Warning** | *Barra superior > Add > Output* | Advanced | Group Output es la SALIDA del grupo: la geometría que se conecte aquí es la que finalmente se ve y se renderiza (todo árbol necesita uno). Viewer es el nodo de depuración: conectándole cualquier punto intermedio del árbol, el Spreadsheet y el Viewport pasan a mostrar ESE resultado parcial (es la opción 'Viewer Node' del desplegable de estado de evaluación del Spreadsheet). Enable Output activa/desactiva una salida sin desconectarla. Warning hace que el modificador muestre un aviso en la interfaz cuando se cumple cierta condición, útil para avisar de que faltan datos o de un valor fuera de rango. |
| 🏷️ | **Add > Attribute: Attribute Statistic / Domain Size / Get Attribute Names / Blur Attribute / Capture Attribute / Remove Named Attribute / Rename Attribute / Store Named Attribute / Transfer Attributes** | *Barra superior > Add > Attribute* | Advanced | Los ATRIBUTOS son los datos que lleva cada elemento de la geometría (los que se ven como columnas en el Spreadsheet), y esta categoría los gestiona: Attribute Statistic calcula estadísticas de un atributo (mínimo, máximo, media...). Domain Size da cuántos elementos hay en un dominio (cuántos vértices, caras...). Get Attribute Names lista los nombres de los atributos existentes. Blur Attribute suaviza los valores de un atributo mezclándolo con el de los elementos vecinos. Capture Attribute congela el valor de un atributo en ese punto del árbol para poder usarlo más adelante sin que lo cambien los nodos intermedios (uno de los nodos clave de Geometry Nodes). Store Named Attribute guarda un valor calculado con un nombre propio, para leerlo después (incluso desde el Shader Editor). Rename Attribute y Remove Named Attribute renombran o borran uno existente. Transfer Attributes copia atributos de OTRA geometría a la actual, según proximidad o índice. |
| 🧊 | **Add > Geometry: Read / Sample / Write / Material / Operations + Geometry to Instance / Join Geometry** | *Barra superior > Add > Geometry* | Advanced | Categoría de operaciones GENERALES, que valen para cualquier tipo de geometría (no solo mallas). Contiene 5 submenús — Read (leer datos de cada elemento), Sample (leer datos de otra geometría en un punto concreto), Write (escribir/modificar datos), Material (asignar y consultar materiales) y Operations (operaciones estructurales: unir, separar, borrar, transformar...) — más 2 nodos sueltos al final: Geometry to Instance convierte una geometría en una instancia (una copia ligera y repetible, mucho más eficiente al multiplicarla) y Join Geometry fusiona en una sola salida varias geometrías distintas, uno de los nodos que más se usa. Los 5 submenús están detallados en las filas siguientes. |
| 🧊 | **Add > Geometry > Read: ID / Index / Named Attribute / Normal / Position / Radius / Get Geometry Bundle** | *Barra superior > Add > Geometry > Read* | Advanced | Nodos que LEEN un dato de cada elemento de la geometría y lo entregan como un campo, para usarlo en cálculos: Position es el más usado (la posición XYZ de cada punto). Index da el número de orden de cada elemento (el mismo que se ve en la primera columna del Spreadsheet), muy útil para hacer que cada copia se comporte distinto. ID da un identificador estable que no cambia aunque cambie el orden. Normal da la dirección hacia la que mira cada cara/punto, base para colocar objetos pegados a una superficie. Radius da el radio de cada punto o de cada punto de curva (grosor). Named Attribute lee un atributo propio guardado antes con Store Named Attribute. Get Geometry Bundle extrae geometrías de un 'bundle' (un paquete que agrupa varias geometrías, el mismo concepto del dominio Bundle que aparece en el Spreadsheet). |
| 🧊 | **Add > Geometry > Sample: Geometry Proximity / Index of Nearest / Raycast / Sample Index / Sample Nearest** | *Barra superior > Add > Geometry > Sample* | Advanced | Leen datos de OTRA geometría en un punto concreto, sin que las dos tengan que coincidir (listado confirmado desde Node > Swap, que usa exactamente el mismo árbol que Add): Geometry Proximity da la distancia y la posición del punto más cercano de otra geometría (para que algo reaccione a lo cerca que está de otra cosa: apartarse, encogerse, cambiar de color). Raycast lanza un rayo en una dirección y devuelve dónde choca con otra geometría y qué datos hay ahí — la forma habitual de 'pegar' objetos a una superficie irregular. Index of Nearest da el índice del elemento más cercano y Sample Nearest el valor que tiene ese elemento. Sample Index lee el valor de un atributo en el índice que se le indique. |
| 🧊 | **Add > Geometry > Write: Set Geometry Bundle / Set Geometry Name / Set ID / Set Position** | *Barra superior > Add > Geometry > Write* | Advanced | Escriben datos básicos de la geometría (listado confirmado desde Node > Swap, que usa exactamente el mismo árbol que Add). Set Position es EL nodo fundamental de Geometry Nodes: mueve cada punto a una posición nueva, y con él se hacen deformaciones, olas, terrenos o cualquier desplazamiento procedural (normalmente combinando Position con una textura o una operación matemática). Set ID asigna a cada elemento un identificador estable, útil para que un valor aleatorio no cambie aunque varíe el orden de los elementos. Set Geometry Name pone nombre a una geometría y Set Geometry Bundle la guarda dentro de un bundle (paquete de geometrías). |
| 🧊 | **Add > Geometry > Material: Replace Material / Material Index / Material Selection / Set Material / Set Material Index** | *Barra superior > Add > Geometry > Material* | Advanced | Gestionan los materiales de la geometría generada por nodos (listado confirmado desde Node > Swap, que usa exactamente el mismo árbol que Add): Set Material asigna un material a las caras seleccionadas (así se puede dar un material distinto a cada parte de lo que generan los nodos, por ejemplo tronco y hojas). Replace Material cambia un material por otro en toda la geometría. Set Material Index escribe el número de ranura de material de cada cara, Material Index lo lee, y Material Selection devuelve una selección con las caras que usan un material concreto (para operar solo sobre ellas). |
| 🧊 | **Add > Geometry > Operations: Bake / Bounding Box / Convex Hull / Delete Geometry / Duplicate Elements / Merge by Distance / Merge Points / Sort Elements / Transform Geometry / Get Geometry Component / Separate Components / Separate Geometry / Split to Instances** | *Barra superior > Add > Geometry > Operations* | Advanced | Operaciones estructurales que valen para cualquier tipo de geometría (listado confirmado desde Node > Swap, que usa exactamente el mismo árbol que Add). Transform Geometry mueve, rota y escala la geometría entera de golpe. Delete Geometry borra los elementos que cumplan una condición y Duplicate Elements los repite N veces (base de muchos efectos de multiplicación). Merge by Distance suelda los puntos que estén más cerca de un umbral (limpieza casi obligatoria tras generar geometría) y Merge Points hace lo propio con puntos concretos. Bounding Box da la caja que envuelve la geometría y Convex Hull la envoltura convexa (como envolverla en plástico tenso). Sort Elements reordena los elementos según un criterio. Bake congela el resultado en disco para no recalcularlo en cada fotograma, clave cuando el árbol se vuelve pesado o hay simulación. El último bloque separa: Separate Geometry parte la geometría en dos según una selección, Split to Instances la trocea en instancias, Separate Components la divide por tipo (malla, curvas, puntos...) y Get Geometry Component extrae uno de esos tipos. |
| 〰️ | **Add > Curve: Read / Sample / Write / Operations / Primitives / Topology** | *Barra superior > Add > Curve* | Advanced | Categoría propia del tipo de geometría CURVA (líneas con puntos de control, que pueden convertirse en malla o usarse como recorrido). Se organiza en 6 submenús: Read (leer datos de los puntos de la curva), Sample (muestrear un punto a lo largo de la curva), Write (modificar propiedades de la curva), Operations (convertirla y transformarla), Primitives (crear curvas nuevas desde cero) y Topology (relaciones entre puntos, splines y sus índices). Los 6 están detallados en las filas siguientes. |
| 〰️ | **Add > Curve > Read: Curve Handle Positions / Curve Length / Curve Tangent / Curve Tilt / Endpoint Selection / Handle Type Selection / Is Spline Cyclic / Spline Length / Spline Parameter / Spline Resolution** | *Barra superior > Add > Curve > Read* | Advanced | Leen datos que la curva ya tiene, para usarlos en cálculos (listado confirmado desde Node > Swap, que usa exactamente el mismo árbol que Add): Spline Parameter es de los más usados, da un valor de 0 a 1 según lo avanzado que esté cada punto a lo largo de la curva (perfecto para que algo cambie de grosor, color o tamaño de principio a fin). Curve Tangent da la dirección en la que avanza la curva en cada punto, y Curve Tilt su giro sobre su propio eje. Curve Length y Spline Length dan la longitud total y la de cada spline. Spline Resolution da en cuántos segmentos se subdivide. Curve Handle Positions da la posición de los manejadores Bézier. Endpoint Selection devuelve una selección con los puntos de los extremos (para tratar el principio y el final de forma distinta), Handle Type Selection una selección según el tipo de manejador, e Is Spline Cyclic dice si la curva está cerrada sobre sí misma. |
| 〰️ | **Add > Curve > Sample: Sample Curve** | *Barra superior > Add > Curve > Sample* | Advanced | Único nodo del submenú. Sample Curve devuelve la posición, la tangente y la normal de un punto situado a una distancia o factor concretos A LO LARGO de la curva, aunque ahí no haya ningún punto de control real. Es la forma habitual de hacer que algo recorra un camino: mover un objeto por una trayectoria, repartir copias a lo largo de una curva o alinear geometría con su dirección. |
| 〰️ | **Add > Curve > Write: Set Curve Normal / Set Curve Radius / Set Curve Tilt / Set Handle Positions / Set Handle Type / Set NURBS Order / Set NURBS Weight / Set Spline Cyclic / Set Spline Resolution / Set Spline Type** | *Barra superior > Add > Curve > Write* | Advanced | Todos empiezan por 'Set' porque ESCRIBEN una propiedad de la curva: Set Curve Radius cambia el grosor punto a punto (lo que determina el grosor del tubo al convertirla en malla). Set Curve Tilt gira la curva sobre su propio eje a lo largo del recorrido. Set Curve Normal define hacia dónde mira. Set Handle Positions y Set Handle Type controlan los manejadores Bézier (su posición y si son Free/Auto/Vector/Aligned), es decir, cómo de curvada es cada esquina. Set Spline Cyclic cierra la curva sobre sí misma. Set Spline Resolution ajusta en cuántos segmentos se subdivide al convertirla en geometría real (más resolución = más suave y más pesada). Set Spline Type convierte entre tipos de spline (Bézier, NURBS, Poly, Catmull Rom) y Set NURBS Order / Set NURBS Weight ajustan los parámetros propios de las NURBS. |
| 〰️ | **Add > Curve > Operations: Curve to Mesh / Curve to Points / Curves to Grease Pencil / Deform Curves on Surface / Fill Curve / Fillet Curve / Interpolate Curves / Resample Curve / Reverse Curve / Subdivide Curve / Trim Curve** | *Barra superior > Add > Curve > Operations* | Advanced | Transforman la curva o la convierten en otra cosa: Curve to Mesh es el nodo estrella, recorre la curva con un perfil (otra curva) y genera una malla real — así se hacen cables, tuberías, molduras o carreteras. Curve to Points la convierte en puntos sueltos (para instanciar objetos sobre ella) y Curves to Grease Pencil en trazos de dibujo. Deform Curves on Surface hace que las curvas sigan la deformación de la superficie sobre la que nacen (usado con pelo). Fill Curve rellena una curva cerrada con caras. Fillet Curve redondea sus esquinas. Interpolate Curves genera curvas intermedias entre otras (relleno de pelo). Resample Curve redistribuye sus puntos de control con una cantidad o espaciado uniforme, paso casi obligatorio antes de trabajar con ella. Reverse Curve invierte su dirección (dónde está el principio y el final). Subdivide Curve añade puntos intermedios y Trim Curve recorta un trozo, quedándose con el tramo entre dos valores. |
| 〰️ | **Add > Curve > Primitives: Arc / Bézier Segment / Curve Circle / Curve Line / Spiral / Quadratic Bézier / Quadrilateral / Star** | *Barra superior > Add > Curve > Primitives* | Advanced | CREAN una curva nueva desde cero, sin necesidad de partir de geometría existente (el equivalente al menú Add del Viewport pero por nodos y con todos sus parámetros animables): Curve Line (una recta entre dos puntos), Arc (un arco), Curve Circle (un círculo), Spiral (una espiral), Quadrilateral (un cuadrilátero, con variantes tipo rectángulo/trapecio/rombo), Star (una estrella con número de puntas y radios ajustables), y Bézier Segment / Quadratic Bézier, que crean un tramo de curva Bézier definido por sus puntos de control. Combinados con Curve to Mesh son la base para generar formas paramétricas completas. |
| 〰️ | **Add > Curve > Topology: Curve of Point / Offset Point in Curve / Points of Curve** | *Barra superior > Add > Curve > Topology* | Advanced | Nodos que devuelven ÍNDICES para moverse por la estructura interna de las curvas, no valores visuales: Curve of Point dice a qué curva (spline) pertenece un punto dado, cuando la geometría contiene varias curvas a la vez. Offset Point in Curve devuelve el punto que está N posiciones antes o después de otro dentro de la misma curva (para comparar un punto con su vecino, calcular direcciones o hacer efectos en cadena). Points of Curve da los puntos que forman una curva concreta, con opción de ordenarlos. Se usan junto a nodos de campo para hacer cálculos que dependen de la vecindad, no solo de cada punto por separado. |
| ✏️ | **Add > Grease Pencil > Read: Named Layer Selection** | *Barra superior > Add > Grease Pencil > Read* | Advanced | La categoría Grease Pencil trabaja con el dibujo 2D de Blender (trazos organizados en capas) dentro de Geometry Nodes, y se divide en 3 submenús: Read, Write y Operations. Read contiene un único nodo, Named Layer Selection, que devuelve una selección (verdadero/falso) con los trazos que están en la capa cuyo nombre se indique — la forma de aplicar un efecto solo a una capa concreta del dibujo. |
| ✏️ | **Add > Grease Pencil > Write: Set Grease Pencil Color / Set Grease Pencil Depth / Set Grease Pencil Softness** | *Barra superior > Add > Grease Pencil > Write* | Advanced | Escriben propiedades de los trazos: Set Grease Pencil Color cambia su color (por trazo o por punto, pudiendo pintar por procedimientos en vez de a mano). Set Grease Pencil Depth controla su orden de profundidad, es decir, qué trazo queda delante de cuál al dibujarse en 3D. Set Grease Pencil Softness ajusta la dureza del borde del trazo, de un filo limpio a un desvanecido suave. |
| ✏️ | **Add > Grease Pencil > Operations: Grease Pencil to Curves / Merge Layers** | *Barra superior > Add > Grease Pencil > Operations* | Advanced | Grease Pencil to Curves convierte los trazos de dibujo en curvas reales, lo que permite tratarlos con todo el submenú Curve (darles grosor con Curve to Mesh, recorrerlos, instanciar objetos sobre ellos...): es el puente habitual entre dibujar a mano y generar geometría 3D a partir de ese dibujo. Merge Layers fusiona varias capas del Grease Pencil en una sola. |
| 🔁 | **Add > Instances: Instance on Points / Instances to Points / Realize Instances / Rotate Instances / Scale Instances / Set Instance Transform / Translate Instances / Instance Bounds / Instance Reference / Instance Transform / Instance Rotation / Instance Scale** | *Barra superior > Add > Instances* | Advanced | Categoría sin submenús, y una de las MÁS IMPORTANTES de Geometry Nodes. Una instancia es una copia ligera de una geometría: se puede repetir miles de veces sin apenas coste, porque por dentro Blender guarda una sola malla y solo apunta dónde va cada copia. Instance on Points es el nodo estrella: coloca una copia de una geometría (u objeto, o colección) sobre cada punto que reciba — así se hacen bosques, multitudes, tornillos repartidos por una superficie o ladrillos de un muro. Instances to Points hace lo contrario. Realize Instances las convierte en geometría real y editable, necesario para aplicarles después nodos que trabajan a nivel de vértice/cara (pero pesado: solo cuando haga falta). Translate / Rotate / Scale Instances mueven, giran o escalan cada copia por separado (normalmente con valores aleatorios, para que no queden todas idénticas) y Set Instance Transform fija su transformación completa de golpe. Los cinco últimos son de lectura: Instance Bounds (la caja que ocupa cada copia), Instance Reference (a qué geometría original apunta), Instance Transform, Instance Rotation e Instance Scale (su transformación actual), para poder usarlos en cálculos. |
| 🔺 | **Add > Mesh: Read / Sample / Write / Operations / Primitives / Topology / UV** | *Barra superior > Add > Mesh* | Advanced | La categoría más extensa: todo lo específico de las MALLAS (vértices, aristas y caras). Sus 7 submenús siguen el patrón habitual — Read (leer datos de cada elemento), Sample (muestrear otra malla), Write (escribir propiedades), Operations (modificar la malla de verdad: extruir, biselar, subdividir...), Primitives (crear mallas nuevas desde cero), Topology (relaciones entre vértices/aristas/caras/esquinas) y UV, exclusivo de esta categoría, para el desplegado UV. Ver las filas siguientes, una por submenú. |
| 🔺 | **Add > Mesh > Read: Cluster by Connected / Edge Angle / Edge Neighbors / Edge Vertices / Edges to Face Groups / Face Area / Face Group Boundaries / Face Neighbors / Is Face Planar / Is Face Smooth / Is Edge Smooth / Mesh Island / Shortest Edge Paths / Vertex Neighbors** | *Barra superior > Add > Mesh > Read* | Advanced | Leen información que Blender ya sabe de la malla, para usarla en cálculos y selecciones: Edge Angle da el ángulo entre las dos caras de una arista (la forma clásica de detectar los bordes duros para biselarlos solo ahí). Face Area da el área de cada cara (para repartir puntos de forma proporcional). Edge Vertices da los dos vértices de cada arista, y Edge Neighbors / Face Neighbors / Vertex Neighbors cuántos elementos vecinos tiene cada uno. Is Face Planar dice si una cara es plana, Is Face Smooth / Is Edge Smooth si están marcadas como suavizadas. Mesh Island y Cluster by Connected identifican los trozos sueltos (no conectados) de la malla, para tratarlos por separado. Edges to Face Groups y Face Group Boundaries agrupan caras separadas por ciertas aristas y detectan sus bordes. Shortest Edge Paths calcula el camino más corto entre dos puntos siguiendo las aristas. |
| 🔺 | **Add > Mesh > Sample: Sample Nearest Surface / Sample UV Surface** | *Barra superior > Add > Mesh > Sample* | Advanced | Leen un valor de OTRA malla en un punto concreto, sin necesidad de que las dos geometrías coincidan: Sample Nearest Surface toma el valor del punto más cercano de la superficie de la otra malla (por ejemplo, para transferir un color o una máscara de un objeto a otro). Sample UV Surface hace lo mismo pero localizando el punto por sus coordenadas UV en vez de por proximidad. |
| 🔺 | **Add > Mesh > Write: Set Mesh Normal / Set Shade Smooth** | *Barra superior > Add > Mesh > Write* | Advanced | Set Mesh Normal escribe a mano la normal (la dirección hacia la que se considera que mira la superficie), lo que cambia cómo recibe la luz sin cambiar la forma real — muy usado en assets de videojuego, por ejemplo para que la vegetación se ilumine de forma uniforme. Set Shade Smooth marca las caras o aristas como suavizadas o planas, el equivalente por nodos de Shade Smooth / Shade Flat del Viewport. |
| 🔺 | **Add > Mesh > Operations: Dual Mesh / Edge Paths to Curves / Edge Paths to Selection / Extrude Mesh / Flip Faces / Mesh Bevel / Mesh Boolean / Mesh to Curve / Mesh to Density Grid / Mesh to Points / Mesh to SDF Grid / Mesh to Volume / Scale Elements / Split Edges / Subdivide Mesh / Subdivision Surface / Triangulate** | *Barra superior > Add > Mesh > Operations* | Advanced | Los nodos que MODIFICAN la malla de verdad, muchos equivalentes a herramientas del Edit Mode pero procedurales: Extrude Mesh extruye vértices, aristas o caras. Mesh Bevel bisela. Mesh Boolean une, resta o intersecta dos mallas. Subdivide Mesh añade cortes y Subdivision Surface suaviza al estilo del modificador Subdivision. Triangulate convierte todo en triángulos (necesario al exportar a motores de videojuego). Split Edges separa aristas, Flip Faces invierte las normales y Scale Elements escala caras o aristas individualmente en vez de la malla entera. Dual Mesh construye la malla dual (cada cara pasa a ser un vértice), muy usado para generar patrones hexagonales.
