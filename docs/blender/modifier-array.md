# Modifier: Array


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Count** | *Dentro del modificador* | Basic | Número total de copias del objeto, incluyendo la original. |
| - | **Relative Offset** | *Dentro del modificador* | Basic | Separa cada copia como un múltiplo del propio tamaño del objeto (p. ej. 1.0 en X = pegadas una a continuación de otra). |
| - | **Constant Offset** | *Dentro del modificador* | Intermediate | Separa cada copia una distancia fija en unidades de Blender, independientemente del tamaño del objeto. |
| - | **Object Offset** | *Dentro del modificador* | Advanced | Usa la posición/rotación de OTRO objeto (normalmente un Empty) como patrón de repetición; permite arrays curvos o en espiral. |
| - | **Merge** | *Dentro del modificador* | Intermediate | Fusiona los vértices donde una copia toca a la siguiente, para que la unión no se note. |
