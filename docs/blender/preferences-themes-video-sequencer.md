# Preferences > Themes: Video Sequencer


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎞️ | **Tipos de strip por color** | *Edit > Preferences > Themes > Video Sequencer* | Intermediate | Cada tipo de strip (bloque) del Video Sequence Editor tiene su propio color para distinguirlos de un vistazo en el montaje: Movie Strip, Clip Strip, Image Strip, Scene Strip, Audio Strip, Effect Strip, Transition Strip, Color Strip, Meta Strip (agrupa otros strips dentro), Mask Strip y Text Strip; Active Strip y Selected Strips resaltan el strip activo/seleccionados. |
| 🎞️ | **Rejilla, keyframes y metadata** | *Edit > Preferences > Themes > Video Sequencer* | Advanced | Grid es la rejilla de fondo de la línea de tiempo; Keyframe Border/Keyframe Border Selected son los keyframes visibles dentro de un strip; Preview Background es el fondo de la ventana de previsualización de vídeo; Metadata Background/Text muestra info superpuesta al preview; Alternate Rows alterna el fondo de las pistas; Text Strip Cursor y Selected Text son el cursor y la selección de texto al editar un Text Strip. |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Video Sequencer > Theme Space* | Basic | Mismo patrón repetido en todos los editores. |
