# UV Editor > View


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Asset Shelf (no disponible en el UV Editor)** | *Barra superior del UV Editor > View* | Basic | Aparece en gris/deshabilitado: el Asset Shelf no está disponible en el UV Editor (a diferencia del Viewport 3D), por lo que esta opción no se puede activar aquí. |
| 🔄 | **Update Automatically** | *Barra superior del UV Editor > View* | Intermediate | Activado por defecto: el mapa UV mostrado se recalcula y actualiza automáticamente al editar la malla en Edit Mode. Si se desactiva, hay que actualizar el mapa UV manualmente tras cada cambio en la geometría. |
| ℹ️ | **Show Metadata** | *Barra superior del UV Editor > View* | Basic | Desactivado por defecto: al activarlo, superpone en el editor los metadatos de la imagen cargada (resolución, formato de color, etc.). |
| 🔍 | **Zoom: 12.5% / 25% / 50% / 100% / 200% / 400% / 800%** | *Barra superior del UV Editor > View > Zoom* | Intermediate | Niveles de zoom fijos del mapa UV (Numpad 8/4/2/1/Ctrl+Numpad 2/4/8): 100% (Numpad 1) muestra el mapa a su resolución de píxel real 1:1 respecto a la imagen cargada; el punto marca el nivel activo. |
| 🔍 | **Zoom In / Zoom Out / Zoom to Fit / Zoom Region...** | *Barra superior del UV Editor > View > Zoom* | Basic | Zoom In/Out (rueda del ratón): acercar/alejar. Zoom to Fit (Shift+Home): ajusta el zoom para que quepa todo el contenido visible. Zoom Region... (Shift+B): dibuja un rectángulo para hacer zoom solo a esa región, igual que en el Viewport 3D. |
| ⌨️ | **Zoom to Fit** | <kbd>Shift</kbd> + <kbd>Home</kbd> | Basic | Zoom to Fit |
| ⌨️ | **Zoom Region...** | <kbd>Shift</kbd> + <kbd>B</kbd> | Basic | Zoom Region... |
| 🪟 | **Area: Horizontal Split / Vertical Split / Maximize Area / Focus Mode / Duplicate Area into New Window / Close Area** | *Barra superior del UV Editor > View > Area* | Intermediate | Horizontal/Vertical Split dividen el UV Editor en dos áreas. Maximize Area (Ctrl+Barra espaciadora) y Focus Mode (Ctrl+Alt+Barra espaciadora) son los mismos comandos ya documentados en 'Viewport 3D > View'. Duplicate Area into New Window abre una copia de este editor en una ventana aparte. Close Area cierra el área actual. |
