# Preferences > System: Cycles Render Devices


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖥️ | **None / CUDA / OptiX / HIP / oneAPI** | *Edit > Preferences > System* | Intermediate | Elige con qué hardware calcula Cycles el render: None usa solo la CPU; CUDA/OptiX son para tarjetas NVIDIA (OptiX suele ir más rápido en tarjetas RTX), HIP para AMD, oneAPI para Intel Arc. |
