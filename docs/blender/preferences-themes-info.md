# Preferences > Themes: Info


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ℹ️ | **Iconos y líneas del editor Info** | *Edit > Preferences > Themes > Info* | Intermediate | Colorea el editor Info (el registro de mensajes/log en la parte inferior de Blender): Selected Line Background/Text Color resalta una línea seleccionada, y cada tipo de mensaje tiene su propio icono coloreado — Error/Warning/Info Icon Foreground, Debug Icon Background/Foreground, Property Icon Foreground/Background (cambios de propiedad) y Operator Icon Background/Foreground (operaciones ejecutadas). |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Info > Theme Space* | Basic | Mismo patrón repetido (en la captura aparece colapsado, pero contiene los mismos campos que en el resto de editores: Title, Text, Header...). |
