# Preferences > Animation: Timeline


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Minimum Grid Spacing** | *Edit > Preferences > Animation > Timeline* | Advanced | Distancia mínima en píxeles entre las marcas de la regla de tiempo antes de que Blender empiece a saltarse números para no amontonarlos. |
| - | **Timecode Style** | *Edit > Preferences > Animation > Timeline* | Advanced | Cómo se muestra el tiempo en la Timeline/Dopesheet (aquí 'Minimal Info'): como frames, como HH:MM:SS, etc. |
| - | **Zoom to Frame Type** | *Edit > Preferences > Animation > Timeline* | Advanced | Qué hace el atajo de encuadrar el frame actual (Home/View Frame); aquí 'Keep Range' mantiene el rango de zoom que ya tenías en vez de resetearlo. |
| - | **Allow Negative Frames** | *Edit > Preferences > Animation > Timeline > Advanced* | Advanced | Permite que la animación empiece antes del frame 0 (frames negativos); Blender avisa de que puede dar problemas con audio y algunos exportadores. |
