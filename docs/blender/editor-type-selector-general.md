# Editor Type Selector: General


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🧊 | **3D Viewport** | *Icono de tipo de editor > 3D Viewport (Mayús+F5)* | Basic | Convierte el panel activo en la vista 3D principal, donde se modela, anima, esculpe y pinta sobre la escena. |
| 🖼️ | **Image Editor** | *Icono de tipo de editor > Image Editor (Mayús+F10)* | Basic | Convierte el panel activo en el editor de imágenes: ver, pintar (Texture Paint) o editar imágenes y texturas cargadas en el archivo. |
| 🗺️ | **UV Editor** | *Icono de tipo de editor > UV Editor (Mayús+F10)* | Intermediate | Convierte el panel activo en el editor del mapa de coordenadas UV de la malla activa en Edit Mode; muestra y permite mover/coser/relajar los UVs (ver categorías 'Barra T: UV Editing'). |
| 🧬 | **Geometry Node Editor** | *Icono de tipo de editor > Geometry Node Editor (Mayús+F3)* | Advanced | Convierte el panel activo en el editor de nodos de Geometry Nodes, para crear geometría y efectos de forma procedural mediante grafos de nodos. |
| 🎞️ | **Compositor** | *Icono de tipo de editor > Compositor (Mayús+F3)* | Advanced | Convierte el panel activo en el editor de nodos de composición, para la postproducción del render (mezclar capas, color, efectos) dentro del propio Blender. |
| 💠 | **Shader Editor** | *Icono de tipo de editor > Shader Editor (Mayús+F3)* | Intermediate | Convierte el panel activo en el editor de nodos de materiales/shaders del objeto activo. |
| 💠 | **Texture Node Editor** | *Icono de tipo de editor > Texture Node Editor (Mayús+F3)* | Advanced | Convierte el panel activo en el editor de nodos de texturas 'legacy' (sistema de texturas antiguo de Blender, poco usado hoy frente al Shader Editor). |
| 🎞️ | **Video Sequencer** | *Icono de tipo de editor > Video Sequencer (Mayús+F8)* | Intermediate | Convierte el panel activo en el editor de montaje de vídeo (Video Sequence Editor), para cortar y combinar clips, audio e imágenes en una línea de tiempo. |
| 🎥 | **Movie Clip Editor** | *Icono de tipo de editor > Movie Clip Editor (Mayús+F2)* | Advanced | Convierte el panel activo en el editor de tracking de vídeo (Motion Tracking / Match-Moving), para seguir puntos de una filmación real y encajar cámara/objetos 3D sobre ella. |
