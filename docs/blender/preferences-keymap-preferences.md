# Preferences > Keymap: Preferences


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Ajustes generales de interacción** | *Edit > Preferences > Keymap > Preferences* | Advanced | No son atajos sino comportamientos globales del ratón/teclado: Select with Mouse Button (si el clic Izquierdo o Derecho selecciona, según venías de otro programa), Spacebar Action (qué hace la barra espaciadora: Play, abrir buscador de Tools, o Search), Activate Gizmo Event (si los gizmos de mover/rotar se activan con Press o con Drag) y Tool Keys (si al pulsar la tecla de una herramienta la activa Immediate o solo la deja como Active Tool para usar después). |
