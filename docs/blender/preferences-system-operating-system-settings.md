# Preferences > System: Operating System Settings


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Register / Unregister** | *Edit > Preferences > System* | Advanced | Asocia (o desasocia) los archivos .blend de Windows para que se abran por defecto con esta versión de Blender al hacer doble clic. |
| - | **For All Users** | *Edit > Preferences > System* | Advanced | Aplica esa asociación de archivos a todos los usuarios del ordenador, no solo al tuyo (requiere permisos de administrador). |
