# Editor Type Selector: Animation


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🔑 | **Dope Sheet** | *Icono de tipo de editor > Dope Sheet (Mayús+F12)* | Intermediate | Convierte el panel activo en la línea de tiempo de keyframes de todos los canales animados, para mover/recolocar fotogramas clave en bloque. |
| ⏱️ | **Timeline** | *Icono de tipo de editor > Timeline (Mayús+F12)* | Basic | Convierte el panel activo en una barra de tiempo simplificada (solo reproducción y frame actual), sin el desglose por canales del Dope Sheet. |
| 📈 | **Graph Editor** | *Icono de tipo de editor > Graph Editor (Mayús+F6)* | Advanced | Convierte el panel activo en el editor de curvas de animación (F-Curves), para ajustar con precisión la interpolación (Bezier, Constant, Linear) entre keyframes. |
| 🧮 | **Drivers** | *Icono de tipo de editor > Drivers (Mayús+F6)* | Advanced | Convierte el panel activo en el editor de Drivers: relaciones donde el valor de una propiedad se calcula automáticamente a partir de otra (por ejemplo, un hueso que controla un modifier). |
| 🎼 | **Nonlinear Animation** | *Icono de tipo de editor > Nonlinear Animation* | Advanced | Convierte el panel activo en el editor NLA, que combina varias Actions (animaciones) del mismo objeto en distintas pistas, como un editor de vídeo pero de animaciones (mezclar, recortar, repetir en bucle). |
