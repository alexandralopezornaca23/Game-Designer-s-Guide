# File Menu: Import


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📥 | **Alembic (.abc)** | *File > Import* | Advanced | Trae geometría 'cacheada' fotograma a fotograma (simulaciones de tela, pelo, fluidos); no trae huesos, solo la malla ya deformada. |
| 📥 | **Universal Scene Description (.usd*)** | *File > Import* | Advanced | Importa escenas en formato USD (.usd/.usdc/.usda), cada vez más estándar en pipelines de estudio; conserva jerarquías y materiales complejos. |
| 📥 | **SVG as Grease Pencil** | *File > Import* | Intermediate | Convierte un SVG (curvas vectoriales, p. ej. desde Illustrator) en trazos de Grease Pencil, ideal para animación 2D. |
| 📥 | **Wavefront (.obj)** | *File > Import* | Basic | Formato universal para mallas estáticas; no trae huesos ni animación. |
| 📥 | **Stanford PLY (.ply)** | *File > Import* | Intermediate | Formato típico de escaneos 3D y point clouds; puede incluir color por vértice. |
| 📥 | **STL (.stl)** | *File > Import* | Basic | Pensado para impresión 3D; solo trae geometría, sin materiales ni animación. |
| 📥 | **FBX (.fbx)** | *File > Import* | Basic | El formato más usado para traer modelos, armaduras (rigs) y animaciones desde Unity, Unreal o Maya. |
| 📥 | **glTF 2.0 (.glb / .gltf)** | *File > Import* | Intermediate | Formato ligero pensado para web y tiempo real; conserva los materiales PBR de forma muy fiel. |
| 📥 | **SVG as Curves (.svg)** | *File > Import* | Intermediate | Convierte un SVG en curvas de Blender (Bézier), listas para editar, extruir o convertir en malla. |
| 📥 | **FBX (.fbx) (Legacy)** | *File > Import* | Advanced | Importador FBX antiguo, previo a la reescritura; úsalo solo si el importador FBX normal falla con un archivo concreto. |
| 📥 | **Motion Capture (.bvh)** | *File > Import* | Advanced | Trae datos de captura de movimiento (mocap) en formato BVH para aplicarlos a un esqueleto. |
