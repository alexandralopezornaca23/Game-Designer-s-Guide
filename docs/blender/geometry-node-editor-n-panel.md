# Geometry Node Editor > N Panel


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎛️ | **Panel N > Active Tool: cambia según la herramienta activa de la Barra T** | *Panel lateral N del Geometry Node Editor > Active Tool (Tecla N)* | Intermediate | El panel lateral N de este editor muestra un bloque 'Active Tool' cuyo contenido CAMBIA según qué herramienta esté activa en la Barra T: es donde se ajustan los parámetros de esa herramienta sin salir del editor. En la captura, con Annotate activo, muestra: Placement (dónde se ancla el trazo; aquí 'Image'), Stabilize Stroke (casilla que suaviza el trazo mientras dibujas, para pulsos temblorosos), Radius (grosor del trazo, 35 px por defecto) y Factor (0.750, la intensidad del suavizado anterior — ambos aparecen en gris hasta que se activa Stabilize Stroke), y Drag (qué hace arrastrar con el botón izquierdo cuando no estás usando la herramienta; por defecto Select Box, el mismo selector ya documentado en 'Barra T: Comunes a todos los modos'). |
