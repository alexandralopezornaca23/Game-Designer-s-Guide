# UV Editor > UV


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📐 | **Transform: Move / Rotate / Resize / Shear / Vertex Slide / Edge Slide / Randomize** | *Barra superior > UV > Transform* | Basic | Mismas transformaciones que en el Viewport 3D pero aplicadas a los UVs seleccionados dentro del mapa 2D: Move, Rotate y Resize son las básicas; Shear inclina/distorsiona en diagonal; Vertex/Edge Slide desliza UVs a lo largo de una arista vecina; Randomize dispersa aleatoriamente los UVs seleccionados (útil para variar texturas procedurales). |
| ⌨️ | **Shear** | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd> | Basic | Shear |
| 🪞 | **Mirror: Copy Mirrored UV Coords / X Axis / Y Axis** | *Barra superior > UV > Mirror* | Intermediate | X Axis / Y Axis: reflejan los UVs seleccionados respecto al eje correspondiente del mapa UV. Copy Mirrored UV Coords: copia coordenadas UV reflejadas desde una selección simétrica en la malla, sin moverlas manualmente. |
| 🧲 | **Snap: Selected to Pixels / Selected to Cursor / Selected to Cursor (Offset) / Selected to Adjacent Unselected / Cursor to Pixels / Cursor to Selected / Cursor to Origin** | *Barra superior > UV > Snap* | Advanced | Ajusta (snap) los UVs seleccionados o el cursor 2D del editor a distintas referencias: la rejilla de píxeles de la imagen, la posición del cursor 2D (con o sin offset), UVs adyacentes no seleccionados, o el origen (0,0) del mapa. |
| 🔲 | **Round to Pixels: Disabled / Corner / Center** | *Barra superior > UV > Round to Pixels* | Advanced | Ajuste que redondea las coordenadas UV a la rejilla de píxeles de la imagen activa tras transformarlas. Corner redondea a la esquina de píxel más cercana, Center al centro del píxel; Disabled lo desactiva. |
| 🖼️ | **Constrain to Image Bounds** | *Barra superior > UV > Constrain to Image Bounds* | Basic | Casilla desactivada por defecto: si se activa, impide mover o transformar los UVs fuera del cuadro 0-1 de la imagen (el área de textura válida). |
| 🔗 | **Merge / Split** | *Barra superior > UV > Merge / Split* | Intermediate | Merge (M): fusiona en un mismo punto los UVs seleccionados, con 3 métodos posibles (ver fila 'Merge: At Center / At Cursor / By Distance'). Split (Alt+M): separa UVs que estaban unidos para que puedan moverse de forma independiente. |
| ⌨️ | **Merge** | <kbd>M</kbd> | Intermediate | Merge |
| ⌨️ | **Split** | <kbd>Alt</kbd> + <kbd>M</kbd> | Intermediate | Split |
| - | **Merge: At Center / At Cursor / By Distance** | *Barra superior > UV > Merge* | Intermediate | Método usado para fusionar los UVs seleccionados con Merge (M): At Center los une en el centro de la selección, At Cursor los une en la posición del cursor 2D, By Distance solo fusiona los UVs que estén más cerca entre sí que una distancia mínima configurable (evita fusionar accidentalmente UVs lejanos). |
| ✂️ | **Rip Move UVs** | *Barra superior > UV > Rip Move UVs (arrastrar con Botón Izquierdo)* | Intermediate | Separa los UVs seleccionados del resto de la isla y los deja pegados al ratón para moverlos, en el mismo momento del arrastre (drag). Es la versión de menú del pincel Rip Region de la Barra T. |
| 🔄 | **Live Unwrap** | *Barra superior > UV > Live Unwrap* | Intermediate | Casilla desactivada por defecto: si se activa, el mapa UV se recalcula automáticamente con el método de Unwrap usado la última vez, cada vez que editas la malla en Edit Mode. |
| 🧩 | **Unwrap: Unwrap Angle Based / Unwrap Conformal / Unwrap Minimum Stretch** | *Barra superior > UV > Unwrap* | Advanced | Tres algoritmos distintos para desplegar (unwrap) la malla marcada con seams: Angle Based (por defecto, prioriza conservar los ángulos), Conformal (más rápido, menos preciso), Minimum Stretch (minimiza el estiramiento de la textura). |
| ⌨️ | **Unwrap** | <kbd>U</kbd> | Advanced | Unwrap |
| 🧩 | **Unwrap: Smart UV Project... / Lightmap Pack... / Follow Active Quads...** | *Barra superior > UV > Unwrap* | Advanced | Métodos alternativos de desplegado automático: Smart UV Project calcula y coloca seams automáticamente según los ángulos de la malla; Lightmap Pack genera un mapa UV optimizado para lightmaps (sin solapes); Follow Active Quads propaga una cuadrícula UV regular a partir de la cara activa. |
| 🧩 | **Unwrap: Cube Projection / Cylinder Projection / Sphere Projection** | *Barra superior > UV > Unwrap* | Advanced | Proyectan los UVs usando una forma geométrica simple como base (cubo, cilindro o esfera), útil como punto de partida rápido en objetos con esa silueta general. |
| 📌 | **Pin / Unpin / Invert Pins** | *Barra superior > UV > Pin / Unpin / Invert Pins* | Intermediate | Pin (P): fija los UVs seleccionados para que un Unwrap posterior no los mueva. Unpin (Alt+P): libera esa fijación. Invert Pins: invierte qué UVs están fijados y cuáles no, sin necesidad de reseleccionar. |
| ⌨️ | **Pin** | <kbd>P</kbd> | Intermediate | Pin |
| ⌨️ | **Unpin** | <kbd>Alt</kbd> + <kbd>P</kbd> | Intermediate | Unpin |
| ✂️ | **Mark Seam / Clear Seam / Seams from Islands** | *Barra superior > UV > Mark Seam / Clear Seam / Seams from Islands* | Intermediate | Mark Seam marca las aristas seleccionadas como costura (línea de corte para el Unwrap); Clear Seam la quita. Seams from Islands marca automáticamente como seam los bordes de las islas UV ya existentes en el mapa. |
| 📦 | **Pack Islands / Average Islands Scale / Arrange/Align Islands** | *Barra superior > UV > Pack Islands / Average Islands Scale / Arrange/Align Islands* | Advanced | Pack Islands reorganiza automáticamente todas las islas UV para aprovechar mejor el espacio de la imagen. Average Islands Scale normaliza el tamaño relativo de las islas según la escala real de la malla 3D. Arrange/Align Islands las ordena/alinea entre sí. |
| 🖼️ | **Set User Region / Custom Region** | *Barra superior > UV > Set User Region / Custom Region* | Advanced | Definen una región personalizada de la imagen (distinta del cuadro 0-1 completo) para usar como límites del espacio UV, útil al trabajar con atlas de texturas donde cada objeto solo ocupa una parte de la imagen. |
| ⌨️ | **Set User Region** | <kbd>Ctrl</kbd> + <kbd>B</kbd> | Advanced | Set User Region |
| ⌨️ | **Custom Region** | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd> | Advanced | Custom Region |
| 🧵 | **Minimize Stretch / Stitch** | *Barra superior > UV > Minimize Stretch / Stitch* | Advanced | Minimize Stretch relaja de forma iterativa los UVs seleccionados para reducir el estiramiento de la textura. Stitch (Alt+V) une/suelda aristas UV seleccionadas que estaban separadas, cosiendo la isla. |
| ⌨️ | **Stitch** | <kbd>Alt</kbd> + <kbd>V</kbd> | Advanced | Stitch |
| 📏 | **Align: Straighten / Straighten X / Straighten Y / Align Auto / Align Vertically / Align Horizontally** | *Barra superior > UV > Align* | Advanced | Alinea en línea recta los UVs seleccionados: Straighten los endereza siguiendo su orientación actual, Straighten X/Y los fuerza a un eje concreto, Align Auto elige automáticamente la mejor orientación, y Align Vertically/Horizontally fuerzan vertical u horizontal. |
| ⌨️ | **Align** | <kbd>Shift</kbd> + <kbd>W</kbd> | Advanced | Align |
| 🔀 | **Align Rotation / Move on Axis: Dynamic / Pixel / UDIM** | *Barra superior > UV > Align Rotation / Move on Axis* | Advanced | Align Rotation gira la isla seleccionada para alinearla con el eje más cercano. Move on Axis restringe el movimiento de los UVs a un solo eje, con distinta granularidad de desplazamiento: Dynamic (libre), Pixel (en pasos de píxel de la imagen) o UDIM (en pasos de tile UDIM completo). |
| 📋 | **Copy UVs / Paste UVs** | *Barra superior > UV > Copy UVs / Paste UVs* | Intermediate | Copian y pegan las coordenadas UV de las caras seleccionadas, permitiendo trasladar un mapa UV ya ajustado a otro UV Map del mismo objeto o a otro objeto con topología compatible. |
| ⌨️ | **Copy UVs** | <kbd>Ctrl</kbd> + <kbd>C</kbd> | Intermediate | Copy UVs |
| ⌨️ | **Paste UVs** | <kbd>Ctrl</kbd> + <kbd>V</kbd> | Intermediate | Paste UVs |
| 👁️ | **Show/Hide Faces: Reveal Hidden / Hide Selected / Hide Unselected** | *Barra superior > UV > Show/Hide Faces* | Intermediate | Igual que ocultar/mostrar en el Viewport 3D pero aplicado solo a qué caras se ven/editan dentro del UV Editor: no afecta a la visibilidad de la malla en el viewport 3D, solo a qué UVs están disponibles para trabajar aquí. |
| ⌨️ | **Reveal Hidden (UV)** | <kbd>Alt</kbd> + <kbd>H</kbd> | Intermediate | Reveal Hidden (UV) |
| ⌨️ | **Hide Selected (UV)** | <kbd>H</kbd> | Intermediate | Hide Selected (UV) |
| ⌨️ | **Hide Unselected (UV)** | <kbd>Shift</kbd> + <kbd>H</kbd> | Intermediate | Hide Unselected (UV) |
| ♻️ | **Reset** | *Barra superior > UV > Reset* | Basic | Restablece el mapa UV de las caras seleccionadas a su estado por defecto, deshaciendo ediciones manuales previas sobre esos UVs. |
| 📤 | **Export UV Layout** | *Barra superior > UV > Export UV Layout* | Basic | Exporta el trazado del mapa UV actual como archivo de imagen (PNG, SVG, EPS...) para usarlo como plantilla al pintar la textura en un programa externo como Photoshop. |
