# Preferences > Themes: Outliner


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🗂️ | **Resaltado, filtro y filas** | *Edit > Preferences > Themes > Outliner* | Intermediate | Filter Match resalta un elemento que coincide con el texto buscado en el filtro del Outliner; Selected Highlight/Active Highlight son el fondo de una fila seleccionada/activa en la propia lista del Outliner; Selected Objects/Active Object/Edited Object colorean el nombre según el estado del objeto en la escena; Alternate Rows alterna el fondo de las filas para facilitar la lectura de listas largas. |
| - | **Theme Space (Title, Text, Header)** | *Edit > Preferences > Themes > Outliner > Theme Space* | Basic | Mismo patrón repetido en todos los editores (colapsado en la captura). |
