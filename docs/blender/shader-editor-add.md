# Shader Editor > Add


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ➕ | **Add: menú general** | *Barra superior del Shader Editor > Add* | Basic | Menú para crear nodos nuevos en el editor, organizado por categorías: Input/Output (entradas y salidas de datos), Shader (los distintos tipos de material/BSDF), Displacement, Color, Texture, Utilities (matemáticas, conversión y utilidades), Group y Layout (organización visual como Frame y Reroute). Es el mismo árbol de categorías que se repite, con el mismo contenido, dentro de 'Node > Swap' (para sustituir un nodo existente por otro tipo en vez de crear uno nuevo). |
| 📥 | **Add > Input > Constant: Ambient Occlusion / Attribute / Bevel / Camera Data / Color Attribute / Curves Info / Fresnel / Geometry / Layer Weight / Light Path / Object Info / Particle Info / Point Info / Raycast / Scene Time / Tangent / Texture Coordinate / UV Map / Volume Info / Wireframe** | *Barra superior > Add > Input > Constant* | Advanced | Nodos de entrada que no dependen de ninguna conexión previa: aportan datos ya calculados por Blender sobre la escena, el objeto o el propio proceso de render (posición, normales, UVs, información de la cámara, del objeto, de partículas, oclusión ambiental, tiempo de escena, etc.) para usarlos dentro de la red de nodos del material. |
| 📥 | **Add > Input: Boolean / Color / Integer / Menu / Value / Vector** | *Barra superior > Add > Input* | Intermediate | Además de los nodos 'Constant' (fila anterior), Input incluye estos 6 tipos de nodo para introducir a mano un valor fijo del tipo correspondiente (un booleano, un color, un entero, una opción de menú, un decimal o un vector) y conectarlo a donde haga falta. |
| 📤 | **Add > Output: AOV Output / Material Output** | *Barra superior > Add > Output* | Intermediate | AOV Output crea una salida de render personalizada (Arbitrary Output Variable) para extraer un pase extra en el compositor. Material Output es el nodo final obligatorio de cualquier material: recibe el resultado final en sus entradas Surface/Volume/Displacement/Thickness (visible en el grafo de ejemplo de las capturas). |
| 📤 | **Material Output > Target: All / EEVEE / Cycles** | *Nodo Material Output (dentro del grafo) > desplegable superior* | Intermediate | Elige para qué motor de render aplica este nodo Material Output cuando hay más de uno en el mismo material (por ejemplo, uno con Displacement solo para Cycles y otro más simple para EEVEE): All (por defecto, el mismo Material Output vale para ambos motores), EEVEE (solo se usa al renderizar/previsualizar con EEVEE) o Cycles (solo con Cycles). Si solo hay un Material Output en el material, esta distinción no tiene efecto. |
| 🎨 | **Add > Shader: Add Shader / Mix Shader / Diffuse BSDF / Emission / Glass BSDF / Glossy BSDF / Holdout / Metallic BSDF / Principled BSDF / Refraction BSDF / Specular BSDF / Subsurface Scattering / Translucent BSDF / Transparent BSDF / Principled Volume / Volume Absorption / Volume Scatter / Volume Coefficients** | *Barra superior > Add > Shader* | Advanced | Todos los tipos de shader (BSDF) que puede llevar un material: Add Shader y Mix Shader combinan dos shaders en uno (sumándolos o mezclándolos); el resto son shaders individuales para superficie (Diffuse, Glass, Glossy, Principled -el más completo y el usado por defecto-, Metallic, Refraction, Specular, Subsurface Scattering, Translucent, Transparent, Emission, Holdout) o para volumen (Principled Volume, Volume Absorption, Volume Scatter, Volume Coefficients). |
| 🎨 | **Add > Displacement: Bump / Displacement / Normal Map / Vector Displacement** | *Barra superior > Add > Displacement* | Advanced | Nodos para simular o generar relieve: Bump simula pequeños baches a partir de un mapa en escala de grises sin modificar la geometría real. Displacement desplaza físicamente la geometría (necesita subdivisión para verse bien). Normal Map aplica un mapa de normales (textura RGB) para simular detalle sin geometría extra. Vector Displacement es como Displacement pero permite desplazar en las 3 direcciones a la vez con un mapa de color. |
| 🎨 | **Add > Color: Blackbody / Brightness/Contrast / Color Ramp / Gamma / Hue/Saturation/Value / Invert Color / Light Falloff / Mix Color / RGB Curves / Wavelength / Combine Color / Separate Color / RGB to BW / Shader to RGB** | *Barra superior > Add > Color* | Advanced | Nodos para generar o transformar color: Blackbody y Wavelength generan un color a partir de una temperatura o longitud de onda física. Brightness/Contrast, Gamma, Hue/Saturation/Value, Invert Color y RGB Curves ajustan un color existente. Color Ramp lo remapea sobre un degradado editable. Mix Color mezcla dos colores con distintos modos de fusión. Combine Color/Separate Color unen o separan un color en sus 3 canales (RGB/HSV/HSL). RGB to BW lo convierte a escala de grises. Shader to RGB convierte el resultado de un shader en un color plano, útil para estilizados tipo toon. |
| 🎨 | **Add > Texture: Brick Texture / Checker Texture / Environment Texture / Gabor Texture / Gradient Texture / IES Texture / Image Texture / Magic Texture / Noise Texture / Sky Texture / Voronoi Texture / Wave Texture / White Noise Texture** | *Barra superior > Add > Texture* | Advanced | Texturas procedurales generadas por fórmula (Brick, Checker, Gabor, Gradient, Magic, Noise, Voronoi, Wave, White Noise) que no necesitan ningún archivo de imagen, más las que sí cargan datos externos: Image Texture (una imagen del disco), Environment Texture (un HDRI panorámico para iluminar la escena), IES Texture (perfil de distribución de luz de una lámpara real) y Sky Texture (cielo procedural físico). |
| 🛠️ | **Add > Utilities > Math: Clamp / Float Curve / Map Range / Math / Mix** | *Barra superior > Add > Utilities > Math* | Advanced | Operan sobre valores numéricos (no colores ni vectores): Clamp limita un valor entre un mínimo y máximo. Float Curve lo remapea con una curva editable a mano. Map Range lo reescala de un rango de entrada a otro de salida. Math hace operaciones aritméticas (suma, multiplicación, potencia, etc.) entre valores. Mix interpola entre dos valores según un factor. |
| 🛠️ | **Add > Utilities > Vector: Combine XYZ / Map Range / Mix Vector / Separate XYZ / Mapping / Normal / Radial Tiling / Vector Curves / Vector Math / Vector Rotate / Vector Transform / Combine Cylindrical / Combine Spherical / Separate Cylindrical / Separate Spherical** | *Barra superior > Add > Utilities > Vector* | Advanced | Las mismas operaciones que en Math pero pensadas para vectores (3 valores X/Y/Z a la vez): Combine XYZ/Separate XYZ unen o separan un vector en sus 3 componentes (también hay variantes Cylindrical/Spherical con otros sistemas de coordenadas). Mapping transforma un vector con posición/rotación/escala, muy usado para mover o rotar una textura. Normal genera/compara un vector normal. Radial Tiling repite un patrón en anillos alrededor de un centro. Vector Curves, Vector Math y Vector Rotate son las versiones vectoriales de Float Curve/Math/rotar un vector. Vector Transform convierte un vector entre distintos espacios de coordenadas (mundo/objeto/cámara). |
| 🛠️ | **Add > Utilities: Repeat / Implicit Conversion / Closure / Evaluate Closure / Combine Bundle / Separate Bundle / Join Bundle / Menu Switch** | *Barra superior > Add > Utilities* | Advanced | Utilidades más avanzadas (algunas en gris si no aplican al contexto actual): Repeat ejecuta un grupo de nodos varias veces en bucle. Implicit Conversion y Closure/Evaluate Closure gestionan cómo se convierten y evalúan datos entre distintos tipos internamente. Combine Bundle/Separate Bundle/Join Bundle agrupan o separan varios datos en un único 'paquete' para pasarlos juntos por un solo cable. Menu Switch crea una entrada de tipo menú desplegable para elegir entre varias ramas de nodos. |
| 👥 | **Add > Group: New Group** | *Barra superior > Add > Group* | Intermediate | Crea un Node Group nuevo y vacío; si ya existieran Node Groups guardados en el archivo, aparecerían listados aquí también para poder añadir una instancia de ellos. |
| 📐 | **Add > Layout: Frame / Reroute** | *Barra superior > Add > Layout* | Basic | No procesan ningún dato, son solo de organización visual: Frame agrupa visualmente varios nodos dentro de un marco con un título (para organizar redes grandes). Reroute es un punto de paso para un cable, útil para ordenar el cableado o dividir una misma salida hacia varios destinos sin cruzar líneas. |
