# Compositor > Add


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ➕ | **Add: menú general** | *Barra superior del Compositor > Add* | Basic | Menú para crear nodos nuevos en el árbol, organizado por categorías: Input/Output, Color, Creative, Filter, Keying, Mask, Tracking, Texture, Transform, Utilities, Group y Layout. Mismo mecanismo que en 'Shader Editor > Add' pero orientado al flujo de postproducción 2D sobre las capas de render en vez de a construir un material 3D. |
| 📥 | **Add > Input: Constant / Blank Image / Bokeh Image / Group Input / Image / Image Info / Image Coordinates / Mask / Movie Clip / String To Image / Scene** | *Barra superior > Add > Input* | Advanced | Constant y Scene son submenús (ver filas siguientes). El resto traen una imagen/dato externo al compositor: Blank Image (imagen en blanco de un tamaño dado), Bokeh Image (genera una forma de bokeh procedural para usar como núcleo de desenfoque), Group Input (entrada de un Node Group), Image (una imagen/secuencia cargada del disco o ya abierta en Blender), Image Info/Image Coordinates (metadatos y coordenadas de una imagen), Mask (una Mask 2D del Mask Editor), Movie Clip (un clip del Movie Clip Editor), String To Image (convierte texto en una imagen renderizada con una fuente). |
| 📥 | **Add > Input > Constant: Boolean / Color / Font / Integer / Integer Vector / Menu / Normal / Object / Rotation / String / Value / Vector** | *Barra superior > Add > Input > Constant* | Advanced | Igual que en 'Shader Editor > Add > Input', nodos para introducir a mano un valor fijo del tipo correspondiente; aquí incluye además Font (una fuente tipográfica, para usar con String To Image) e Integer Vector (vector de números enteros). |
| 📥 | **Add > Input > Scene: Active Camera / Camera Info / Object Info / Render Layers / Scene Time / Time Curve** | *Barra superior > Add > Input > Scene* | Advanced | Traen datos de la escena 3D al compositor: Active Camera (la cámara activa como objeto), Camera Info (sus parámetros, ej. distancia focal), Object Info (datos de un objeto concreto), Render Layers (el resultado renderizado de un View Layer con todos sus pases/AOV — la entrada más usada del Compositor), Scene Time (fotograma actual), Time Curve (curva de tiempo editable). |
| 📤 | **Add > Output: Enable Output / Group Output / Viewer / Warning / File Output** | *Barra superior > Add > Output* | Intermediate | Enable Output activa/desactiva en bloque otro nodo de salida sin desconectarlo. Group Output es la salida de un Node Group. Viewer muestra el resultado en el Image Editor/Backdrop del propio Compositor para previsualizar sin afectar al render final. Warning muestra un aviso en la interfaz si recibe cierto valor (para depurar el propio árbol). File Output guarda el resultado directamente a uno o varios archivos de imagen en disco, con su propia ruta y formato configurables. |
| 🎨 | **Add > Color: Alpha Convert / Alpha Over / Set Alpha / Combine Color / Separate Color / Depth Combine / Mix Color / Blackbody / Color Ramp / Convert Colorspace / Convert to Display / Invert Color / RGB to BW / Adjust** | *Barra superior > Add > Color* | Advanced | Alpha Convert/Alpha Over/Set Alpha gestionan el canal alfa (transparencia) y cómo se superponen imágenes con él. Combine Color/Separate Color unen o separan una imagen en sus canales (RGB/HSV/HSL/YCbCr...). Depth Combine combina dos imágenes usando su pase Z (profundidad) para decidir cuál queda delante. Mix Color mezcla dos imágenes con distintos modos de fusión. Blackbody, Color Ramp, Convert Colorspace, Convert to Display, Invert Color y RGB to BW son las mismas utilidades ya vistas en Shader Editor, aplicadas aquí a imágenes completas en vez de a un shader. Adjust agrupa un submenú aparte con más ajustes de color tipo edición fotográfica (ver fila siguiente). |
| 🎨 | **Add > Color > Adjust: Brightness/Contrast / Color Balance / Color Correction / Exposure / Gamma / Hue Correct / Hue/Saturation/Value / RGB Curves / Tonemap** | *Barra superior > Add > Color > Adjust* | Advanced | Brightness/Contrast y Gamma ajustan brillo/contraste/gamma global. Color Balance corrige el tono por rangos tonales (sombras/medios/altas luces, rueda de color tipo etalonaje). Color Correction es similar pero con más control por canal. Exposure simula cambiar la exposición de cámara en stops. Hue Correct ajusta el tono según una curva editable por rango de color. Hue/Saturation/Value y RGB Curves son las mismas utilidades ya vistas. Tonemap comprime el rango dinámico de una imagen HDR para que se vea bien en pantalla SDR. |
| 🎭 | **Add > Creative: Kuwahara / Pixelate / Posterize** | *Barra superior > Add > Creative* | Intermediate | Filtros con efecto artístico/estilizado: Kuwahara suaviza la imagen preservando bordes, dando un aspecto pictórico tipo pintura. Pixelate reduce la resolución efectiva en bloques, dando aspecto retro/pixel art. Posterize reduce el número de tonos de color disponibles, dando un aspecto de cartel con bandas de color planas. |
| 🌫️ | **Add > Filter: Anti-Aliasing / Convolve / Denoise / Despeckle / Dilate/Erode / Mask To SDF / Inpaint / Filter / Glare / Blur** | *Barra superior > Add > Filter* | Advanced | Anti-Aliasing suaviza bordes dentados. Convolve aplica un filtro de convolución con un kernel personalizado. Denoise limpia el ruido del render (muy útil con los pases de Cycles). Despeckle quita píxeles sueltos/ruido puntual sin difuminar el resto. Dilate/Erode agranda o encoge una máscara/selección. Mask To SDF convierte una máscara en un campo de distancia con signo. Inpaint rellena zonas marcadas reconstruyendo el contenido a partir de los píxeles vecinos. Filter agrupa filtros de convolución clásicos (enfocar, realzar bordes, suavizar...). Glare añade destellos/resplandor alrededor de zonas muy brillantes. Blur agrupa un submenú aparte con distintos tipos de desenfoque (ver fila siguiente). |
| 🌫️ | **Add > Filter > Blur: Bilateral Blur / Blur / Bokeh Blur / Defocus / Directional Blur / Vector Blur** | *Barra superior > Add > Filter > Blur* | Advanced | Bilateral Blur difumina preservando bordes marcados (según diferencia de color). Blur es el desenfoque gaussiano/genérico estándar. Bokeh Blur simula el desenfoque de un objetivo de cámara real con una forma de apertura concreta. Defocus simula el desenfoque de profundidad de campo usando el pase Z. Directional Blur difumina en una única dirección (efecto de movimiento en línea recta o zoom). Vector Blur usa el pase de Vector/motion para simular motion blur realista según el movimiento real de cada píxel entre fotogramas. |
| 🎬 | **Add > Keying: Channel Key / Chroma Key / Color Key / Color Spill / Difference Key / Distance Key / Keying / Keying Screen / Luminance Key** | *Barra superior > Add > Keying* | Advanced | Herramientas para quitar un fondo (croma) y recomponer sobre otro: Channel Key clave por un canal de color concreto. Chroma Key clave por un color de croma (verde/azul) en espacio YUV. Color Key clave por un rango de color RGB. Color Spill quita el 'derrame' de color del croma reflejado en el sujeto (ej. borde verdoso en el pelo). Difference Key clave comparando con una imagen de referencia sin sujeto. Distance Key clave por distancia de color en un espacio de color dado. Keying es el nodo de clave más completo y usado (despill, ajuste de bordes, etc. en un solo nodo). Keying Screen analiza una placa del fondo de croma para generar una clave de referencia más uniforme. Luminance Key clave por luminosidad. |
| 🎭 | **Add > Mask: Cryptomatte / Cryptomatte (Legacy) / Box Mask / Ellipse Mask / Double Edge Mask / ID Mask** | *Barra superior > Add > Mask* | Advanced | Cryptomatte (y su versión Legacy) genera máscaras de selección por objeto/material a partir del pase Cryptomatte del render, permitiendo aislar cualquier elemento por nombre sin repetir el render. Box Mask/Ellipse Mask dibujan una máscara geométrica simple (rectángulo/elipse) directamente en el nodo. Double Edge Mask genera un degradado en ambos bordes de una máscara existente. ID Mask genera una máscara a partir del pase Object Index/Material Index de un render. |
| 🎯 | **Add > Tracking: Plane Track Deform / Stabilize 2D / Track Position** | *Barra superior > Add > Tracking* | Advanced | Traen al Compositor los datos de un seguimiento (tracking) hecho en el Movie Clip Editor: Plane Track Deform proyecta una imagen/textura deformada sobre un Plane Track rastreado (para insertar carteles/pantallas en un vídeo). Stabilize 2D aplica la estabilización 2D calculada en el tracking. Track Position da la posición 2D de un punto de seguimiento concreto, fotograma a fotograma. |
| 🧱 | **Add > Texture: Brick Texture / Checker Texture / Gabor Texture / Gradient Texture / Magic Texture / Noise Texture / Voronoi Texture / Wave Texture / White Noise Texture** | *Barra superior > Add > Texture* | Intermediate | Las mismas texturas procedurales ya vistas en 'Shader Editor > Add > Texture', generadas aquí directamente como una imagen 2D del Compositor en vez de como entrada de un material (no incluye Environment/IES/Image/Sky Texture, que no aplican al Compositor). |
| 📐 | **Add > Transform: Rotate / Scale / Transform / Translate / Corner Pin / Crop / Displace / Flip / Map UV / Lens Distortion / Movie Distortion** | *Barra superior > Add > Transform* | Advanced | Rotate/Scale/Translate mueven, rotan o escalan la imagen entera por separado; Transform hace las 3 cosas a la vez en un solo nodo. Corner Pin deforma la imagen ajustando sus 4 esquinas a 4 puntos distintos (para encajarla en una superficie en perspectiva). Crop recorta la imagen a una región. Displace desplaza los píxeles según un mapa de desplazamiento (vector). Flip la voltea en horizontal/vertical. Map UV la remapea según un pase UV. Lens Distortion simula/corrige la distorsión óptica de un objetivo real (barril/cojín, aberración cromática). Movie Distortion aplica la distorsión de lente calibrada en el tracking de un clip. |
| 🛠️ | **Add > Utilities: Levels / Normalize / Implicit Conversion / Split / Switch / Index Switch / Menu Switch / Switch Stereo View / Relative To Pixel / Math / Vector / Matrix / Rotation / Text** | *Barra superior > Add > Utilities* | Advanced | Levels muestra un histograma con cuentagotas para leer valores de la imagen. Normalize reescala los valores de la imagen a un rango 0-1. Implicit Conversion/Split/Switch/Index Switch/Menu Switch gestionan bifurcaciones y conversiones de tipo de dato dentro del árbol (elegir entre varias entradas según una condición, índice o menú). Switch Stereo View elige entre la vista izquierda/derecha en un render estéreo. Relative To Pixel convierte un valor relativo (0-1) a píxeles absolutos según la resolución. Math/Vector/Matrix/Rotation/Text son submenús con nodos numéricos, de rotación y de texto respectivamente (ver filas siguientes). |
| 🛠️ | **Add > Utilities > Math: Clamp / Float Curve / Map Range / Math / Mix** | *Barra superior > Add > Utilities > Math* | Advanced | Mismo submenú ya visto en 'Shader Editor > Add > Utilities > Math', aquí operando sobre los valores numéricos de la imagen: Clamp limita un valor entre un mínimo y máximo. Float Curve lo remapea con una curva editable a mano. Map Range lo reescala de un rango de entrada a otro de salida. Math hace operaciones aritméticas entre valores. Mix interpola entre dos valores según un factor. |
| 🛠️ | **Add > Utilities > Vector: Combine XYZ / Map Range / Mix Vector / Separate XYZ / Radial Tiling / Vector Curves / Vector Math / Vector Rotate** | *Barra superior > Add > Utilities > Vector* | Advanced | Versión reducida del submenú Vector ya visto en Shader Editor: mismas operaciones (Combine XYZ/Separate XYZ, Map Range, Mix Vector, Radial Tiling, Vector Curves, Vector Math, Vector Rotate) pero SIN Mapping, Normal, Vector Transform ni las variantes Cylindrical/Spherical, que son específicas de coordenadas 3D de shading y no aplican a una imagen 2D del Compositor. |
| 🛠️ | **Add > Utilities > Matrix: Combine Matrix / Determinant / Invert Matrix / Multiply Matrices / Project Point / Separate Matrix / Transform Direction / Transform Point / Transpose Matrix** | *Barra superior > Add > Utilities > Matrix* | Advanced | Submenú de álgebra matricial, no visto en 'Shader Editor > Add': Combine Matrix construye una matriz 4×4 a partir de sus componentes; Separate Matrix hace lo contrario. Determinant calcula su determinante. Invert Matrix la invierte. Multiply Matrices las multiplica entre sí. Project Point proyecta un punto 3D a través de la matriz (ej. de cámara) a coordenadas 2D de pantalla. Transform Direction/Transform Point transforman un vector/punto por la matriz. Transpose Matrix la transpone. |
| ➕ | **Add > Utilities > Rotation: Align Rotation to Vector / Axes to Rotation / Axis Angle to Rotation / Euler to Rotation / Invert Rotation / Mix Rotation / Rotate Rotation / Rotate Vector / Rotation to Axis Angle / Rotation to Euler / Rotation to Quaternion / Quaternion to Rotation** | *Barra superior > Add > Utilities > Rotation* | Advanced | Submenú de álgebra de rotaciones, no visto en 'Shader Editor > Add': Align Rotation to Vector calcula la rotación necesaria para alinear un eje con un vector dado. Axes to Rotation construye una rotación a partir de 2-3 ejes. Axis Angle to Rotation/Rotation to Axis Angle convierten entre una rotación y su forma eje+ángulo. Euler to Rotation/Rotation to Euler convierten entre ángulos de Euler y una rotación. Invert Rotation calcula la rotación inversa. Mix Rotation interpola entre dos rotaciones. Rotate Rotation combina/compone dos rotaciones. Rotate Vector aplica una rotación a un vector. Rotation to Quaternion/Quaternion to Rotation convierten entre una rotación y su representación en cuaternión. |
| ➕ | **Add > Utilities > Text: Format String / Match String / Replace String / Reverse String / Set String Case / Slice String / Trim String / Find in String / String Length / String to Value / Value to String / Special Characters** | *Barra superior > Add > Utilities > Text* | Advanced | Submenú de manipulación de texto, no visto en 'Shader Editor > Add' (relacionado con el nodo String To Image de Input): Format String compone una cadena insertando valores. Match String comprueba si una cadena cumple un patrón. Replace String sustituye una parte de la cadena por otra. Reverse String la invierte. Set String Case cambia mayúsculas/minúsculas. Slice String extrae una sub-cadena. Trim String quita espacios sobrantes. Find in String busca la posición de un texto dentro de otro. String Length da su longitud en caracteres. String to Value/Value to String convierten entre texto y un valor numérico. Special Characters inserta caracteres especiales predefinidos. |
