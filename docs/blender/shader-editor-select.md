# Shader Editor > Select


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖱️ | **Lasso Select: Set / Extend / Subtract** | *Barra superior del Shader Editor > Select > Lasso Select* | Intermediate | Misma variante de 3 modos ya vista en 'UV Editor > Select', pero aquí el gesto se hace con el BOTÓN IZQUIERDO del ratón en vez del derecho: Extend es Ctrl+Alt+arrastrar (Botón Izquierdo), Subtract es Mayús+Ctrl+Alt+arrastrar (Botón Izquierdo). |
| ⌨️ | **Lasso Select: Extend** | *Ctrl+Alt+arrastrar (Botón Izquierdo)* | Intermediate | Lasso Select: Extend |
| ⌨️ | **Lasso Select: Subtract** | *Mayús+Ctrl+Alt+arrastrar (Botón Izquierdo)* | Intermediate | Lasso Select: Subtract |
| 🔗 | **Linked from / Linked to** | *Barra superior del Shader Editor > Select* | Advanced | Amplían la selección siguiendo los cables conectados al nodo activo: Linked from (L) selecciona todos los nodos 'aguas arriba' que alimentan de datos al nodo activo. Linked to (Mayús+L) selecciona los nodos 'aguas abajo' que reciben datos del nodo activo. |
| ⌨️ | **Linked from** | <kbd>L</kbd> | Advanced | Linked from |
| ⌨️ | **Linked to** | <kbd>Mayús</kbd> + <kbd>L</kbd> | Advanced | Linked to |
| 🖱️ | **Select Grouped: Type / Color / Prefix / Suffix** | *Barra superior del Shader Editor > Select > Select Grouped* | Advanced | Amplía la selección a partir del nodo activo: Type (mismo tipo de nodo), Color (mismo color asignado al nodo), Prefix (nombre con el mismo prefijo, el texto antes del primer espacio o punto), Suffix (mismo sufijo, el texto después del último espacio o punto). Las 4 variantes comparten el atajo Mayús+G y se elige la opción en un menú contextual. |
| ⌨️ | **Select Grouped** | <kbd>Mayús</kbd> + <kbd>G</kbd> | Advanced | Select Grouped |
| 🖱️ | **Activate Same Type Previous / Activate Same Type Next** | *Barra superior del Shader Editor > Select* | Advanced | Cambian cuál es el nodo ACTIVO (el de borde blanco, no la selección completa) saltando al nodo anterior/siguiente del mismo tipo que el actual, sin cambiar qué nodos están seleccionados. |
| ⌨️ | **Activate Same Type Previous** | <kbd>Mayús</kbd> + <kbd>[</kbd> | Advanced | Activate Same Type Previous |
| ⌨️ | **Activate Same Type Next** | <kbd>Mayús</kbd> + <kbd>]</kbd> | Advanced | Activate Same Type Next |
| 🔎 | **Find Node...** | *Barra superior del Shader Editor > Select* | Intermediate | Abre un cuadro de búsqueda para localizar y seleccionar un nodo por su nombre, útil en gráficos de nodos grandes donde es difícil encontrarlo a simple vista. |
| ⌨️ | **Find Node...** | <kbd>Ctrl</kbd> + <kbd>F</kbd> | Intermediate | Find Node... |
