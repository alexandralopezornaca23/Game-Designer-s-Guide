# Preferences > Editing: 3D Cursor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| - | **Surface Project** | *Edit > Preferences > Editing > 3D Cursor* | Intermediate | Al colocar el 3D Cursor con Mayús+Clic derecho, lo pega a la superficie del objeto bajo el cursor en vez de dejarlo flotando en el aire. |
| - | **Lock Adjust** | *Edit > Preferences > Editing > 3D Cursor* | Advanced | Bloquea también la rotación del 3D Cursor al usar Surface Project, para que se oriente según la normal de la superficie. |
