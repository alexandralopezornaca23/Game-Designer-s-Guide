# Top Menu > Help


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ❓ | **Manual** | *Help > Manual* | Basic | Abre en el navegador la documentación oficial online de Blender. |
| ❓ | **Support** | *Help > Support* | Basic | Enlace a la página oficial de opciones de soporte (fondo Blender, contacto...). |
| 💬 | **User Communities** | *Help > User Communities* | Basic | Enlace a los espacios oficiales de comunidad (foros, Discord...) para pedir ayuda o resolver dudas con otros usuarios. |
| 🤝 | **Get Involved** | *Help > Get Involved* | Intermediate | Enlace a cómo contribuir al propio desarrollo de Blender (código, documentación, traducciones...), al ser software libre y de código abierto. |
| 📝 | **Release Notes** | *Help > Release Notes* | Basic | Abre las notas de la versión instalada, con el listado de novedades y cambios de esa release. |
| 🐛 | **Report a Bug** | *Help > Report a Bug* | Intermediate | Abre el formulario oficial para reportar errores, ya con la info de tu versión/sistema rellenada. |
| 🖥️ | **Save System Info...** | *Help > Save System Info...* | Advanced | Genera un archivo de texto con los datos técnicos de tu sistema (GPU, drivers, versión de Blender...); suele pedirse al reportar bugs. |
