# Interface — Window


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🪟 | **Cómo está repartida la ventana** | — | Basic | Cinco zonas. Arriba, el MENÚ SUPERIOR con todos los comandos, y debajo la BARRA DE HERRAMIENTAS con los botones de uso frecuente y los selectores de pincel. A la izquierda, la CAJA DE HERRAMIENTAS (Toolbox) con la herramienta activa. En el centro, el LIENZO. A los lados, los DOCKERS o paneles acoplables (capas, color, pinceles...), que se mueven y se apilan como quieras. Y abajo del todo, la BARRA DE ESTADO con el zoom y la información del documento. |
| 📋 | **Menú superior: los diez menús** | *Menú superior* | Basic | FILE (archivos y exportación), EDIT (deshacer, copiar, pegar, rellenar), VIEW (zoom, espejo, reglas, guías), IMAGE (tamaño y propiedades de la imagen entera), LAYER (todo lo de capas y máscaras), SELECT (selecciones), FILTER (filtros y efectos), TOOLS (scripts y grabación), SETTINGS (dockers, atajos, preferencias y espacios de trabajo) y HELP. La diferencia que más confunde al empezar: IMAGE actúa sobre el documento entero y LAYER solo sobre la capa activa. |
| 🧩 | **Los dockers y cómo se colocan** | *Settings > Dockers* | Basic | Cada panel lateral es un DOCKER y se enciende o se apaga desde Settings > Dockers. Se arrastran por su barra de título para moverlos, se apilan en pestañas soltando uno encima de otro, y se pueden sacar fuera de la ventana. Krita trae muchos más de los que ves por defecto: si echas de menos una función, mira primero si su docker está apagado. |
| 🗂️ | **Los espacios de trabajo (Workspaces)** | *Barra de herramientas, botón de la derecha / Settings > Workspaces* | Intermediate | Un espacio de trabajo guarda QUÉ dockers tienes abiertos y dónde. Krita trae varios preparados (pintura, animación, edición) y puedes guardar el tuyo. Merece la pena montarte uno para pintar texturas y otro para animar sprites: cambiar de uno a otro es un clic. |
| 📊 | **La barra de estado** | *Parte inferior de la ventana* | Basic | Muestra el nivel de zoom (se puede escribir un valor exacto), el perfil de color del documento, la memoria que está usando Krita y un aviso cuando hay una selección activa. Ese aviso de selección es el que te salva cuando el pincel 'no pinta' porque te habías dejado una selección puesta. |
| 🖥️ | **Modo de pantalla completa y modo sin distracciones** | *View > Full Screen Mode / Canvas Only* | Intermediate | CANVAS ONLY esconde toda la interfaz y deja solo el lienzo, que es como conviene mirar un dibujo antes de darlo por terminado. FULL SCREEN MODE quita además el marco de la ventana. Los dos se recuperan con el mismo comando. |
