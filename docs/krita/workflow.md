# Workflow


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖼️ | **De PureRef a Krita** | *Herramienta Reference Images* | Intermediate | Dos caminos: tener PureRef flotando encima mientras pintas, o meter las referencias DENTRO del .KRA con la herramienta Reference Images, que las deja flotando sobre el lienzo sin exportarse. El segundo es mejor cuando el archivo va a viajar o cuando trabajas en una sola pantalla. |
| 🎮 | **De Krita a Unity** | *File > Export > PNG* | Intermediate | Para un sprite o una textura, exporta PNG con transparencia y con el tamaño en potencias de dos (512, 1024, 2048) si va a ser una textura de material. Guarda siempre el .KRA con las capas al lado del PNG exportado, en la carpeta del proyecto. |
| 🗿 | **De ZBrush a Krita y vuelta** | — | Intermediate | El puente natural: sacas de ZBrush una captura o un render BPR (Document > Export, o Texture > Grab Unshaded Doc para textura plana), lo pintas o lo retocas en Krita, y el resultado vuelve como textura o se queda como lámina de portafolio. |
| 📸 | **Krita para el portafolio, no solo para el arte final** | — | Basic | Guarda los bocetos y las capas de proceso: una lámina que enseñe boceto, línea, color plano y acabado dice mucho más de cómo trabajas que la imagen final sola, y es justo lo que se valora en una entrega y en un portafolio. |
