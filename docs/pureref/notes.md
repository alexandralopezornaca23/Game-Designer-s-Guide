# Notes


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🅱️ | **Toggle bold text** | <kbd>Ctrl</kbd> + <kbd>B</kbd> | Intermediate | Pone en negrita el texto de una nota. Las notas son cuadros de texto que se colocan en el lienzo junto a las imágenes. |
| 𝑰 | **Toggle italic text** | <kbd>Ctrl</kbd> + <kbd>I</kbd> | Intermediate | Pone el texto en cursiva. |
| ⎁ | **Toggle underline** | <kbd>Ctrl</kbd> + <kbd>U</kbd> | Intermediate | Subraya el texto. |
| 🔠 | **Increase font size** | <kbd>Ctrl</kbd> + <kbd>Mayús</kbd> + <kbd>.</kbd> | Intermediate | Agranda la letra de la nota. |
| 📝 | **Para qué sirven las notas en un tablero** | — | Intermediate | Para dejar escrito POR QUÉ está ahí cada referencia: 'la silueta de esta capa es la que quiero', 'ojo, este material es cuero, no tela', 'proporción 7 cabezas'. Cuando retomas el proyecto semanas después, esas notas son lo que te ahorra volver a decidirlo todo. PureRef tiene además un apartado de atajos llamado Multi Note para trabajar con varias a la vez. |
