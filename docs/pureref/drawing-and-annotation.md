# Drawing & Annotation


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ✏️ | **Select pen tool** | <kbd>D</kbd> | Intermediate | Activa el LÁPIZ para dibujar a mano alzada sobre el tablero. Sirve para marcar líneas de acción, proporciones o ejes de simetría encima de una referencia. |
| 📏 | **Select line tool** | <kbd>L</kbd> | Intermediate | Activa la LÍNEA recta. Es lo que se usa para trazar las líneas de altura de un personaje sobre varias referencias a la vez y comprobar que las proporciones coinciden. |
| ▭ | **Select rectangle tool** | <kbd>R</kbd> | Intermediate | Activa el RECTÁNGULO, para encuadrar la zona de una imagen que te interesa. |
| ⭕ | **Select ellipse tool** | <kbd>C</kbd> | Intermediate | Activa la ELIPSE, cómoda para señalar formas redondeadas (el volumen de un hombro, una articulación). |
| 🧽 | **Select eraser tool** | <kbd>E</kbd> | Intermediate | Activa el BORRADOR para quitar lo dibujado. |
| 🎨 | **Para qué sirve dibujar sobre las referencias** | — | Intermediate | Poder anotar encima convierte el tablero en una herramienta de ESTUDIO y no solo de consulta: marcar las líneas de acción de una pose, las divisiones de proporción de una figura o el recorrido de la luz en una foto te hace entender la referencia en vez de copiarla. Para una entrega de clase, además, ese tablero anotado enseña tu proceso. |
