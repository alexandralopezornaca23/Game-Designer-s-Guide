# Navigation & View


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ✋ | **Pan (mover el lienzo)** | *Alt + clic izquierdo y arrastrar* | Basic | Desplaza el lienzo para moverte por el tablero. Como el lienzo es infinito, puedes tener zonas separadas —una para la cabeza, otra para las manos, otra para la ropa— y viajar entre ellas. |
| 🔍 | **Zoom in** | <kbd>Ctrl</kbd> | Basic | Acerca la vista. Sirve para estudiar un detalle concreto de una referencia sin abrirla en otro programa. |
| 🔍 | **Zoom out** | <kbd>Ctrl</kbd> + <kbd>-</kbd> | Basic | Aleja la vista. |
| 🎯 | **Reset camera zoom** | <kbd>Ctrl</kbd> + <kbd>0</kbd> | Basic | Devuelve el zoom a su valor original. Es el botón de 'me he perdido' cuando te has ido demasiado lejos o demasiado cerca. |
| 🔲 | **Select all** | <kbd>Ctrl</kbd> + <kbd>A</kbd> | Basic | Selecciona todas las imágenes del lienzo. Combinado con el agrupado o con una alineación, es la forma de ordenar el tablero entero de una vez. |
