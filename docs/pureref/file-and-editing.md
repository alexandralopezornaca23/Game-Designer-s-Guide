# File & Editing


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💾 | **Save** | <kbd>Ctrl</kbd> + <kbd>S</kbd> | Basic | Guarda la escena en su archivo .pur. Igual que en cualquier programa: guarda a menudo, sobre todo después de pasarte media hora colocando referencias. |
| 📤 | **Export scene** | <kbd>Ctrl</kbd> + <kbd>E</kbd> | Intermediate | Exporta la escena. Sirve para sacar el tablero como imagen y llevártelo a otro sitio — por ejemplo para cargarlo luego en ZBrush como Image Plane, o para adjuntarlo en una entrega. |
| 📋 | **Copy** | <kbd>Ctrl</kbd> + <kbd>C</kbd> | Basic | Copia lo que tengas seleccionado. |
| 📌 | **Paste** | <kbd>Ctrl</kbd> + <kbd>V</kbd> | Basic | Pega. Es también la forma rápida de meter una imagen copiada del navegador directamente en el tablero. |
| 📄 | **Duplicate** | <kbd>Ctrl</kbd> + <kbd>D</kbd> | Intermediate | Duplica la selección. Útil para tener la misma referencia dos veces, una entera y otra recortada en un detalle. |
| ↩️ | **Undo** | <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Basic | Deshace el último cambio. |
| ↪️ | **Redo** | <kbd>Ctrl</kbd> + <kbd>Mayús</kbd> + <kbd>Z</kbd> | Basic | Rehace lo deshecho. |
| ❌ | **Close** | <kbd>Ctrl</kbd> + <kbd>Q</kbd> | Basic | Cierra el programa. |
