# Graph Editor


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🎯 | **Encuadrar la curva completa** | <kbd>F</kbd> | Intermediate | Centra la vista del Graph Editor en las curvas del objeto seleccionado (distinto del F de encuadrar en el viewport 3D). |
| ✂️ | **Romper tangentes** | *Tangents > Break Tangents* | Advanced | Permite mover un asa de la curva sin que se mueva la otra; útil para golpes secos. |
| 📉 | **Tangentes planas** | *Tangents > Flat* | Advanced | Pone las asas en horizontal para evitar que el movimiento rebote al inicio/fin. |
