# Rigging


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🦴 | **Ajustar tamaño de los joints (Joint Size)** | *Display > Animation > Joint Size* | Basic | Solo cambia la visualización, no afecta al rig. |
| 🦴 | **Encadenar / emparentar joints** | *P (con los joints seleccionados de hijo a padre)* | Intermediate | Selecciona primero los huesos hijos y en último lugar el padre. |
| 🪞 | **Mirror Joints (duplicar en espejo)** | *Skeleton > Mirror Joints* | Intermediate |  |
| ⚪ | **Seleccionar vértices de un control (Control Vertex)** | *Ctrl + Clic derecho (mantenido) sobre la curva > Control Vertex* | Advanced |  |
| ⚪ | **Seleccionar todos los vértices del control** | *En Control Vertex: Ctrl + Clic derecho (mantenido) > To CVs* | Advanced |  |
| 🎨 | **Dar color a los controles (Drawing Overrides)** | *Attribute Editor > pestaña Shape > Object Display > Drawing Overrides* | Intermediate | Convención habitual: rojo = derecha, amarillo = central, azul = izquierda. |
