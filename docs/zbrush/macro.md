# Macro


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| ❗ | **Macro > grabar tu propio macro** | *Menú superior > Macro* | Advanced | Los macros son la forma FÁCIL de automatizar ZBrush sin escribir ni una línea de código: se graba una secuencia de pasos hechos a mano y queda como un botón más en esta paleta. Para tareas repetitivas de un trabajo de clase (preparar todos los SubTools igual, exportar con los mismos ajustes) ahorra muchísimo tiempo. Los macros más complejos se escriben en ZScript. |
| ⏺️ | **New Macro** | *Menú superior > Macro* | Advanced | Empieza a grabar: a partir de aquí se hacen los pasos a mano. |
| ⏹️ | **End Macro** | *Menú superior > Macro* | Advanced | Termina la grabación y pide un nombre para el macro. |
| 🔄 | **Reload All Macros** | *Menú superior > Macro* | Advanced | Recarga la lista. Es lo que hay que pulsar tras instalar macros descargados. |
