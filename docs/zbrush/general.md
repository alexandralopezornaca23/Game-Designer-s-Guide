# General


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 📂 | **Abrir proyecto** | <kbd>Ctrl</kbd> + <kbd>O</kbd> | Basic | Abre un archivo de PROYECTO (.ZPR), que es el formato completo: guarda la escultura con todos sus SubTools, más el documento, las luces, los materiales y la configuración de la sesión. Es el que quieres para continuar un trabajo. No confundirlo con la herramienta (.ZTL), que guarda solo el modelo y sus SubTools, ni con el documento (.ZBR), que guarda solo el lienzo 2.5D y NO la escultura. |
| 💾 | **Guardar proyecto** | <kbd>Ctrl</kbd> + <kbd>S</kbd> | Basic | Guarda el proyecto entero en .ZPR. Dos consejos que ahorran disgustos: usa File > Save Next en lugar de sobrescribir siempre el mismo archivo, porque guarda versiones numeradas solas y te deja volver atrás días después; y ten presente que si Enable Saving está activo en Preferences > Undo History, el archivo lleva dentro todo el historial de deshacer y puede pesar varios gigas. Existe además el guardado automático de QuickSave, que se recupera desde LightBox. |
| ↩️ | **Deshacer / Rehacer** | <kbd>Ctrl</kbd> + <kbd>Z / Mayús</kbd> + <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Basic | Los de siempre, pero con una particularidad de ZBrush que conviene tener clara: hay TRES historiales separados, el general, el de SpotLight y el de la herramienta, y cada uno se deshace por su cuenta (están en la paleta Edit). Por eso a veces Ctrl+Z parece que no hace nada o deshace algo que no esperabas: estás deshaciendo en otro historial. Para retroceder muchos pasos de golpe es más cómodo el deslizador UndoCounter, que recorre la sesión como una línea de tiempo. |
| ✏️ | **Alternar modo Edición (Edit)** | <kbd>T</kbd> | Basic | Con el modo Edición desactivado no puedes esculpir sobre el modelo. |
| ⌨️ | **Edit Spotlight** | <kbd>Z</kbd> | Intermediate | Edit Spotlight |
| ⌨️ | **Turn On Spotlight** | <kbd>Mayús</kbd> + <kbd>Z</kbd> | Intermediate | Turn On Spotlight |
| ⌨️ | **Snapshot Object** | <kbd>Mayús</kbd> + <kbd>S</kbd> | Intermediate | Snapshot Object |
