# File


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 💾 | **File: la paleta donde se guarda tu trabajo de verdad** | *Menú superior > File* | Basic | LA PALETA MÁS IMPORTANTE para no perder trabajo, y la que más confusión genera en ZBrush porque hay TRES cosas distintas que se pueden guardar. El PROYECTO (.ZPR) es el paquete completo: escultura, SubTools, lienzo, materiales, luces y configuración — es lo que se guarda desde el bloque de arriba de esta paleta y lo que debes usar normalmente. La HERRAMIENTA (.ZTL) es solo tu modelo con sus SubTools, sin escena, y se guarda desde el bloque Tool Mesh de aquí o desde Tool > Save As. El DOCUMENTO (.ZBR) es únicamente el lienzo, y no contiene tu escultura. REGLA: guarda proyecto, y guarda a menudo. |
| 📂 | **File > el bloque del PROYECTO (.ZPR)** | *Menú superior > File (bloque superior)* | Basic | El bloque que de verdad guarda tu trabajo. SAVE NEXT es una joya poco conocida y muy recomendable en un trabajo de clase. |
| 📂 | **Open** | *Menú superior > File (bloque superior)* | Basic | Abre un proyecto .ZPR. |
| 🏷️ | **Save As** | *Menú superior > File (bloque superior)* | Basic | Guarda el proyecto con nombre nuevo. |
| 💾 | **Save** | *Menú superior > File (bloque superior)* | Basic | Sobrescribe el proyecto actual. |
| 🔢 | **Save Next** | *Menú superior > File (bloque superior)* | Basic | Guarda una versión numerada automáticamente (proyecto_1, proyecto_2...) sin preguntarte nada, así que pulsándolo cada rato tienes un historial de versiones sin esfuerzo. |
| ↩️ | **Revert** | *Menú superior > File (bloque superior)* | Basic | Descarta los cambios y recarga el proyecto tal y como está en disco. En gris si aún no lo has guardado. |
| 🕓 | **UndoHistory** | *Menú superior > File (bloque superior)* | Intermediate | Decide si el historial de deshacer se guarda dentro del archivo: te permite seguir deshaciendo al reabrirlo, pero engorda mucho el .ZPR. |
| 🗂️ | **Lightbox▶Projects** | *Menú superior > File (bloque superior)* | Basic | Abre la biblioteca de proyectos. |
| 🧰 | **Open XMD ToolBox** | *Menú superior > File (bloque superior)* | Advanced | Abre esa herramienta adicional. |
| 📝 | **File > Project Notes: notas guardadas dentro del proyecto** | *Menú superior > File* | Intermediate | Un bloc de notas guardado DENTRO del propio proyecto. Sirve para dejarte recordatorios de en qué punto lo dejaste, qué falta por hacer o qué escala usaste, y viaja con el archivo, así que sigue ahí meses después. |
| 📝 | **Project Notes** | *Menú superior > File* | Intermediate | El campo de notas. Sale en gris hasta que se pulsa Edit. |
| ✏️ | **Edit** | *Menú superior > File* | Intermediate | Habilita la escritura en esas notas. |
| 📎 | **File > guardar y cargar elementos sueltos** | *Menú superior > File > TimeLine, SpotLight, Texture, Alpha* | Advanced | Cuatro bloques pequeños para guardar y cargar elementos por separado, sin arrastrar el proyecto entero. Cada uno lleva su propia Paleta porque los nombres se repiten entre ellos. |


## File > Canvas, Tool Mesh


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🧊 | **File > Canvas y Tool Mesh: guardar el lienzo y la herramienta** | *Menú superior > File > Canvas, Tool Mesh* | Intermediate | Los dos bloques que guardan las OTRAS dos cosas: CANVAS guarda el documento (.ZBR), o sea el lienzo, y TOOL MESH guarda la HERRAMIENTA (.ZTL), tu modelo con sus SubTools. Cada uno lleva su propia Paleta porque repiten los nombres Open, Save, Save As y Save Next del bloque del proyecto. |
