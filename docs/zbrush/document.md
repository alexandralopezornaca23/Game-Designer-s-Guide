| 📁 | **Document: qué es el documento y por qué apenas vas a tocar esta paleta** | *Menú superior > Document* | Intermediate | El DOCUMENTO es el lienzo 2D sobre el que ZBrush dibuja: la zona gris donde ves tu modelo. Viene del ZBrush clásico, que era un programa de pintura 2.5D, y por eso esta paleta habla de anchos, altos y píxeles en vez de polígonos. Para esculpir y llevarte el modelo a Unity o Maya no la necesitas casi nunca. Sí importa en tres casos: cuando quieres una imagen de tu escultura a buena resolución para el portafolio, cuando vas a usar ZAppLink para retocar en Photoshop, y cuando quieres cambiar el fondo. OJO con la confusión: guardar el documento (.ZBR) NO guarda tu escultura, guarda el lienzo. Tu trabajo se guarda con File > Save As (proyecto .ZPR) o Tool > Save As (herramienta .ZTL). |

## Document > PaintStop


| | Action | Shortcut / Location | Level | Notes |
|---|---|---|---|---|
| 🖍️ | **Document > PaintStop** | *Menú superior > Document > PaintStop* | Advanced | PaintStop es un programa de pintura 2D que viene incluido dentro de ZBrush, con pinceles que imitan óleo, acuarela, lápiz y carboncillo sobre lienzos con textura. Se abre desde este botón y trabaja sobre el documento. No tiene nada que ver con esculpir: es una herramienta de ilustración aparte, herencia de la época en que ZBrush era un programa de pintura. La miniatura de al lado muestra un ejemplo del tipo de resultado. Curiosidad útil si algún día quieres pintar un fondo a mano detrás de una escultura para una lámina. |
